# src/data — 촉매 파생

## 목적

**촉매(Catalyst) 시스템의 데이터 계약과 파생 로직**(ADR-0029). 리포 루트의 `/data`(콘텐츠 카탈로그)와
이름이 같지만 층이 다르다 — 여기는 `src` 안이라 앱 로직에 가깝고, 순수 함수로만 이루어져 있다.

촉매는 **런 1회를 격화시키는 소모품**이다. 모든 촉매가 난이도 페널티와 보상 부스트를 한 몸으로
가지며, 출격 전 성계 지도에서 주입하고 런 시작 시 소모된다(PvE 전용).
