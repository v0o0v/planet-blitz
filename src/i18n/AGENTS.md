# i18n — 로컬라이즈

## 목적

게임 내 사용자 노출 문자열을 키로 조회하는 계층. **영어(`EN`)가 정본**이고 `MessageKey` 는 그 키
집합에서 파생되며, 한국어(`KO`)는 같은 키를 전부 채워야 한다(`Record<MessageKey, string>` 로 강제 —
누락하면 컴파일 오류). 브라우저 언어 자동 감지 + 수동 토글, 선택은 localStorage 에 남는다.

sim 은 이 모듈을 **절대** import 하지 않는다(ADR-0005 — 문자열은 해시와 무관).

## 주요 파일

| 파일 | 설명 |
|---|---|
| `catalog.ts` | (4432줄) `EN` / `KO` 카탈로그. **`KO` 선언부 바로 위 주석이 한국어 용어 정본표**다 — 문구를 쓰기 전에 반드시 읽는다 |
| `index.ts` | `t(key, params)` 조회 + 로케일 선택. `pickInitialLocale` 은 순수 함수라 브라우저 없이 검증된다 |

## AI 에이전트용

### 이 디렉터리에서 작업할 때

- **새 문구는 `EN` 에 먼저 추가하고 `KO` 를 채운다.** 하나만 넣으면 타입 에러가 난다.
- **용어 정본표를 따른다.** 2026-08-04 전수 점검에서 *같은 개념이 화면마다 다른 이름으로 불리는*
  결함을 119건 고쳤다. 특히 갈라 놓아야 하는 것들:
  - `Hull` = 선체 / `HP`(플레이어) = 체력 / 적·코어·방어체의 HP = **내구도**
  - `Stash` = 창고 / `Collection`·`Stock` = 보관함 (섞지 않는다)
  - `Invasion` = **침략 단계**(행성 난이도)와 **침공**(PvP)으로 KO 가 나눠 놓았다. 병합 금지
  - `Elite` = 정예(엘리트 ✗) · `Wave`(L1 슬롯) = 편대(웨이브 ✗) · `Damage` = 피해량(데미지 ✗)
- 예외 둘: **좁은 칩은 축약 허용**(각 자리에 이유가 주석으로 남아 있다), **서사는 문체가 연출**
  (인트로·사연·기록 파편은 문어체, 도발 스티커는 반말). UI 문장은 존댓말로 통일.
- 직역 함정 이력이 주석에 있다 — 은유가 한국어에서 살지 않으면 규칙을 그대로 적는다.
- 콘텐츠명(행성·적·파워업)은 데이터 레이어 소유라 여기 없다. 하네스·치트 패널은 개발 도구라 제외.
