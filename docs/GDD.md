# 게임 설계 문서 (GDD) — Planet Blitz

> 용어는 [CONTEXT.md](../CONTEXT.md)를 따른다. 되돌리기 어려운 결정은 [docs/adr/](./adr/)에 기록되어 있다.
> ✅ = 인터뷰에서 확정된 사항, 📝 = 확정 사항에서 개연성 있게 채운 제안(변경 가능), ❓ = 미결.
> 2026-07-15 딥 인터뷰(12라운드, 최종 모호도 19%)로 대폭 상세화 — 전문은 [.omc/specs/deep-interview-shooting-detail.md](../.omc/specs/deep-interview-shooting-detail.md).

## 1. 정체성

- ✅ 타이틀: **Planet Blitz** (한글 병기: 플래닛 블리츠)
- ✅ 탄막 슈팅 × 디아블로2 파밍 × 뱀파이어 서바이벌 런 구조 × 비동기 PvP(타워디펜스 역공)
- ✅ CrazyGames 출시, WebGL, 1920×1080 기준 (레터박스 스케일링)
- ✅ 1차 출시는 데스크톱 전용. 입력 추상화·해상도 독립 설계로 모바일 확장로 확보
- ✅ 수익화는 CrazyGames SDK 리워드 광고 2지점만 (PvE 사망 부활 1회 / 런 정산 보너스). 침공에서는 부활 불가
- ✅ PvE + PvP 모두 완성한 뒤 출시 (부분 선출시 없음)
- ✅ 본질 정의: **"내 위의 누군가를 끌어내리는 게임"** — 래더 등반이 목적, 파밍·빌드는 연료. 밸런싱 충돌 시 PvP 공정성 우선

한 줄 피치: **"행성을 침략해 장비를 파밍하고, 그 힘으로 나보다 높은 랭커의 기지를 뚫어 자리를 빼앗는 탄막 슈팅."**

## 2. 코어 루프

```
행성 침략(PvE 런, 기준 시간 약 2분·창발적)
  → 전리품(장비·크레딧·희귀 광물·경험치)
  → 기지에서 영구 성장(스킬트리·장비·리롤) + 방어 배치 강화·정비
  → 더 높은 난이도 티어 파밍 ⟲
  → 상위 랭커 기지 침공(PvP) → 래더 순위 스왑 + 복제 약탈 ⟲
  → 만렙 도달 → 퇴역(수호 기체 배치 + 새 기체 시작) ⟲⟲   ← 엔드게임 대순환
```

풍화가 전체 루프에 시간 압력을 걸어 접속·소비·순위 변동을 순환시킨다.

## 3. 전투 (PvE 런)

- ✅ 아레나 서바이벌 + 탄막: 넓은 탑다운 아레나, 적 떼가 사방에서 접근하며 탄막 패턴을 발사. 공격은 자동, 플레이어는 회피·포지셔닝에 집중
- ✅ 런 길이 = 창발적(고정 아님). 기준 시간(par) 약 2분(웨이브 약 1분 + 보스 약 1분), 적정 레벨·티어 기준. 웨이브는 고정 타이머가 아니라 **처치 할당**으로 진행하고 못 채우면 **급행 소환**으로 압박 → 강하면 짧게·약하면 길게. 보스전에도 일반몹이 계속 등장해 화력 부족 시 몹 누적으로 자연 사망(별도 제한시간·enrage 없음). 웨이브 진행 후 마지막에 보스 등장 (ADR-0011)
- ✅ **파워업 = 장비 증폭식**: 런 내 레벨업 3택은 장착 장비·투자 스킬에서 파생된 강화·변형 (예: 발칸 연사속도↑, 미사일 분열, 대시 쿨다운↓, 실드 반격 폭발). 임시 무기 추가 없음 — 내 빌드가 깊을수록 파워업 풀도 진화하여 파밍↔런이 상호 강화
- ✅ 드랍: 엘리트·보스만 장비를 바닥 드랍(등급색 빔), 잡몹은 자원·경험치 젬. 수거분은 사망해도 전량 보존, 사망 페널티는 보스 보상(확정 고등급 드랍) 상실
- 🔜 **레이더**(우상단 HUD): 무한 스크롤 월드라 전체 지도가 아닌 플레이어 중심 미니맵. 보스·엘리트, 드랍 아이템·장비, 기믹·해저드 표시(잡몹 제외). 중범위 + 사거리 밖은 테두리 방향 화살표, 북 고정, 렌더 전용 (ADR-0009)
- ✅ 모든 런은 [시드+입력로그] 리플레이 제출 (ADR-0005) — 전투 로직은 고정 타임스텝 결정론, 렌더 분리
- ✅ **재미 요소 (2026-07-15 선별, 스펙: deep-interview-fun-factors)**:
  - **젬 콤보** (M1): 경험치 젬 연속 수집 시 콤보 배율(최대 x1.5) — 이동 동선의 미니게임화
  - **보급선 습격** (M1): 런 중 등장하는 적 보급선(20초 제한), 격추 시 확정 장비 드랍
  - **격추 유머 연출** (M1): 격추 시 우스꽝스러운 사출·낙하산 탈출 — 패배 좌절 완충
  - **변칙 경보** (M2): 런 시작 시 ~25% 확률로 변칙 조건 제안(수락/거부 선택) — 중력 폭풍(탄속↓·드랍+50%) / 군체 대발생(적 2배·약체) / 암흑 성운(시야↓·유니크 2배) 등. 시드 RNG 발동(ADR-0005 준수)
  - 🔜 v1.1: 유성우 타임 (§15)
- ✅ **패턴 시스템 (2026-07-15 확정, 스펙: deep-interview-enemy-patterns-difficulty)**:
  - 적 20종 전부 고유 패턴 — 구현은 공용 **패턴 컴포넌트 엔진**(발사체×궤적×타이밍 조합, 시드 RNG), 고유함은 디자인 데이터로
  - 🔜 **탄 거동 다양성** (색=거동): 적탄 거동 카탈로그 = 직진(속도변화)·유도(호밍)·곡사(사인/가속회전)·분열(산탄). 거동은 sim(결정론), 시각은 렌더. **적 1종당 시그니처 거동**으로 몹 정체성 부여. 밀도는 보스·엘리트에 집중. 유도탄은 락 만료로 카이팅 반격 여지
  - 🔜 **판정점**: 플레이어 피격 판정을 기체보다 훨씬 작은 중심점으로 → 고밀도에서도 공정("빽빽해도 틈으로"). 판정점 미표시(관대한 히트박스 체감), 그레이징은 1차 무보상 (ADR-0010)
  - 잡몹 **역할 4슬롯 템플릿**: 행성당 돌격형·사수형·특수형·지원형 각 1종 (역할별 위협 기준선 공유, 슬롯 내 패턴은 행성별 완전 자유 — 20종 초안 매트릭스는 스펙 참조)
  - 웨이브 = **랜덤 조합**: 웨이브 카드 풀에서 시드 추첨 + 구간별 강도 예산표(화면 내 적 수·동시 탄 상한 300→2,000) — 난이도·성능 동시 제어
  - **보스 구조**: 3페이즈(HP 100/70/35%) — P1 시그니처 → P2 변형+지형 개입 → P3 발악. 전환 시 2초 연출+탄 전체 소거. 패턴 시전 직후 5초 **과열 창**(받는 피해 2배) — 접근 타이밍의 공격적 재미
- 📝 조작: WASD/방향키 이동 + 마우스 이동 겸용. 대시(스페이스, 쿨다운·무적프레임)는 기동 계열 스킬로 강화
- 📝 파워업 풀 24종: 주무기 파생 5타입×2종 = 10, 보조무기 파생 5, 스킬 파생 계열당 3×3 = 9

## 4. 영구 성장

- ✅ 기체 = 디아2의 캐릭터. 3계열 스킬트리, 포인트 분배로 빌드 구성
- ✅ **기체 레벨 캡 100** — 스킬 포인트 총 99. 노드 비용 총합 ~250포인트(계열당 ~85)로 설계해 최대 40%만 커버 → 빌드 선택 강제. Lv70+ 구간은 경험치 요구 급증(3티어 반복 파밍 구간)
- ✅ 티어 진입 요구: 2티어 = Lv30, 3티어 = Lv60
- ✅ 리스펙: 크레딧 비용 (레벨 비례 증가)
- ✅ **퇴역 (엔드게임 순환)**: 만렙 기체를 퇴역시키면 ①빌드·장비 스냅샷 그대로 기지 방어의 AI **수호 기체**로 참전 ②새 기체 타입 해금(새 3계열 트리 = 사실상 새 클래스) ③**계보 포인트** 기본 지급 ④기존 수호 기체 일괄 소멸 선택 UI 제공. 파밍 장비는 창고 공유로 재사용
- ✅ **계보** (구 계승 특전 흡수·대체, ADR-0007): 계정 영구 트리 — [기체 가지](내 기체 소폭 강화) + [수호 가지](모든 수호 기체 강화). 포인트 원천: 퇴역 기본 지급 + 수호 기체 소멸(성능 비례). 무한 투자 가능하되 효과는 로그 스케일 (📝 점근형: 보너스 총합 +50% 수렴 — PvP 고착화 방지). 리스펙 없음. UI는 연구소
- ✅ 1차 출시 기체 2종: 스타터 + 퇴역 해금 1종. **퇴역 해금 기체는 선택제**: 타이탄형(고HP·고화력·저속·대시 쿨다운↑) / 인터셉터형(고속·대시 특화·저내구) 중 스탯 프리셋을 선택, 3계열 트리는 공유(전용 트리 분화는 출시 후 확장)
- 📝 3계열 트리 초안 (계열당 20노드, 노드당 1~5포인트):
  - **화력 계열** — 주무기·보조무기 강화, 관통·연쇄·폭발 변형. 최상위: 탄막 상쇄 레이저
  - **생존 계열** — 장갑·실드 강화, 피격 반응(반격 펄스), 실드 재생. 최상위: 치명타 1회 무효
  - **기동 계열** — 이동·대시 강화, 자석 반경, 파워업 선택지 +1. 최상위: 대시 잔상이 탄막을 지움
- 📝 디아2식 시너지: 하위 노드 투자 포인트가 상위 노드 효과를 소폭 증폭
- ✅ 수호 기체: 보유 무제한, 방어전 동시 투입 최대 2기 (배치 포인트 예산과 별도 슬롯)
- ✅ **수호 기체 생애주기** (ADR-0007): 수명형 — 풍화로 성능 감쇠(📝 주 5%p, 100→50% 바닥, 약 10주), 정비·회복 불가, 자동 소멸 없음. **소멸**은 방어 사령부에서 상시 가능하며 계보 포인트 = 전투력 점수 비례 × 남은 성능 → "신선할 때 회수 vs 말년까지 활용"의 상시 딜레마. 순환: 퇴역 생성 → 노후화 → 소멸 회수 → 계보 강화 → 다음 세대 더 강함
- ✅ 스냅샷 정체: 퇴역 시 장비 원본은 자동 창고 반환, 수호 기체는 능력치 **복사 스냅샷** + 퇴역 순간의 **전투력 점수**(장비·어픽스·빌드 종합) 기록 — 좋은 장비로 퇴역할수록 강한 수호기·높은 회수가치
- ✅ 계보 수호 가지 구성: 대부분 반복 투자형 수치 노드(피해↑·내구↑·풍화 속도↓) + 마일스톤 질적 노드 3~4개(📝 격추 시 1회 재기동 / 코어 근접 수비 모드 / 실드 공유)
- 📝 수호 기체 AI: 방어전에서 침입자를 요격하는 이동형 유닛 (포탑과 달리 추적형). 기본 성능은 스냅샷 기준 × 남은 성능 % × 계보 수호 가지 보너스

## 5. 장비·아이템

- ✅ 슬롯 7종 8칸: 주무기 / 보조무기 / 장갑 / 실드 / 엔진 / 코어 / 모듈×2
- ✅ 등급 4단계: 노말 → 매직(어픽스 1~2) → 레어(어픽스 3~6) → 유니크(고정+고유 효과). 세트·소켓·룬워드는 출시 후 확장
- ✅ **인벤토리**: 런 중 수거 무제한(자동 수거) → 기지 인벤 48칸(6×8) + 창고 96칸(크레딧으로 2회 확장). 아이템 1×1 고정. 창고는 기체 간 공유(퇴역 순환의 기반)
- ✅ **분해**: 노말·매직 → 크레딧, 레어 이상 → 희귀 광물 소량. 인벤 가득 시 일괄 분해 UI — 버리기가 손해가 아닌 변환
- ✅ 볼륨(표준판): 주무기 5타입(발칸/스프레드/레일건/미사일/빔) / 보조무기 5종 / 어픽스 접두 12+접미 12 / 유니크 15점
- ✅ 어픽스 리롤: 희귀 광물 소모 크래프팅 (최종 싱크)
- ✅ **어픽스 잠금 리롤** (M3): 리롤 시 어픽스 1개 잠금 가능(광물 비용 3배) + 슬롯머신식 롤링 연출 — "거의 완성된 레어"의 도박 재미
- ✅ **유니크 세리머니** (M2): 유니크 드랍 순간 0.5초 슬로모+전용 사운드+금빛 플래시 (렌더 계층 전용 — 시뮬 결과 무영향)
- ✅ 어픽스 24종 = 접두 12(공격) + 접미 12(유틸·생존). **원소 3종(화염·냉기·전격)은 상태이상 시스템과 함께 M3 투입** — M2는 원소 제외 21종으로 시작, M3에서 24종 완성(전체 목록은 M2/M3 계획 참조)
- ✅ 유니크 15점 = M2 5점(주무기 3타입 대표 각 1 + 보조무기 1 + 범용 1) + M3 10점(슬롯 7종 전체 커버). 예: "쌍둥이 항성" (스프레드 — 발사체 2배, 피해 -30%, 피격 시 실드 대신 탄 소멸). 전체 15점 목록은 M2/M3 계획 참조

## 6. 월드 — 행성

- ✅ 행성 = 점령되지 않는 반복 파밍 스팟. 행성별 특산 자원·드랍 테이블. 클리어 시 상위 티어 해금
- ✅ **행성 완전 병렬**: 4개 파밍 행성은 동일 출발선(난이도 사다리 없음) — 차별화는 특산 광물·패턴 스타일, 진행감은 티어가 전담
- ✅ 난이도 티어 3단계: 정찰 → 교전 → 섬멸 (진입: Lv1 / Lv30 / Lv60). 티어마다 적 강화 + 드랍 상향 + 고유 희귀 광물 추가
- ✅ **티어 스케일링 = 패턴 진화 중심**: 수치 배율은 완만(📝 HP ×1/×2.2/×4.5 — HP 스펀지 금지), 교전 = 기존 패턴에 서브탄 추가, 섬멸 = 패턴 변형+밀도↑ (수치만 다른 티어 금지)
- ✅ **엘리트 어픽스**: 상위 티어 엘리트에 디아2 챔피언식 랜덤 수식어 부여 — 📝 풀 8종(분열하는·가속하는·보복하는·자기장·은폐하는·소환하는·완강한·과충전), 교전 1개/섬멸 2개, 명판 표시("분열하는 격자포"), 보유 시 드랍 상향, 시드 RNG 부여
- ✅ 적 볼륨: 잡몹 행성당 4종×5행성 = 20종(역할 4슬롯: 돌격·사수·특수·지원) / 엘리트 행성당 2종 = 10종 / 보스 5종(각 3페이즈) — 20종 고유 패턴 초안 매트릭스는 [스펙](../.omc/specs/deep-interview-enemy-patterns-difficulty.md) 참조
- 📝 1차 출시 행성 5개 (기존 초안 유지):
  | 행성 | 테마 | 특산 광물 | 보스 컨셉 |
  |---|---|---|---|
  | 베르단 | 초원·군체 곤충 | 키틴 결정 | 여왕 무리개체 (소환+포위 탄막) |
  | 카르곤 | 화산·중장갑 | 화성암 코어 | 용암 요새 전차 (장판+직선 탄벽) |
  | 니플헤임 | 빙설·유령 함대 | 극저온 파편 | 유령 기함 (레이저 그물+감속 지대) |
  | 아르케 | 고대 기계 유적 | 유물 회로 | 수호자 오벨리스크 (기하학 회전 탄막) |
  | 홈월드 궤도 | 튜토리얼 | — | 해적 두목 (기초 패턴 교본) |

## 7. 기지

- ✅ 기지 = 홈 행성의 거점. 영구 성장 관리 + 방어 배치
- ✅ **화면 구조 = 기지 맵 공간 연출**: 픽셀아트 기지 맵에서 건물 클릭으로 기능 진입 — 격납고(장비·인벤·분해) / 연구소(스킬트리·퇴역) / 정제소(어픽스 리롤) / 방어 사령부(방어 배치·정비) / 관제탑(래더·침공·리플레이). 미해금 건물은 잠금 연출로 해금 순서 자연 노출
- 📝 해금 순서: 튜토리얼 런 직후 격납고 → Lv3 연구소 → 행성 1클리어 정제소 → Lv10+행성 2클리어 방어 사령부·관제탑(PvP 해금)

## 8. PvP — 침공과 방어

- ✅ 코어 파괴형: 제한시간 3분 내 코어 파괴 시 승리, 시간 초과·격추 시 실패. PvE와 동일 조작, 부활 불가
- ✅ 방어는 자동 (비동기). 배치 = 포탑 6종 + 장애물 + **수호 기체**(퇴역 기체 AI), 배치 포인트 예산제(전원 동일 + 시설 업그레이드 소폭 증가)
- ✅ **검증 = 결정론 리플레이 전수 재실행** (ADR-0005). 위조 불가능 수준
- ✅ **리플레이 관전**: 방어자는 자기 기지가 공격당한 리플레이를 관전 가능 (검증 구조의 부산물, 기존 ❓ 해소)
- ✅ 성공 보상: 래더 순위 스왑 + 복제 약탈 (ADR-0003)
- ✅ **배치전**: PvP 해금 시 첫 5회는 NPC 시드 기지 대상 → 성적으로 초기 순위 삽입(기존 유저 순위 무변동)
- ✅ **비활성 침하**: 30일 미접속 계정은 주기적 순위 하락
- ✅ **복수전** (M4): 침공당해 순위를 잃으면 24시간 내 '복수' 역침공 — 쿨다운 무시, 성공 시 자리 탈환+보너스 광물. 빼앗기고 되찾는 감정 루프
- ✅ **도발 스티커** (M4): 침공/방어 성공 시 미리 설정한 스티커 1개가 상대 알림에 표시. 사전 제작 세트에서만 선택(자유 입력 금지 — 독성·검열 비용 차단)
- 🔜 v1.1: 리플레이 극장, 철옹성 현상금 (§15)
- 📝 침공 대상: 내 순위보다 높은 유저 중 기본 제안 3명(바로 위 ~ +30위 랜덤) + 갱신. 동일 대상 재도전 쿨다운 1시간, 실패 페널티 없음
- 📝 방어자 보상: 방어 성공 기록당 소량 크레딧 (접속 시 수령)

## 9. 경제

- ✅ 크레딧 (범용): 방어 시설 건설·**정비**, 기본 업그레이드, 리스펙, 창고 확장
- ✅ 희귀 광물 (행성·티어별 특산): 상위 방어 시설, 어픽스 리롤
- ✅ 분해·복제 약탈로 두 자원 모두 추가 획득
- ✅ **풍화** (ADR-0006): 주기적 자연 감쇠, 두 대상 — **자원·장비·레벨·순위는 대상 아님**
  - ①방어 시설 정비도: 주 1회(일요일 자정 UTC) -5%p, 정비도 0%면 포탑 성능 50%까지 저하. 정비(크레딧)로 회복
  - ②수호 기체 성능: 주 5%p 감쇠, 바닥 50%, 회복 불가(수명형) — 소멸→계보 포인트 회수가 대응 수단 (§4, ADR-0007)
  - 상위 랭커일수록 유지 부담↑ → 방치된 상위 기지에 도전 창. 하락 예고·알림 UI 필수
- 📝 싱크 우선순위: 리롤(무한 싱크) > 정비(주기 싱크) > 시설·창고(유한 싱크) — 자원 축적 문제는 풍화가 아닌 싱크로 처리

## 11. 기술

- ✅ TypeScript + PixiJS v8, RPG UI는 DOM 오버레이 (ADR-0001)
- ✅ **전투 시뮬 코어 = 플랫폼 독립 순수 TS 모듈** (ADR-0005): 고정 타임스텝, 시드 RNG 전용(`Math.random`/`Date.now` 금지), 클라이언트(렌더 연결)와 Edge Function(검증)에서 동일 실행
- ✅ Supabase (ADR-0002): Postgres(유저·장비·래더·방어 배치·리플레이) + Edge Functions(침공 전수 검증·순위 스왑·PvE 샘플링 검증) + pg_cron(풍화·침하 주기 실행)
- ✅ PvE 검증 = 샘플링 재실행: 래더 상위 N%·통계 이상치(시간당 획득량 상한 초과)·랜덤 소수. 적발 시 런 무효+계정 플래그
- 📝 CrazyGames SDK: 로그인 연동, 리워드 광고, 진행도 클라우드 저장 병행
- 📝 에셋 파이프라인: 픽셀랩포지 PNG → 스프라이트시트 패킹 → PixiJS 로더

## 12. 화면 목록

📝 타이틀 → 기지 맵(허브) → [격납고 / 연구소 / 정제소 / 방어 사령부 / 관제탑] + 행성 선택(성계 지도) / 런(전투) / 정산 — 총 10화면. 첫 실행은 타이틀 → 즉시 튜토리얼 런(표준보다 짧은 단축판 — 새 런 모델(ADR-0011)에 맞춰 수치 재조정 예정) → 첫 드랍 → 기지 공개 (✅ FTUE 확정: 입력 후 60초 내 전투)
