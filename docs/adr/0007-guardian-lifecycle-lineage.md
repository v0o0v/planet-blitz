# 수호 기체는 수명형 순환 자원 — 소멸·계보 시스템

수호 기체(퇴역 기체의 방어 AI)를 영구 보존물로 두면 보유 무제한 정책과 맞물려 무한 축적되고, 오래된 스냅샷이 영원히 방어를 지키는 정체 구조가 된다. 운영자 요구(2026-07-15 딥 인터뷰)로 수호 기체를 **생애주기 순환 자원**으로 재설계했다: 퇴역으로 생성 → 풍화로 노후화(주 5%p, 바닥 50%, **정비·회복 불가**) → **소멸**로 계보 포인트 회수(남은 성능 비례, 상시 가능) → **계보** 트리 강화로 다음 세대 수호 기체가 더 강해진다. 기존 계승 특전은 계보의 기체 가지로 흡수·폐지되었다.

## Considered Options

- **개별 수호 기체 강화** — 수명형 풍화로 결국 소멸할 대상에 투자하는 손실 구조라 기각. 포인트는 계정 단위 계보에만 쌓여 개체 소멸과 무모순
- **수호 기체 정비 허용** — 소멸 동기가 사라져 포인트 순환이 작동하지 않으므로 기각
- **계보 상한(유한 트리)** — 권장이었으나 운영자가 무한+로그 스케일 선택. 고착화 재생산 리스크는 점근형 수치(보너스 총합 +50% 수렴 제안)로 통제

## Consequences

- "낡은 수호기를 계속 쓸까, 신선할 때 회수할까"가 상시 결정이 된다 — 방치 유저는 회수량도 자연 손해를 봐서 순환이 가속된다
- 자동 소멸은 없다(바닥 50% 유지) — ADR-0003 무손실 철학 유지. 유저 행동 없이 수호 기체가 사라지는 경로를 만들지 말 것
- 계보 투자는 리스펙 불가 — 포인트가 순환 재화이므로 환불 루프를 열면 경제가 무너진다
- ADR-0006의 "풍화는 정비도에만" 조항은 본 ADR로 개정되었다
