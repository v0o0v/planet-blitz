# 방어 카드 — 효력은 스냅샷 고정, 사용 횟수 차감은 결과 확정 시

방어 카드(침공당할 때 자동 발동되는 소모성 방어 강화 카드)를 침공 파이프라인에 태우면서, 두 가지 시점을 결정해야 했다: ① 카드 효력이 어느 시점의 카드를 기준으로 하는가, ② 사용 횟수는 언제 차감되는가. 결정(2026-07-18 그릴링): **효력은 `begin_invasion` 스냅샷에 카드(효과+남은 횟수)를 함께 고정하고, 차감은 `apply_invasion_result`로 결과가 확정될 때만 서버가 수행한다.** 이는 기존 정비도·수호 기체 권위 주입(ADR-0005/0007, M5 스냅샷)과 동일한 패턴이다.

대안은 침공 시작 시 즉시 차감이었다. 즉시 차감은 직관적이고 구현이 단순하지만, 공격자가 침공을 **시작만 반복하고 런을 버리는 것**으로 방어자의 카드를 공짜로 고갈시키는 악용(카드 빼기 간보기)이 가능하다. 카드는 유한 소모품이자 희소 자원이므로, 방어자가 아무 전투도 치르지 않고 자원을 잃는 경로는 열어둘 수 없다.

## Consequences

- 사용 횟수 차감은 서버 전용이다 — `apply_invasion_result` 확정 경로에서만 감소하며, 클라이언트는 카드 횟수를 직접 쓸 수 없다(기존 가드 트리거 패턴)
- 공격자가 런을 제출하지 않으면(포기·이탈) 방어자의 카드는 닳지 않는다 — 승패와 무관하게, "확정된 침공 1건 = 차감 1"
- 카드 효력은 스냅샷 시점 기준이므로, 침공 진행 중 방어자가 카드를 교체·소진해도 그 침공의 판정은 변하지 않는다 — 레이스 컨디션 없음
- verify-invasion EF는 제출된 config가 아니라 스냅샷의 서버 권위 카드 데이터로 재실행한다 — 카드 효과 위조 불가
- 동시 침공 다건이 같은 스냅샷 카드를 참조할 수 있으므로, 잔여 횟수가 0이 된 뒤 확정되는 침공도 카드 효력은 유지된다(스냅샷에 이미 실렸으므로) — 차감은 바닥 0에서 멈춘다
