# 풍화 — 시즌 리셋 대신 방어 시설의 주기적 자연 감쇠

영구 래더(ADR-0004)는 시즌 리셋이 없어 상위권 고착이 구조적 문제다. 시즌제 대신 **풍화**를 도입한다: 방어 시설의 정비도가 주기적으로 하락(시작값: 주 5%p, 0%에서 포탑 성능 50%까지 저하)해 방치된 기지의 방어가 서서히 약해지고, 접속해 크레딧으로 **정비**하면 회복된다. 상위 랭커일수록 시설이 많아 유지 부담이 크므로, 방치된 상위 기지에 하위 랭커의 도전 창이 자연히 열린다. 운영자 요구(2026-07-15 딥 인터뷰 R11~14): "시즌제가 없는 문제를 자연 감쇠 개념으로 해소" — 용어는 실제 천문학 용어인 풍화(space weathering)로 확정.

## Consequences

- **풍화는 정비도에 작용하고, 자원·장비·기체 레벨·래더 순위는 감쇠하지 않는다** — 초안의 자원 감쇠(주 8%)는 인터뷰 R14에서 운영자가 명시 철회했다. 이로써 ADR-0003(오프라인 실손실 없음 철학)과 완전히 정합: 방치로 잃는 것은 "방어력"뿐이며, 그것이 곧 래더 순환 장치다
- **개정 (2026-07-15, ADR-0007):** 수호 기체 성능도 풍화 대상에 추가되었다 — 단, 시설과 달리 회복 불가(수명형)이고 바닥 50%에서 멈추며 자동 소멸은 없다. "방치로 잃는 것은 방어력뿐" 원칙은 유지된다
- 순위 하락은 여전히 침공당해야만 발생한다 — 풍화는 뚫리기 쉽게 만들 뿐 직접 순위를 깎지 않는다 (직접 감점은 비활성 침하가 담당)
- 자원 무한 축적 문제는 풍화가 아닌 소비 싱크(어픽스 리롤·정비·시설)로 처리한다
- 정비 비용은 크레딧의 주기적 싱크가 되어 경제 순환에 기여한다
