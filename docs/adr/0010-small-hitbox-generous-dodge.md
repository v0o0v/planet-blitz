# 피격 판정은 기체보다 훨씬 작은 판정점

고밀도 탄막에서 "피하는 맛"을 공정하게 만들기 위해, 플레이어 피격 판정을 기체 스프라이트 반지름이 아니라 그보다 훨씬 작은 **판정점**(중심의 작은 원)으로 잡는다. 이렇게 하면 화면이 탄으로 빽빽해도 실제로는 틈으로 빠져나갈 수 있어, 탄 수를 크게 늘려도 불공정하지 않다. 판정점은 플레이어에게 표시하지 않는다 — 관대한 판정을 명시적 UI 없이 체감으로 전달한다(억울한 피격 대신 "아슬아슬하게 살았다"는 감각).

## Consequences

- 적탄 수·밀도를 보스·엘리트 구간에서 공격적으로 올릴 수 있는 여지가 생긴다 — 판정이 작지 않으면 같은 탄 수가 곧바로 불공정해진다
- 기존 밸런스(접촉 피해·탄 수)는 판정점 기준으로 재조정이 필요하다 — 기체 반지름 판정 전제로 튜닝된 수치는 판정점에서 너무 쉬워지므로 사후 재튜닝
- 그레이징(판정점엔 안 닿고 기체를 스치는 근접 회피)은 1차에선 보상 없이 감각으로만 두고, 콤보·전용 게이지 보상은 확장으로 예약
- 판정점 미표시 대안(집중/포커스 모드로만 노출)은 입력·sim 변경이 필요해 1차 범위에서 제외 — 표시 안 함이 렌더·입력 변경 0
