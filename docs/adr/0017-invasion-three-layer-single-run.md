# 침공은 3레이어 연속 단일 런 — 단일 아레나 침공 폐지

기존 침공(단일 아레나에서 3분 코어 러시)은 엔드게임인데도 구조가 단순해 재미·긴장 곡선이 부족했다. 결정(2026-07-20 그릴링): **침공을 세 개의 레이어 — 레이어 1(행성 외곽, 아래→위 강제 종스크롤 약 90초) → 레이어 2(기지 내부 회랑, 좌→우 강제 횡스크롤 약 90초) → 레이어 3(코어 방, 고정 화면 최대 120초) — 를 끊김 없이 통과하는 단일 런(총 상한 5분)으로 재설계한다.** 체력·자원은 레이어 간 승계되고, 중간 사망은 침공 실패이며 체크포인트는 없다. 시점은 세 레이어 모두 톱다운으로 유지하고 스크롤 방향·배경 아트만 달리한다. 미출시 상태이므로 기존 단일 아레나 침공 자산(15×9 격자·포탑 6종·배치 포인트 예산)의 보존은 고려하지 않는다.

대안은 ① 레이어별 체크포인트(사망 시 해당 레이어부터 재개), ② 레이어별 독립 출격(순차 공략)이었다. 둘 다 방어의 앞단(레이어 1·2)을 "한 번만 뚫으면 되는 소모 없는 관문"으로 격하시켜, 방어자의 3중 방어선이 소모전으로서 갖는 의미(레이어 1에서 깎은 체력이 레이어 3에서 결실)를 파괴한다. 단일 런은 검증도 리플레이 1개로 끝나 기존 결정론 전수 검증(ADR-0005) 파이프라인을 그대로 쓴다.

## Consequences

- 강제 스크롤 카메라·스폰 체계는 신규 구현이다 — 현재 게임에는 강제 스크롤이 없다(PvE·구 침공 모두 플레이어 추적 카메라). sim 결정론 규율 안에서 카메라 진행을 틱 함수로 구현해야 한다
- 레이어 1·2의 시간은 상한이지 고정이 아니다 — 구간 전멸 시 스크롤 가속(전멸 가속, 최대 ×2 수준)으로 강한 공격자는 빨리 돌파한다(PvE 처치 할당 철학의 일관 적용)
- verify-invasion의 재실행 시간 예산 상한이 180초×60틱에서 300초×60틱으로 늘어난다
- 빈 슬롯·소켓은 기본 수비대(행성 소속 최저 등급 편대·설비)가 자동 충원한다 — 신규·방치 기지 침공이 빈 스크롤이 되는 것을 막는다
- 방어 사령부는 레이어별 편집 체제로 재편된다 — 레이어 1은 웨이브 슬롯(편대 꽂기), 레이어 2는 맵 템플릿+설치 소켓, 레이어 3는 보스 슬롯 1·수호 기체 슬롯 2·기물 소켓+코어
- 방어 전력 총량 제한은 "슬롯이 곧 예산"이다 — 별도 코스트 포인트 예산 없음, 공정성은 래더 매칭이 흡수
