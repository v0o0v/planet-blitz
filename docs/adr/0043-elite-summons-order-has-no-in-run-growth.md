# ADR-0043 — 정예 소집령은 런 내 성장이 0 이다

- 상태: 채택 (2026-07-31)
- 관련: ADR-0042(의뢰 런은 모드를 갈아탄다) · ADR-0011(창발 런 길이 = 처치 할당) ·
  ADR-0035(표준 진행 경로) · ADR-0036(XP 이중 풀) · ADR-0030(장비 요구 레벨 게이트)

## 맥락

**정예 소집령**은 의뢰서의 **주문** 한 종류로, 잡몹이 전혀 나오지 않고 엘리트·보스급만
연달아 내려온다.

여기서 이 저장소의 드랍 규율과 정면으로 만난다 — **장비는 엘리트·보스만 바닥에 떨구고,
경험치 젬은 잡몹만 남긴다.** 그래서 잡몹이 0 이면 젬이 0 이고, 젬이 0 이면 런 내 레벨업이
0 이며, 레벨업이 0 이면 **파워업 3택이 한 번도 열리지 않는다**.

이게 왜 큰가 하면, 현재 밸런스 전체가 그 반대를 전제로 앉아 있기 때문이다. 2026-07-27 밸런싱
패스는 표준 빌드 기준 **런당 레벨업 6.1~7.7 회**를 실측해 그 위에 클리어율·par(95초)·전리품
기대치를 맞췄다. 파워업 0 인 런은 그 기준선 바깥에 선다.

동시에 두 번째 구멍이 열린다. 지금까지 "화력이 부족한 플레이어"의 런 길이를 캡한 것은
enrage 도 제한시간도 아니라 **잡몹이 쌓여 자연히 죽는 것**이었다. 잡몹이 없으면 그 캡이
통째로 사라져 "못 죽이는데 안 죽는" 교착이 가능해진다.

## 결정

**정예 소집령에서는 런 내 성장을 아예 일으키지 않는다 — 경험치 젬도, 레벨업도, 파워업
3택도 없다.** 플레이어는 영구 성장(장비·스킬 투자·계보)만으로 보스급을 상대한다.

교착은 **급행 소환의 정예판**이 끊는다 — 처치가 늦으면 다음 정예가 겹쳐 내려온다. 고정
제한시간도 보스 enrage 도 쓰지 않는다.

## 근거

**이 주문의 재미가 정확히 거기에 있다.** 정예 소집령은 파밍 런이 아니라 **빌드 시험대**다 —
"내가 지금까지 키운 것만으로 이만큼을 상대할 수 있는가"를 묻는 자리이고, 런 중에 파워업으로
따라잡는 순간 그 질문이 사라진다. 파워업을 선지급해 채워 넣는 절충안도 검토했으나, 그러면
"의뢰서가 지정한 빌드로 싸운다"가 되어 **제약 계약**과 결이 겹쳐 주문 종류를 하나 줄이는
것과 같아진다.

**교착 차단을 급행 소환으로 푸는 것은 기존 철학의 직역이다.** 이 저장소는 고정 웨이브 타이머를
의도적으로 폐지하고 "강하면 빨리 통과한다"는 창발 난이도를 전 모드에 걸어 왔다(ADR-0011).
정예가 겹쳐 내려오는 구조는 그 규칙을 그대로 적용한 것뿐이다 — 강하면 하나씩 깔끔하게 치우고,
약하면 화면이 보스급으로 빽빽해져 자연히 죽는다. 제한시간을 넣었다면 폐지한 고정 타이머를
되살리는 셈이고, enrage 를 넣었다면 보스에 없던 축을 새로 여는 셈이다.

## 결과

- **이 주문만 별도 난이도 기준선을 갖는다.** 파워업 0 을 전제로 정예·보스급 HP 와 겹침
  간격을 따로 계측해야 하며, 다른 주문·행성 모드의 계측에서 파생되지 않는다.
- **장비·스킬 투자의 체감 기여가 가장 선명하게 드러나는 콘텐츠**가 된다. 파밍의 성과가
  파워업 운에 가려지지 않는 유일한 자리다.
- 젬이 0 이므로 이 런은 **기체 레벨을 사실상 올리지 않는다** — 성장 동기가 보상 쪽에만 실린다.
- 런 내 성장이 없다는 사실이 UI 에 명시돼야 한다. 아무 설명 없이 파워업이 안 열리면
  플레이어는 그것을 결함으로 읽는다.

## 대안

- **정예가 잡몹 몫의 젬까지 떨군다** — 레벨 곡선을 보존하면서 "잡몹 없음"만 성립시키는 가장
  안전한 안이었다. 기각 이유는 위와 같다: 그러면 이 주문이 "정예가 많은 평범한 런"이 된다.
- **출격 시 파워업 선지급** — 제약 계약과 결이 겹친다.
- **잡몹을 0 이 아니라 극소로** — 기존 구조를 전혀 안 건드리지만 "보스급만 나온다"는 상연을
  희석해 이 주문이 존재할 이유를 지운다.
