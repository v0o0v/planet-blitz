# 래더는 영구제 — 시즌 리셋 없음

래더는 전 유저가 하나의 순위표에 줄서는 영구 구조이며, 침공 성공 시 공격자와 방어자가 자리를 맞바꾸는 사다리 방식이다. 시즌제(4~6주 리셋 + 시즌 보상)가 웹 게임 리텐션의 일반해지만, 운영자 판단으로 영구 래더를 선택했다: 구현·운영이 단순하고 "순위표의 내 자리"라는 감각이 명확하며, "나보다 높은 유저를 침략한다"는 게임의 핵심 판타지와 직결된다.

## Consequences

- 출시 후 시간이 지날수록 신규 유저의 진입 장벽(최하위 시작)이 커진다 — 배치전, 비활성 유저 순위 침하 같은 완화책이 밸런싱 단계에서 필요하다
- 시즌 보상 지급·리셋 파이프라인은 만들지 않는다. 추후 시즌제 전환은 래더 테이블 재설계를 수반하므로 사실상 일방통행 결정이다
