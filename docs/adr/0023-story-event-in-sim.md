# 런 중 서사 이벤트(에코 신호)는 sim 결정론 경로에 편입한다

스토리 시스템(2026-07-23 그릴링 세션)에서 "런 중간에 아주 가끔 이벤트가 발생하고, 해결하면 보상"이라는 요구가 나왔다. 런 내 보상(크레딧·기록 파편)에 영향을 주는 이상 이 이벤트는 sim 밖에 둘 수 없다 — 서버가 시드+입력로그 재실행으로 보상을 재검증하기 때문이다(ADR-0005). 그래서 **에코 신호를 기존 근접 트리거 이벤트 프레임워크(`src/sim/events.ts`)의 확장으로 sim 안에 넣는다.** 출현은 런 시드에서만 파생(초기값 약 3%, 런당 최대 1회 — 수치는 출시 전 밸런스 패스에서 재조정)해 클라이언트가 위조할 입력이 없고, 서버는 시드만으로 재검증한다. 목표는 안정화 버티기(반경 내 체류), 보상은 경제(크레딧)와 메타 수집(기록 파편)뿐 — 런 내 전투력에는 불개입해 밸런스 보류 방침과 충돌하지 않는다. 로어 텍스트 표시는 UI 레이어(i18n)의 일이며 sim은 이벤트 결과 플래그만 낸다.

## Considered Options

- **UI 오버레이만** — 결정론 완전 무접촉이지만 "해결하면 베네핏"이라는 핵심(인게임 행동→보상)이 빠져 기각.
- **정산 시점 이벤트** — sim 무접촉으로 팝업+보너스를 줄 수 있지만 "게임 중간에 자연스럽게"라는 요구와 어긋나(긴장감 없음) 기각.
- **피티 보장(무등장 N런 시 보장)** — 런 밖 카운터를 sim 입력으로 넣어야 해 입력 위조로 강제 등장 파밍이 가능해지고 검증 표면이 넓어져 기각. 순수 시드 확률 채택.

## Consequences

- 런 해시 계약에 신규 필드가 추가되므로 해시 마이그레이션 + `verify-pve-sample`·`verify-invasion` EF 재배포가 필요하다(Lane7 `shrinkRuntime` 선례의 절차를 따른다).
- 약 3% 확률이라 라이트 유저는 오래 못 볼 수 있다 — 기록 파편 도감(기록 보관소)의 수집 완성은 의도적으로 장기 콘텐츠다.
