# docs/adr — 아키텍처 결정 기록

## 목적

**되돌리기 어려운 결정** — 번호는 0001~0048, 파일은 50개다(번호가 중복된 쌍이 둘 있다:
`0029` 촉매/오디오, `0034` 조우/스크롤 앵커). 코드를 고치기 전에 여기서 "이미 정해진 것"을 확인한다.

## AI 에이전트용

### 이 디렉터리에서 작업할 때

- 새 ADR 은 **다음 번호**로 만든다(현재 최대 0048). 중복 번호를 또 만들지 않도록 `ls` 로 확인한다.
- 기존 결정을 뒤집을 때는 그 ADR 에 개정 표시를 남기고 새 ADR 에서 근거를 적는다 — **지우지 않는다.**
- 구현·문서·테스트가 ADR 을 인용할 때는 번호로 인용한다(코드 주석의 `ADR-00xx` 관용구).
