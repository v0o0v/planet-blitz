# 하네스는 DEV 전용, 오염 런은 정산·리플레이 제외

게임 흐름 전체(스크린 점프·fast-forward·치트·프로필 프리셋)를 제어하는 하네스를 도입하면서, ADR-0005의 결정론 리플레이 검증 계약과 충돌하지 않도록 두 겹의 격리를 결정한다: ① 하네스·치트 패널은 `import.meta.env.DEV`에서만 번들되어 프로덕션에 코드 자체가 존재하지 않는다. ② DEV에서도 치트·하네스 개입이 한 번이라도 일어난 런은 **오염 런**으로 표시되어 프로필 정산과 리플레이 제출에서 제외된다. 또한 하네스는 본 세이브와 분리된 **하네스 프로필** 슬롯만 읽고 쓴다.

## Consequences

- 오염 런은 전리품·XP를 남기지 않는다 — 치트로 만든 상태가 로컬 프로필에 정산되면 그 프로필로 만든 테스트·리플레이가 전부 의심스러워지므로, 편의보다 검증 계약 보호를 택했다
- "DEV 전용이니 플래그 불필요" 대안은 기각 — DEV에서도 치트 런이 로컬 프로필에 섞이면 개발 중 재현·버그 리포트의 신뢰가 깨진다
- 오토파일럿(결정론적 입력 봇)은 개입이 아니라 정상 입력 생성이므로 그 자체로는 런을 오염시키지 않는다 — 시드+입력로그가 온전하면 리플레이 재현이 성립하기 때문
- M4 PvP 서버 검증 구현 시 이 경계(무엇이 오염인가)를 그대로 준용한다
