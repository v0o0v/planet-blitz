# 조우 — 런 중 opt-in 희귀 이벤트 프레임워크(에코 신호 일반화)

행성 격침(PvE 침략 런)에 "행성 격침 시작할 때마다 어떤 이벤트를 만날까 두근두근"한 재미를 얹고 싶다는 요구가 나왔다(2026-07-24 그릴링) — 아예 생각지도 못한 곳으로 이동해 아이템을 다량 먹거나 매우 중요한 아이템을 얻는 식의 의외성. 이미 **에코 신호**(런당 ~3%, 서사, 반경 내 안정화 버티기, 크레딧+기록 파편, 전투력 불개입, ADR-0023)가 있으나 단일 유형·고정 연출·서사 한정이라 그 요구의 좁은 프로토타입에 그친다.

결정: **에코 신호의 검증된 뼈대(시드 롤 → 조건부 해시 폴드 → 반경 판정 → 보상)를 "조우" 프레임워크로 일반화하고, 에코를 그 안의 서사형 1종으로 흡수한다.** 프레임워크 계약:

- **보상은 경제·수집 축에만**(loot·젬·크레딧·희귀 광물·설계도·기록 파편) 국한하고 현재 런 전투력에는 불개입한다. 런 중 획득 아이템은 정산 귀속 경제이지 런 파워가 아니므로("파워업만이 런 전투력" 원칙·아이템 베제 0), "아이템 다량/중요 아이템" 요구를 밸런스 보류 방침과 무충돌하게 충족한다.
- **런당 최대 1회 · 희소(≈2% 플레이스홀더) · 순수 시드(피티 없음).** 드문 대박 순간으로 설계한다 — 두근두근은 매 런의 기대·복권 감각. 피티 카운터를 런 입력으로 넣지 않는 것은 강제 등장 파밍 위조를 막기 위함이다(ADR-0023 반치트 규율 계승).
- **전면 opt-in.** 무시하면 안전하게 런을 잇고, 들어가면(선택) 큰 보상과 실제 위험을 함께 진다.
- **실제 사망 가능.** detour/전투 조우에서 HP가 0이면 런 실패다(전리품은 보존되고 보스 처치 보상만 놓친다 — 기존 사망 모델과 정합). 사망 위험이 실재하므로 진입은 opt-in이어야 공정하다.
- **1차 결(bucket) 3종**: 탐욕 수집형(플래그십 **보물 격실** — 포탈로 진입하는 별도 보너스 공간 detour + 인라인 경량 **기록 파편우**·**유령 보급선단**)·도박 선택형(**오스카 제단** — 즉시 전리품/드랍·광물 부스트/봉인 상자[바닥 보장 상방 도박] 3택)·전투 도전형(**봉인 수호자** — 봉인을 열면 미니 수호자가 라이브 런 위에 오버레이, 웨이브 병행). 유형별 상세 형태는 CONTEXT.md glossary에 못박았고 수치는 밸런스.
- **모드별 맞춤.** 6개 행성 모드가 각자 정체성에 맞는 변형을 갖는다(공통 프레임워크 + 모드별 변형 레이어, 뱀서류를 첫 레퍼런스 구현).

## Considered Options

- **별개 신규 레이어**(에코와 공존하는 독립 시스템) — 두 개의 "런 중 드문 시드 이벤트"가 중복 개념·중복 해시 필드를 낳아 기각. 검증된 에코 뼈대 재사용이 결정론 리스크가 작다.
- **에코 폐기·흡수** — 서사형 수집(기록 파편 도감)이라는 에코 고유 가치를 지우므로 기각. 에코는 조우의 서사형으로 보존한다.
- **인라인(이동 없음, 현 에코 방식 유지)** — "아예 생각지도 못한 곳으로 이동"이라는 핵심 요구에 미달. 플래그십은 별도 보너스 룸으로 간다.
- **같은 월드 세트피스 워프**(별도 룸 없이 먼 좌표로) — 결정론 리스크는 낮으나 "딴 세상" 몰입이 약해 플래그십에서 기각(향후 경량 변형으로는 여지).
- **빈번+안전(회피 유발 방지)** — 사용자가 희소(2%)+실사망을 명시 선택. 드문 고위험·고보상 순간으로 확정.
- **경제 + 신규 런-파워 스파이크** — 파워업 모델·아이템 베제 0·밸런스 보류와 충돌하는 설계 이탈이라 기각. 경제·수집만.
- **강제 발생** — 2% 강제 사망 이벤트는 회피 불가 억울한 죽음이라 기각. 전면 opt-in.

## Consequences

- 런 해시 계약에 조우 런타임 신규 필드가 추가되나 **positive(조우 발생) 런에서만** 존재해 조건부 append-only 폴드한다 → 조우 미발생 런은 per-tick 해시가 바이트 불변이다(echo/shrink/scroll 런타임 선례). 해시 마이그레이션 + `verify-pve-sample`·`verify-invasion` EF 재배포가 필요하다(이 프로젝트 반복 절차).
- 플래그십 **보물 격실**의 별도 보너스 공간 = 메인 런 일시정지(세그먼트 시계·처치 할당·스폰 정지, 해시 필드) + 플레이어 좌표 워프 + 시드 파생 세트피스 스폰 + 복귀. 포탈 진입은 플레이어 입력(리플레이 로그), 방 내용물은 시드 파생이라 서버 재실행 재검증이 성립하나 `verify-pve-sample` 재실행 표면이 커진다.
- 보물 격실 방 규칙(2026-07-24 그릴 상세): **위험 구배**(입구 안전지대 자유 수집 + 안쪽 위험지대에 수호체가 지키는 **확정 고희귀 장비 1개**), 닫힘 **타이머 + 조기 이탈**(가진 것 보존, 만료 시 자동 이젝트), 방 안 처치는 메인 **처치 할당**에 불산입(진행 게이트 파밍 치즈 차단), HP 승계·방 내 사망은 런 실패(전역 실사망 규칙). 등급 분포·타이머 길이는 밸런스.
- 등장률 상향분은 정직 파밍 속도를 높이므로 **3중 캡**(지표 개연성·런당·시간당 상한)이 조우 잭팟을 감안해 재조정돼야 한다(밸런스 결과물, 치팅 방어선 유지).
- 6개 모드별 조우 변형 상세 설계는 다운스트림 per-mode 작업이다. 에코 신호는 기존처럼 전 PvE 모드에서 롤된다(inert라 모드 무관).
- 수치 전부(등장률·타이머·중요 아이템 등급·유형 가중치)는 밸런스 = 출시 전 일괄 튜닝 대상이며, 구조만 이 ADR로 고정한다.
