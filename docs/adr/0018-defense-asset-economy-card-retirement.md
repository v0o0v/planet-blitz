# 방어체 통합 수집 경제 — 방어 카드 시스템 폐지, 코어 모듈로 흡수

침공 3레이어 재설계(ADR-0017)로 방어자가 준비하는 대상이 편대·설비·기물·방어 보스·수호 기체·코어로 확장되면서, 방어 자산의 획득·강화 경제를 통일해야 했다. 결정(2026-07-20 그릴링): **모든 방어체는 장비와 동일한 4등급(노말→매직→레어→유니크)+방어체 어픽스 문법을 따르고, 획득은 PvE 런 드랍(주축)·제작·침공 약탈 복제(설계도), 강화는 방어체 레벨·승급(중복 설계도)·어픽스 리롤의 3축으로 한다. M6에서 구현 완료된 방어 카드 시스템은 별도 시스템으로는 폐지하고, 코어의 강화 슬롯에 장착하는 소모성 "코어 모듈"로 흡수한다** — 정적 카운터·동적 트리거·사용 횟수·스냅샷 고정(ADR-0012)·상점/합성/보관함 경제는 코어 모듈 경제로 재포장되어 존속한다.

대안은 ① 카드를 침공 전체 룰 카드로 병존시키는 것, ② 소모성까지 폐지해 영구 장비형 모듈로 만드는 것이었다. ①은 카드와 방어체가 "등급+어픽스+합성" 문법을 이중으로 가져 인지 부하·밸런스 포인트가 2배가 되고, ②는 "방어당할 때마다 닳는다"는 긴장감과 재화 순환 싱크를 잃는다. 소모성 유지는 사용자의 명시 선택이다.

## Consequences

- 구현 완료된 M6 카드 코드(cardEffects·cards RPC·cardsView)는 폐기가 아니라 코어 모듈로 개명·재배선된다 — 카드 어픽스는 "모듈 어픽스"로 전체 표기 변경
- 어픽스 주체가 넷이 된다 — 장비 어픽스 / 엘리트 어픽스 / 방어체 어픽스 / 모듈 어픽스. 단독 표기 금지 규칙은 CONTEXT.md에 기록
- 침공 약탈 복제는 ADR-0003(방어자 무손실)을 유지한다 — 낮은 확률로 상대 방어체 설계도를 "복제"하며 방어자는 잃지 않는다
- 방어 실적(방어 성공)은 방어체 획득 경로가 아니다 — 부익부 방지를 위해 보조 재화 수준으로만 열어둔다
- 풍화는 배치된 방어체에만 작용한다(정비로 회복, 수호 기체만 회복 불가) — 보관함의 수집품은 닳지 않아 수집 도파민과 충돌하지 않는다
