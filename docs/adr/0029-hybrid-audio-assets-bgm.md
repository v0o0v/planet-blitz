# BGM 에 한해 외부 오디오 에셋 도입 (하이브리드)

## Status

accepted

## Context

지금까지 사운드는 "외부 오디오 에셋 0" 원칙으로 전부 절차 합성(Web Audio oscillator/noise)했다(`src/render/audio.ts`). 이 결정의 명시적 이점은 **번들 크기 0**과 **라이선스 이슈 0** 이었다. 그러나 "풍부한 배경음악"은 절차 합성만으로 만들기 어렵다 — 드론·아르페지오 수준의 생성 음악으로는 전투·보스·침공의 곡조를 원하는 밀도로 뽑을 수 없다.

## Decision

**하이브리드**를 택한다 — SFX 는 절차 합성을 유지하고, **BGM 만 외부 음악 루프**(로열티프리·상업 라이선스 음원)를 도입한다. 사운드 존 5종(메뉴·기지 / PvE 전투 / 보스 / 침공 / 정산 스팅어)에 정적 트랙을 매핑하고 화면 전환 시 크로스페이드한다. 번들 영향은 지연 로딩 + 프리페치(ogg + mp3 폴백, 트랙당 ~1–2MB)로 유계한다. 결정론(ADR-0005)은 불변 — 모든 사운드는 render 계층이고 sim 은 소리를 모른다.

## Considered Options

- **완전 절차 유지**: 에셋 0·번들 0·라이선스 0 사수. 그러나 "풍부한 전투 음악"의 질적 한계가 분명해 기각.
- **외부 에셋 전면 도입(SFX 포함)**: 품질 상한 최고. 그러나 번들·로딩·라이선스·CrazyGames 제약 부담이 가장 크고, 절차 SFX 의 무한 변주·0코스트 이점을 버리게 되어 기각.

## Consequences

- CrazyGames 상업 배포를 위해 각 트랙의 출처·라이선스를 저장소에 기록해야 한다 — "라이선스 이슈 0" 원칙은 상실되고 관리 책임으로 대체된다.
- 볼륨 제어가 마스터 단일 게인에서 BGM/SFX/UI 3버스로 확장된다(설정 UI·`pb.audio` 저장 구조 마이그레이션).
- 음악 AI 생성(Suno/Udio 등)은 상업 사용권·저작권 귀속이 회색지대라 소스에서 배제했다.
