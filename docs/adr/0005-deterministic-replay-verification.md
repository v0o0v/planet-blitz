# 전투는 결정론 시뮬 + 리플레이 검증 아키텍처

웹 클라이언트는 완전히 위조 가능하고, 영구 래더(ADR-0004)는 치터 오염 시 복구가 안 된다. 이를 근본 차단하기 위해 전투 로직을 **고정 타임스텝 결정론 시뮬**(시드 RNG 전용, 렌더와 분리된 순수 TS 모듈)로 설계하고, 모든 런이 [시드+입력로그] 리플레이를 제출한다. 침공(PvP)은 Edge Function이 전수 재실행해 결과를 재현 검증하고, PvE 런은 샘플링(래더 상위·통계 이상치·랜덤)만 재검증한다. 부산물로 침공 리플레이 관전 기능이 같은 구조에서 무료로 나온다.

## Consequences

- 시뮬 코어는 클라이언트와 서버 양쪽에서 동일하게 실행 가능해야 한다 — `Math.random`/`Date.now` 사용 금지, 부동소수점 결정론 규율을 M1 첫 코드부터 적용 (사후 도입은 사실상 불가능하므로 지금 결정)
- 개연성 검증만 하는 대안(통계 상한 체크)은 정교한 치트(슬로우 핵, 자동 회피 봇)를 못 막아 기각
- 전수 PvE 검증은 Supabase 컴퓨팅 비용이 DAU에 선형 증가해 기각
