# 퇴역 기체는 장비를 잠근 실물로 보존 — 예비역 소집이 침공 공백을 메운다

퇴역이 세대 리셋(Lv1·스킬 0)이라 PvE는 침략 단계를 낮게 골라 다시 오르면 되지만, 침공(PvP)은 난이도 선택 축이 없고 래더 순위가 유지되므로 퇴역 직후 공격 플레이만 구조적으로 불능이 된다(방어는 퇴역 무영향 — 오히려 수호 기체가 늘어 강해진다). 이를 해결하기 위해(2026-07-23 grill 세션) 퇴역 기체를 **장착 장비를 잠근 실물**로 보존하고(구 "능력치 복사 스냅샷 + 장비 창고 반환" 모델 개정), 침공 출격 시 활성 기체 대신 미소멸 수호 기체를 골라 모는 **예비역 소집**을 도입한다. 소집 스펙 = 실물 빌드(잠긴 장비 + 동결 스킬) × 풍화 성능%(방어 참전과 동일한 단일 상태), 정산 경험치는 활성 기체 귀속, PvE 침략은 활성 기체 전용. 소멸 시 잠긴 장비는 창고로 반환된다.

## Considered Options

- **침공 한정 스탯 보정(레벨 격차 자동 보정)** — 파워의 출처가 화면에 보이지 않는 인위 보정이라 공정성 가독이 나빠 기각
- **장비 효과 복사(원본은 창고 반환 유지)** — 같은 장비의 힘이 구세대·신세대 두 기체에 동시에 존재해 소집이 공짜 파워가 되고 "회수 vs 다리" 긴장이 사라져 기각
- **장비 영구 귀속(소멸 시 장비도 함께 소멸)** — 파밍한 유니크가 증발해 디아블로2식 세대 관통 파밍 경제와 정면 충돌이라 기각
- **재성장 경험치 가속** — 딥 기간을 줄일 뿐 침공 불능 구간 자체는 남아 단독 해법으로 기각

## Consequences

- ADR-0007의 수호 기체 정의(능력치 복사 스냅샷)와 장비 창고 자동 반환 조항은 본 ADR로 개정된다 — 생애주기 순환(풍화 → 소멸 → 계보)은 그대로 유지
- 프리셋(타이탄/인터셉터)은 스탯 블록 선택이 아니라 **AI 행동 성향** 선택으로 의미가 바뀐다 — 방어 참전 스펙도 실물 빌드에서 파생되어 "한 기체 = 한 스펙"이 된다
- 장착분 잠김으로 새 세대는 창고의 예비 장비로 시작한다 — 최상급 장비를 물려주려면 소멸(다리 포기)이 필요한 상시 결정이 생긴다
- 풍화 감쇠(바닥 50%)가 소집 전력에도 그대로 적용되어 자연 세대교체 압력으로 작동한다 — 소집 전용 추가 마모는 없다
- 소멸 보상(전투력 점수 비례 포인트)과 장비 반환의 이중 보상 조정, 소집 런 경험치 귀속 비율은 출시 전 밸런스 패스로 이월(2026-07-22 방침)
