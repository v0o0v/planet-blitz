# 미니맵은 전체 지도가 아니라 플레이어 중심 레이더

우상단 미니맵 요구를 구현하면서 **전체 아레나 지도가 아니라 플레이어 중심 레이더**로 설계한다. 아레나가 청크 기반 무한 스크롤 월드(ADR-0002의 스크롤 맵, 경계 없는 f64 좌표)라 "전체 지도"라는 개념 자체가 성립하지 않기 때문이다. 레이더는 주변 중범위를 축소해 보스·엘리트, 드랍 아이템·장비, 기믹·해저드를 표시하고, 사거리 밖 대상은 테두리 방향 화살표로 지시한다. 북 고정(회전 없음)이며 스냅샷만 읽는 렌더 전용이라 sim 결정론(ADR-0005)에 무관하다.

## Consequences

- 레이더 사거리를 벗어난 정보는 방향만 알 수 있고 정확한 거리는 알 수 없다 — 무한 월드에서 전역 위치를 압축 표시할 방법이 없으므로 감수한다
- "전체 맵 미니맵" 대안은 기각 — 월드에 경계가 없어 축척을 정의할 수 없고, 무한 좌표를 고정 사각형에 매핑하면 플레이어가 항상 원점에 붙어 무의미해진다
- 잡몹은 레이더에서 제외 — 고밀도 전투에서 잡몹까지 찍으면 레이더가 지저분해져 핵심 정보(보스 방향·드랍)가 묻힌다
- 표시 대상이 늘면 여기에 아이콘·색 범례를 추가하되, 탄의 시각 문법(색=거동)과는 별개 체계다
