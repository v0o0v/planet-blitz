# 침공 보상은 복제 약탈 — 방어자는 실손실 없음

침공(PvP) 성공 시 공격자는 방어자 보유 자원의 일부를 "복제"해 받고, 방어자는 아무것도 잃지 않는다. 클래시 오브 클랜식 실제 약탈은 긴장감과 방어 투자 동기가 크지만, CrazyGames 캐주얼 웹 유저에게 오프라인 손실 스트레스는 이탈 요인이고 쉴드 등 보호 시스템까지 추가 설계가 필요해진다. 방어자의 실질 페널티는 래더 순위를 빼앗기는 것 하나로 충분하다고 판단했다. 서버 검증도 단순해진다(방어자 잔고를 건드리지 않으므로 동시성 문제가 줄어든다).

미래 독자를 위한 주의: "약탈인데 왜 방어자가 안 잃냐"는 의도된 설계다. 실손실 도입은 이탈률 데이터를 보고 나서만 재검토한다.
