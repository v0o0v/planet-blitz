# Planet Blitz 초보자 가이드

> 이 문서는 Planet Blitz를 처음 접하는 플레이어를 위한 안내서입니다.
> 게임의 전체 흐름, 각 시스템의 역할, 그리고 게임에서 쓰이는 용어를 한 번에 이해할 수 있도록 구성했습니다.

---

## 1. 이 게임은 어떤 게임인가요?

**Planet Blitz(플래닛 블리츠)** 는 웹 브라우저에서 즐기는 **탑다운 탄막 슈팅 게임**입니다. 여기에 세 가지 재미가 섞여 있습니다.

- **탄막 슈팅**: 사방에서 몰려오는 적 떼와 탄막을 요리조리 피하며 싸웁니다. 공격은 자동이고, 여러분의 몫은 **회피와 포지셔닝**입니다.
- **파밍(디아블로 스타일)**: 전투에서 등급이 다른 장비를 주워 모으고, 더 좋은 장비로 더 어려운 곳을 파밍합니다.
- **비동기 PvP(래더 경쟁)**: 충분히 강해지면 **나보다 순위가 높은 플레이어의 기지를 침공**해서 순위를 빼앗습니다.

한 줄로 요약하면:

> **"행성을 침략해 장비를 파밍하고, 그 힘으로 상위 랭커의 기지를 뚫어 자리를 빼앗는 게임."**

파밍과 빌드는 수단이고, 최종 목표는 **래더(순위표) 등반**입니다.

- **플랫폼**: 데스크톱 웹 브라우저 (1920×1080 기준)
- **런 1회 길이**: 약 2분 (강할수록 짧아지고, 약할수록 길어집니다)

## 2. 게임의 큰 흐름 (코어 루프)

게임 전체는 아래의 순환으로 돌아갑니다. 처음에는 ①~③만 반복하다가, 성장하면 ④(PvP), 만렙이 되면 ⑤(엔드게임)가 열립니다.

```
① 행성 침략 (PvE 런, 약 2분)
      ↓ 전리품: 장비 · 크레딧 · 희귀 광물 · 경험치
② 기지에서 성장 (스킬트리 · 장비 장착 · 리롤) + 방어 배치 강화
      ↓
③ 더 높은 침략 단계에서 파밍  ⟲ (①로 반복)
      ↓ 충분히 강해지면
④ 상위 랭커 기지 침공 (PvP) → 성공 시 순위 맞바꾸기 + 복제 약탈  ⟲
      ↓ 기체가 만렙(Lv100)에 도달하면
⑤ 퇴역 → 수호 기체 배치 + 새 기체로 다시 시작 (계보로 계정 전체가 강해짐)  ⟲⟲
```

즉, **"싸운다 → 강해진다 → 더 어려운 곳에서 싸운다 → 남의 자리를 빼앗는다"** 의 반복입니다.

## 3. 조작 방법

| 조작 | 키 |
|---|---|
| 이동 | `WASD` 또는 방향키 |
| 조준 | 마우스 (주무기는 가장 가까운 적을 자동 조준·자동 연사) |
| 대시 | `Space` — 쿨다운이 있고, 대시 중 잠깐 무적입니다 |
| 파워업 선택 | 마우스 클릭 (레벨업 시 3개 중 1개 선택) |

### 꼭 알아야 할 판정 규칙

- 내 기체는 커 보이지만, **실제로 탄에 맞는 판정점은 기체 중심의 아주 작은 점(반지름 8px)** 뿐입니다. 탄막이 빽빽해 보여도 틈 사이로 지나갈 수 있으니 겁먹지 말고 파고드세요.
- 반대로 **경험치 젬이나 아이템 같은 이로운 것**은 기체 크기 전체로 넉넉하게 주워집니다.

## 4. 런(Run) 1회는 이렇게 진행됩니다

**런**이란 행성에 출격해서 사망하거나 보스를 잡을 때까지의 전투 1회를 말합니다.

1. **행성·단계 선택** — 성계 지도에서 갈 행성과 침략 단계를 고르고 출격합니다.
2. **촉매 주입 (선택)** — 출격 직전, 성계 지도에서 모아 둔 **촉매**를 이번 런에 주입할 수 있습니다. 모든 촉매는 난이도 페널티와 보상 부스트를 **한 몸**으로 가집니다(예: "적이 더 많아지는 대신 드랍 증가"). 여러 개·같은 종류 중복까지 겹쳐 부을 수 있고, 세면 셀수록 위험과 보상이 함께 커집니다. 촉매는 엘리트·보스 런 드랍으로 얻으며 **해금 조건이 없어 첫 획득 즉시** 주입할 수 있습니다. 주입분은 출격하는 순간 소모됩니다(PvE 침략 전용).
3. **웨이브 전투** — 넓은 아레나에서 적 떼가 몰려옵니다. 이 게임의 웨이브는 시간이 아니라 **처치 할당(목표 처치 수)** 으로 진행됩니다. 할당을 채우면 다음 구간으로 넘어가고, 못 채우면 **급행 소환**으로 적이 계속 추가되어 압박이 심해집니다. → 강한 빌드일수록 런이 짧게 끝납니다.
4. **레벨업 → 파워업 3택** — 경험치 젬을 모아 레벨업하면 화면에 3개의 파워업이 뜹니다. 하나를 골라 이번 런 동안의 임시 강화를 받습니다. 파워업은 **지금 장착한 장비·투자한 스킬에서 파생**되므로, 빌드가 깊을수록 좋은 파워업이 나옵니다.
5. **보급선 습격 (기회!)** — 런 중간에 가끔 **보급선**이 지나갑니다(20초 제한). 격추하면 확정 장비/젬을 드랍하는 보너스 목표입니다.
6. **보스전** — 웨이브를 모두 통과하면 보스가 등장합니다. 보스는 3페이즈(HP 100%/70%/35%)로 패턴이 바뀌며, 보스전 중에도 잡몹이 계속 나옵니다. 보스가 큰 패턴을 쓴 직후 5초간은 **과열 창**이라 받는 피해가 2배 — 이때 화력을 집중하세요.
7. **정산** — 획득한 장비·크레딧·경험치를 정산하고 "다시 출격"할 수 있습니다.

### 죽으면 어떻게 되나요?

**걱정할 것 없습니다.** 런 도중 사망해도 그때까지 주운 전리품은 **전량 보존**됩니다. 잃는 것은 보스 확정 드랍 기회뿐입니다. 부담 없이 도전하세요.

## 5. 기지 — 성장의 허브

런과 런 사이에는 **기지 맵**에서 성장합니다. 건물을 클릭해 각 기능에 들어갑니다.

| 건물 | 하는 일 | 해금 시점 |
|---|---|---|
| **격납고** | 장비 장착, 인벤토리(48칸)·창고(96칸) 관리, 장비 분해 | 튜토리얼 직후 |
| **연구소** | 스킬트리 투자, 리스펙, (만렙 시) 퇴역 | 기체 Lv3 |
| **정제소** | 장비 어픽스 리롤 (희귀 광물 소모) | 행성 1개 클리어 |
| **방어 사령부** | 내 기지의 방어 배치 (포탑·장애물·코어), 정비 | Lv10 + 행성 2개 클리어 |
| **관제탑** | 래더 확인, 침공 대상 선택, 리플레이 관전 | Lv10 + 행성 2개 클리어 |

기지 맵에서 **출격** 버튼을 누르면 성계 지도(행성 선택)로 갑니다.

## 6. 성장 시스템

### 6-1. 장비 (런 밖의 영구 장비)

기체에는 **7종 8칸**의 장비 슬롯이 있습니다: 주무기 / 보조무기 / 장갑 / 실드 / 엔진 / 코어 / 모듈×2.

- **주무기 5타입**: 발칸, 스프레드, 레일건, 미사일, 빔 — 각각 사격 스타일이 완전히 다릅니다.
- **아이템 등급 4단계**:
  1. **노말** — 기본 성능만.
  2. **매직** — 랜덤 어픽스 1~2개.
  3. **레어** — 랜덤 어픽스 3~6개.
  4. **유니크** — 고정 능력치 + 고유 효과 (예: "쌍둥이 항성" — 발사체 2배, 피해 -30%). 드랍 시 슬로모션+금빛 연출이 나옵니다.
- **어픽스**란 장비에 붙는 랜덤 옵션입니다(공격계 접두 12종 + 유틸·생존계 접미 12종). 화염·냉기·전격 같은 원소 상태이상 옵션도 있습니다.
- 필요 없는 장비는 **분해**하세요: 노말·매직 → 크레딧, 레어 이상 → 희귀 광물.
- 아까운 옵션 하나만 아쉬울 땐 정제소에서 **리롤**(원하는 어픽스는 잠그고 나머지만 다시 굴리기)이 가능합니다.

### 6-2. 스킬트리 (기체 레벨)

- 런에서 얻은 경험치로 **기체 레벨**이 오릅니다 (최대 **Lv100**, 스킬 포인트 총 99).
- 스킬트리는 **화력 / 생존 / 기동** 3계열, 총 60노드입니다. 전부 찍는 데 약 250포인트가 필요하지만 가진 것은 99포인트 — **모든 걸 가질 수 없으니 빌드를 선택**해야 합니다.
- 하위 노드 투자가 상위 노드를 증폭하는 시너지 구조라 한 계열을 깊게 파는 것도 강력합니다.
- 실수했다면 크레딧을 내고 **리스펙**할 수 있습니다.

### 6-3. 재화 정리

| 재화 | 얻는 곳 | 쓰는 곳 |
|---|---|---|
| **크레딧** | 런 정산, 노말·매직 분해 | 방어 시설 건설·정비, 리스펙, 창고 확장 |
| **희귀 광물** | 행성·단계별 특산 드랍, 레어+ 분해 | 상위 방어 시설, 어픽스 리롤 |
| **경험치 젬** | 잡몹 드랍 (런 내에서 자석처럼 수거) | 런 내 레벨업 + 기체 경험치 |
| **계보 포인트** | 기체 퇴역·수호 기체 소멸 | 계보 트리 (계정 영구 강화) |

팁: 젬을 **끊기지 않고 연달아 주우면 콤보 배율**(최대 x1.5)이 붙습니다.

## 7. 행성과 난이도

- **행성**은 반복해서 파밍하는 사냥터입니다. 점령하는 것이 아니라 계속 다시 갈 수 있습니다.
- 행성 5곳: **홈월드 궤도**(튜토리얼), **베르단**(초원·군체형 적), **카르곤**(화산·중장갑 적), **니플헤임**(빙설·유령 함대), **아르케**(고대 기계 유적). 행성마다 적 패턴 스타일과 특산 광물이 다릅니다.
- 각 행성에는 **침략 단계**(1부터 상한 없이 오르는 정수)가 있습니다. 예전의 "정찰/교전/섬멸 3티어"는 폐지되고, 행성마다 **독립적으로** 클리어할수록 다음 단계가 열립니다. 도전 가능한 최고 단계 = **max(10, 그 행성 최고 클리어 단계 + 5)** (처음엔 1~10단계가 열려 있습니다).
- 단계가 오르면 적이 **연속적으로** 강해지고 드랍도 좋아집니다(HP만 부풀리는 스펀지 방식이 아닙니다). 대신 정해진 **구간 경계**에서 질적으로 바뀝니다:

| 구간 | 대략 단계 | 특징 |
|---|---|---|
| **밴드 0** | 1~10 | 기본 난이도 |
| **밴드 1** | 11~20 | 엘리트 증원(엘리트에 어픽스 1개) |
| **밴드 2** | 21+ | 적 서브탄 추가 + 밀도 상승, 엘리트 어픽스 2개, 최상급 보상 |

*(구간 경계·강화 배율은 밸런스 조정 중 — 출시 직전 확정됩니다.)*

- 적은 행성마다 **돌격형·사수형·특수형·지원형** 4가지 역할로 구성되며, 가끔 **엘리트**(랜덤 강화 수식어 — "분열하는", "가속하는" 등 — 가 붙은 강적)가 등장합니다.

## 8. PvP — 침공과 래더

기체 Lv10 + 행성 2개 클리어로 해금되는 이 게임의 핵심 콘텐츠입니다.

### 용어부터 구분하세요

- **침략** = 행성에 가는 **PvE** 런.
- **침공** = 다른 플레이어의 기지에 도전하는 **PvP**.

### 침공은 이렇게 진행됩니다

1. **관제탑**에서 래더를 보고 나보다 순위가 높은 대상을 고릅니다.
2. 상대 기지에 돌입 — **제한시간 3분**, **부활 불가**. 상대가 배치한 포탑·장애물·수호 기체를 뚫고 **코어를 파괴**하면 승리.
3. **성공 시**: 상대와 **래더 순위를 맞바꾸고**, 상대 자원을 **복제 약탈**합니다. 복제이므로 **상대는 아무것도 잃지 않습니다** — 마음 편히 침공하세요.
4. 상대는 실시간으로 방어하지 않습니다(비동기). 여러분의 기지도 여러분이 없는 동안 **배치해 둔 방어**가 자동으로 싸웁니다.

### 관련 시스템

- **방어 배치**: 방어 사령부에서 포탑(6종)·장애물·수호 기체를 배치 포인트 예산 안에서 배치합니다.
- **래더**: 시즌 리셋이 없는 **영구 순위표**. 순위는 침공 스왑으로만 오르내립니다.
- **배치전**: PvP 첫 해금 시 NPC 기지 5회를 상대해 초기 순위를 배정받습니다.
- **복수전**: 침공당하면 24시간 안에 쿨다운 무시하고 **역침공**할 수 있습니다.
- **도발 스티커**: 침공 시 상대에게 표시될 스티커를 하나 고를 수 있습니다.
- **리플레이 관전**: 내 기지가 침공당한 장면을 다시 볼 수 있습니다.

## 9. 엔드게임 — 퇴역, 수호 기체, 계보

기체가 **Lv100(만렙)** 이 되면 열리는 장기 콘텐츠입니다.

### 퇴역

만렙 기체를 은퇴시키는 것입니다. 퇴역하면:

1. 그 기체의 빌드·장비 스냅샷이 **수호 기체**(내 기지를 지키는 AI)가 됩니다.
2. 새 기체 타입이 해금되어 **새 기체로 다시 시작**합니다.
3. **계보 포인트**를 받습니다.
4. 장비 원본은 창고로 돌아오므로 새 기체가 물려받을 수 있습니다.

### 수호 기체

- 퇴역 기체의 능력치를 복사한 방어 AI입니다. 방어전에 동시 최대 2기 배치.
- 프리셋 2종: **타이탄형**(고HP·고화력·저속) / **인터셉터형**(고속·대시·저내구).
- 단, **수명이 있습니다** — 풍화로 매주 성능이 5%p씩 감소(바닥 50%)하며 회복할 수 없습니다.
- 낡은 수호 기체는 **소멸**시켜 계보 포인트로 회수할 수 있습니다. 남은 성능이 높을수록 많이 돌려받으므로, "신선할 때 회수할까, 말년까지 쓸까"를 저울질하게 됩니다.

### 계보

- **계정 단위의 영구 강화 트리**입니다. 기체가 바뀌어도 사라지지 않습니다.
- **기체 가지**(내 플레이 기체 강화)와 **수호 가지**(모든 수호 기체 강화) 두 갈래.
- 무한히 투자할 수 있지만 보너스는 **+50% 상한**에 점점 수렴합니다. 리스펙은 없습니다.

### 풍화 — 게임 세계의 시간 압력

방치하면 자연히 낡는 시스템입니다. 대상은 딱 두 가지:

1. **방어 시설 정비도**: 매주 5%p 감소. 0%가 되면 포탑 성능이 50%까지 떨어집니다. 크레딧으로 **정비**하면 회복됩니다.
2. **수호 기체 성능**: 매주 5%p 감소, 회복 불가 (위 참조).

**자원·장비·레벨·래더 순위는 절대 풍화되지 않습니다.** 오래 쉬어도 여러분의 성장 자체는 그대로입니다.

## 10. 초보자 추천 진행 순서

1. **튜토리얼 런**을 마치고 조작(이동·대시)에 익숙해지세요. 탄은 "작은 판정점"만 피하면 됩니다.
2. **낮은 침략 단계**에서 런을 반복하며 장비를 줍고, 격납고에서 더 좋은 것으로 갈아입으세요. 남는 장비는 분해.
3. Lv3에 연구소가 열리면 **한 계열(화력 추천)을 깊게** 투자하세요. 포인트는 모든 걸 찍기엔 부족하게 설계되어 있습니다.
4. 런 중에는 **젬 콤보 유지**와 **보급선 격추**를 챙기면 성장이 빨라집니다.
5. 행성 2개 클리어 + Lv10 → **배치전 5회**로 래더에 진입하고, 방어 사령부에서 기지 방어를 배치해 두세요.
6. 낮은 단계를 클리어하면 **더 높은 침략 단계**가 열립니다 — 넘어가 더 좋은 파밍을 시작하고, 여유가 되면 상위 랭커 **침공**에 도전하세요. 죽어도 잃을 게 없고, 성공하면 순위와 복제 약탈을 얻습니다.
7. 장기 목표: Lv100 → **퇴역** → 계보로 계정을 강화하며 다음 기체로 더 높이.

## 11. 용어 사전

### 전투·런

| 용어 | 의미 |
|---|---|
| **런 (run)** | 행성 출격 1회의 전투 세션 (출격~사망 또는 보스 처치) |
| **처치 할당 (kill quota)** | 웨이브를 넘어가기 위한 목표 처치 수. 이 게임은 시간이 아니라 처치 수로 진행됩니다 |
| **급행 소환** | 처치 할당을 못 채울 때 적이 계속 추가 소환되는 압박 시스템 |
| **웨이브 (wave)** | 런 내 전투 구간. 뒤로 갈수록 적·탄이 많아집니다 |
| **파워업 (powerup)** | 레벨업 시 3택으로 고르는 런 한정 임시 강화. 런이 끝나면 사라집니다 |
| **촉매 (catalyst)** | 출격 전 주입하는 런 1회 소모품. 페널티+보상을 한 몸으로 가지며 스택 가능 (위험↑ 보상↑). 구 "변칙 경보"를 대체 (ADR-0029) |
| **보급선** | 런 중 잠깐 지나가는 보너스 목표. 격추 시 확정 보상 |
| **판정점 (hit point)** | 기체 중심의 실제 피격 판정 (반지름 8px). 이것만 안 맞으면 됩니다 |
| **그레이징 (grazing)** | 판정점에 닿지 않게 탄을 아슬아슬하게 스치는 것 |
| **과열 창 (overheat window)** | 보스가 큰 패턴을 쓴 직후 5초간 받는 피해 2배가 되는 딜타임 |
| **엘리트 / 엘리트 어픽스** | 랜덤 강화 수식어("분열하는" 등)가 붙은 강적 / 그 수식어 |
| **레이더 (radar)** | 우상단의 플레이어 중심 미니맵 |

### 성장·아이템

| 용어 | 의미 |
|---|---|
| **기체 (ship)** | 플레이어가 조종하는 우주선 = RPG의 캐릭터. 레벨 캡 100 |
| **어픽스 (affix)** | 매직·레어 장비에 붙는 랜덤 옵션 (접두=공격계, 접미=유틸·생존계) |
| **유니크 (unique)** | 고정 능력치 + 고유 효과를 가진 최상위 등급 장비 |
| **리롤 (reroll)** | 정제소에서 희귀 광물을 소모해 어픽스를 다시 굴리는 것 (잠금 가능) |
| **분해 (salvage)** | 장비를 재화로 환원 (노말·매직→크레딧, 레어+→희귀 광물) |
| **크레딧 (credit)** | 범용 화폐 |
| **희귀 광물 (mineral)** | 행성·단계별 특산 상위 재화 |
| **경험치 젬 (gem)** | 적이 드랍하는 경험치. 연속 수집 시 콤보 배율 (최대 x1.5) |
| **침략 단계 (stage)** | 행성 난이도 축. 1부터 상한 없이 오르는 정수로, 행성별로 독립 추적되고 클리어할수록 개방(상한 = max(10, 최고 클리어 + 5)). 구 3티어(정찰/교전/섬멸, 폐지)를 대체 |
| **행성 (planet)** | 반복 파밍 사냥터. 점령 개념 없음 |

### PvP·엔드게임

| 용어 | 의미 |
|---|---|
| **침략** | 행성 PvE 런 (PvP가 아님에 주의) |
| **침공 (invasion)** | 다른 플레이어 기지에 도전하는 PvP (3분, 부활 불가) |
| **코어 (core)** | 기지의 심장. 침공에서 파괴하면 승리 |
| **래더 (ladder)** | 시즌 리셋 없는 영구 순위표 |
| **복제 약탈 (copy loot)** | 침공 성공 보상. 상대 자원을 복제해 획득 — 상대는 잃지 않음 |
| **배치전 (placement)** | PvP 해금 직후 NPC 기지 5회로 초기 순위 배정 |
| **복수전 (revenge)** | 침공당한 뒤 24시간 내 가능한 역침공 |
| **도발 스티커** | 침공 시 상대에게 표시되는 스티커 |
| **퇴역 (retire)** | 만렙 기체를 은퇴시켜 수호 기체화 + 새 기체 시작 |
| **수호 기체 (guardian)** | 퇴역 기체의 스냅샷으로 만드는 방어 AI. 수명형(풍화로 감쇠) |
| **소멸 (dismiss)** | 수호 기체를 해체해 계보 포인트로 회수 |
| **계보 (lineage)** | 계정 단위 영구 강화 트리 (기체 가지 + 수호 가지, 상한 +50%) |
| **계보 포인트** | 퇴역·소멸로만 얻는 계보 전용 재화 |
| **풍화 (weathering)** | 방어 시설 정비도·수호 기체 성능이 매주 자연 감소하는 것 |
| **정비 (maintenance)** | 크레딧으로 방어 시설 정비도를 회복하는 것 |
| **전투력 점수 (combat power)** | 장비·빌드를 종합 평가한 수치 |

## 12. 자주 묻는 질문

**Q. 죽으면 아이템을 잃나요?**
아니요. 런 중 사망해도 수거한 전리품은 전부 가져갑니다. 잃는 건 그 런의 보스 확정 드랍 기회뿐입니다.

**Q. 침공당하면 내 자원을 뺏기나요?**
아니요. 공격자는 여러분 자원의 **복제본**을 가져갑니다. 여러분이 실제로 잃는 것은 래더 순위(스왑)뿐입니다.

**Q. 오래 접속 안 하면 캐릭터가 약해지나요?**
레벨·장비·자원·순위는 그대로입니다. 다만 방어 시설 정비도와 수호 기체 성능은 매주 조금씩 낮아지니, 복귀하면 정비부터 하세요.

**Q. 웨이브가 안 끝나요.**
이 게임의 웨이브는 시간이 아니라 **처치 수**로 진행됩니다. 화력이 부족하면 런이 길어지니, 장비·스킬을 강화하고 다시 도전하세요.

**Q. 탄막이 너무 빽빽해서 못 피하겠어요.**
실제 피격 판정은 기체 중심의 작은 점뿐입니다. 탄 사이 틈으로 지나갈 수 있고, 급할 땐 대시(Space)의 무적 시간을 활용하세요.
