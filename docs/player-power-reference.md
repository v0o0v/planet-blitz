# 플레이어 능력 종합 레퍼런스

> 플레이어의 능력(전투력)에 관여하는 **모든 요소**를 한 문서에 정리한 레퍼런스입니다.
> 모든 수치는 실제 코드·데이터 파일 기준이며, 설계 문서(GDD)에만 있고 아직 구현되지 않은 항목은 **[계획(미구현)]** 으로 표기했습니다. 수치는 밸런싱 과정에서 변경될 수 있습니다.

**능력이 만들어지는 큰 그림:**

```
기본 스탯 (모든 기체 공통)
  × 장비 (주무기 타입 + 어픽스 + 유니크 효과)      ← 영구, 파밍으로 획득
  × 스킬트리 (기체 레벨업 포인트 투자)             ← 영구, 리스펙 가능
  × 계보 (계정 단위 보너스, 최대 +50%)             ← 영구, 퇴역/소멸로 성장
  × 파워업 (런 내 레벨업 3택)                      ← 런 한정, 종료 시 소멸
  + 상태이상·콤보·촉매 등 상황 요소
```

퍼센트 스탯은 곱연산 배율, flat 스탯은 가산입니다. 장비 어픽스를 먼저 합산해 배율화한 뒤, 스킬 파생 스탯을 그 위에 곱하는 ARPG 표준 이중 스택 구조입니다 (`src/items/loadout.ts`).

## 2. 장비

### 2-1. 슬롯 구조 — 7종 8칸

`main`(주무기) / `sub`(보조무기) / `armor`(장갑) / `shield`(실드) / `engine`(엔진) / `core`(코어) / `module`×2(모듈 2칸).

- 슬롯 자체는 스탯을 주지 않습니다. **아이템에 붙은 어픽스의 합**이 능력치가 되고, 유일한 예외로 **주무기 타입**이 기본 무기 성능을 결정합니다.
- 등급 4단계: **노말**(어픽스 없음) → **매직**(1~2개) → **레어**(3~6개) → **유니크**(고정 능력치 + 고유 효과).
- 보조무기 5종은 아래 §2-1-1에 구현되어 있습니다.

### 2-1-1. 보조무기 5종 기본 성능

보조무기(`sub` 슬롯)는 주무기와 **완전히 독립된 자기 사이클**로 자동 발사됩니다(주무기 쿨다운과 경쟁하지 않음). `subWeaponType`(0~4)으로 분기하며, 미장착 시 아무 동작도 하지 않습니다(기존 런과 비트 동일). 발사 사이클은 플레이어의 미사용 `timer` 필드에 실어 결정론을 유지합니다. 상수는 `src/sim/world.ts`.

| # | 이름 | 메커닉 | 발사 간격* | 데미지 | 사거리 | 기타 |
|---|---|---|---|---|---|---|
| 0 | 사이드킥 | 최근접 적 자동 조준, 빠른 단발 볼트 | 18틱 | 6 | 900 | 꾸준한 보조 DPS |
| 1 | 스캐터 | 3발 광각 산탄(총 확산 0.52rad) | 33틱 | 4 ×3발 | 620 | 근거리 다수 제압 |
| 2 | 기뢰장 | 플레이어 위치에 정지 장판 설치(반경 64, 수명 150틱), 밟는 적에게 매 틱 피해 | 66틱 | 3/틱 | 설치형 | 관통 예산 40회 소진 시 소멸(총 피해 상한) |
| 3 | 센트리 | 임시 자동 포탑 주기 배치(자율 사격) | 300틱 | 포탑탄 10 | 포탑 900 | 자율 드론 베이 포탑 재사용(고정 스탯) |
| 4 | 호밍 플레어 | 유도 미사일(제한 선회, 탄속 1000) | 45틱 | 14 | 950 | 곡선 추적, 느린 연사·강한 단발 |

*발사 간격이 클수록 발사가 느립니다. 기뢰장·센트리는 조준 대상 없이도 선제 설치(지역 거부·자율 사격)하며, 나머지 3종은 사거리 내 적이 없으면 사이클을 대기합니다.

**어픽스 상호작용**: 데미지(예리한/치명적인 등)·연사(속사의/과부하된) 어픽스는 **주무기와 동일한 배율**(`loadout.damageMult` / `fireRateMult`)이 보조무기의 직접 발사체(사이드킥·스캐터·기뢰장·호밍 플레어)에 그대로 공유됩니다. 예외: **센트리(3)가 배치하는 포탑**은 자율 드론 베이와 동일한 고정 스탯 포탑으로, 포탑탄은 별도 시스템(`stepTurrets`)이 관리하므로 어픽스 배율을 받지 않습니다.

### 2-2. 주무기 5타입 기본 성능

기준 무기(발칸): 발사 간격 6틱, 데미지 8, 탄속 1800, 탄 1발, 관통 0, 탄 수명 55틱, **기준 사거리 1650**(`BASE_WEAPON_RANGE`). 타입별 배율 (`src/items/loadout.ts`):

| 타입 | 데미지 | 발사 간격* | 탄속 | 사거리 | 기타 |
|---|---|---|---|---|---|
| 발칸 | ×1 | ×1 | ×1 | 1650 | 기준 연사형 |
| 스프레드 | ×0.7 | ×1.15 | ×0.9 | 1650 | 탄 +2발, 확산 大 |
| 레일건 | ×2.4 | ×2.0 | ×1.6 | 1650 | 관통 +3 — 강한 단발·고관통 |
| 미사일 | ×2.2 | ×2.6 | ×0.7 | 1650 | 유도탄 — 강한 단발·느린 연사 |
| 빔 | ×0.42 | ×0.6 | — | **800** (`BEAM_RANGE_DELTA = -850`) | 짧은 세그먼트 지속 판정 |

*발사 간격 배율이 클수록 연사가 느립니다.

**빔 사거리가 낮은 것은 페널티가 아니라 투자 여지입니다.** 빔의 `range` 는 조준 상한이자 **타격선 길이**라 다른 아키타입과 성질이 다릅니다 — 세그먼트를 `BEAM_MAX_SEGMENTS`(16) × 간격(90) = **1440** 까지만 깔 수 있어 그 위의 사거리는 빔에게 아무 의미가 없습니다. 공용 기준 1650 에서 출발시키면 처음부터 상한에 붙어 사거리 어픽스·스킬 노드·집속 렌즈가 전부 무효가 되므로, 800 에서 출발시켜 상한까지 640 의 투자 여지를 남깁니다(세그먼트 8개 → 최대 16개). 이 값은 `tests/weaponRange.test.ts` 가 "빔 기준 사거리 === 800" 으로 못박습니다.

## 3. 스킬트리 — 63노드 (기체 레벨)

기체 레벨(캡 100)로 얻는 스킬 포인트 99를 투자합니다. 계열당 base 20노드(5티어 × 4노드) + 최상위 캡스톤 1노드, 노드당 최대 4~5포인트(캡스톤 1포인트), base 용량 약 250 → **전부 찍을 수 없어 빌드 선택이 강제**됩니다. 크레딧으로 리스펙 가능. (`data/skills.ts`)

## 5. 계보 (lineage) — 계정 영구 보너스

퇴역·소멸로 얻는 **계보 포인트**를 투자하는 계정 단위 트리. 리스펙 없음. (`data/lineage.ts`)

- **가지 2종**: 기체 가지(현역 기체 강화) / 수호 가지(모든 수호 기체 강화).
- **기체 가지 적용 스탯** (`src/items/loadout.ts` applyShipLineageBonus — 수호 가지와 대칭 3축): 데미지 ×(1+보너스), 발사 간격 ÷(1+보너스)(연사↑), 최대 HP +기준 100 대비 보너스%. 이동속도·탄속·자석 등 나머지 축은 비대상. 장비·스킬 위에 곱연산으로 겹침.
- **보너스 곡선**: 레벨 L에서 `+50% × L/(L+20)` — L=20에서 +25%, 무한 투자해도 **+50% 상한**에 점근.
- **투자 비용**: 다음 레벨 비용 = `40 + 현재레벨 × 10`.
- **포인트 획득**: 퇴역 시 기본 50 + 수호 기체 소멸 시 `전투력 점수 × 남은 성능%` 비례 회수.
- 수호 기체에 적용 시: 스냅샷 스탯 × 남은 성능% × 계보 보너스 (HP·접촉피해·탄피해·연사에 적용, 기하 값은 스냅샷 고정).
- **마일스톤 질적 노드** (수호 가지 레벨 도달 시 **자동 해금** — 별도 투자·리스펙 없음, `data/lineage.ts` guardianMilestones): 방어전 config(`GuardianPlacement.milestones` 비트마스크)로 실려 sim 이 결정론 재현한다. 서버는 계보 레벨에서 마스크를 권위 재도출해 위조를 차단(verify-invasion). 초기 수치(밸런싱 튜닝 대상, §5):
  - **① 격추 재기동** (Lv10 해금): 방어전에서 수호 기체 HP 0 도달 시 **1회 부활** — 실효 최대 HP의 50%(`REBOOT_HP_BP`)로 회복, 부활 후 90틱(1.5초, `REBOOT_DELAY_TICKS`) 재기동 딜레이 동안 무적·정지(이동·사격·접촉피해 없음). 방어전당 1회(충전 소진 후 일반 격추).
  - **② 코어 근접 수비** (Lv25 해금): 코어 반경 420유닛(`CORE_GUARD_RADIUS`) 내 수호 기체는 탄피해·접촉피해 +30%(`CORE_GUARD_DAMAGE_BP`), 발사 간격 ÷1.3(연사↑). 반경 밖으로 나가면 즉시 기본치로 복귀.
  - **③ 실드 공유** (Lv50 해금): 방어전 시작 시 참전 수호들의 실효 HP 합(전투력 풀)에 비례한 실드를 코어(풀 ×50%, `SHIELD_SHARE_CORE_BP`)·각 포탑(풀 ×10%, `SHIELD_SHARE_TURRET_BP`)에 부여. 실드는 아군탄 피해를 HP보다 먼저 흡수한다.

## 6. 재화 → 능력 기여 경로

| 재화 | 능력에 기여하는 길 |
|---|---|
| **경험치 젬** | 런 내 즉시 XP → 레벨업 → 파워업 획득 + 기체 레벨(스킬 포인트). **유일하게 런 도중 실시간으로 전투력을 올리는 재화** |
| **크레딧** | 리스펙(빌드 교정), 창고 확장, 방어 시설 건설·정비 |
| **광물** | 어픽스 리롤(정제소) — 원하는 어픽스 잠금 리롤은 비용 3배. 상위 방어 시설 |
| **계보 포인트** | 계보 트리 투자 (§5) |

- 장비 분해: 노말·매직 → 크레딧, 레어 이상 → 광물.

**리롤·업그레이드 상세 비용 공식** (`data/economy.ts` — 순수 결정론 정수):

| 항목 | 재화 | 공식 | 예시 |
|---|---|---|---|
| 어픽스 리롤 | 광물 | `6 + 4×등급랭크 + 2×어픽스수` (등급랭크: normal 0·magic 1·rare 2·unique 3) | magic·1어픽스 = 12, rare·3어픽스 = 20 |
| 어픽스 잠금 리롤 | 광물 | 기본 비용 `× (3 × 잠금수)` (GDD §9: 잠금 1개 = ×3) | rare·3어픽스 잠금 1 = 20×3 = 60 |
| 리스펙 | 크레딧 | `기체레벨 × 100` (레벨 비례) | Lv10 = 1000, Lv100 = 10000 |
| 창고 확장 | 크레딧 | `200 × (이미확장수 + 1)` (회차 비례, 2회 한정) | 1회차 200, 2회차 400 |

- 설계 의도: 리롤은 무한 싱크(좋은 베이스일수록 부담↑), 리스펙은 주기 싱크(만렙일수록 교정 신중), 창고는 유한 싱크(회차마다 무겁게).

**런 내 XP 관련 수치** (`src/sim/world.ts`):
- **경험치는 두 풀로 갈립니다**(ADR-0036) — 런 중에 보이는 게이지는 **런 풀**(레벨업 → 파워업 3택, 런 종료 시 소멸), 정산에서 기체 레벨에 들어가는 값은 **메타 풀**입니다. 같은 젬이 두 풀에 서로 다른 값을 넣습니다(메타 풀만 침략 단계에 비례: `stageMetaXpMult(stage) = stage`).
- **런 풀** 레벨업 필요 XP `xpToNext(level)` (초과분 이월):
  - **PvE 침략** = `10 + 레벨 × 66`
  - **침공(PvP)** = `10 + 레벨 × 6` — 런 구조(3레이어 단판·웨이브 없음·처치 볼륨이 훨씬 작다)가 달라 커브가 분리돼 있습니다(ADR-0036 개정 2)
- **메타 풀** 레벨업 필요 XP `xpToNextMeta(level) = 40 + 레벨 × 1790` (`src/save/progressionPath.ts`) — 기체 레벨은 캡 100 에서 하드 클램프되고 초과 XP 는 버려집니다
- 획득 XP = 젬 XP값 × 콤보 배율 × XP 보너스(어픽스·스킬·유물 증폭기 ×1.15)
- **젬 콤보**: 2초(120틱) 안에 계속 주우면 스택당 +0.05, 10스택 = **최대 ×1.5**
- **보급선**: HP 420, 20초 제한, 격추 시 젬 14개(각 XP 6) 확정 드랍

**촉매** (출격 전 주입, `src/data/catalysts.ts` · 드랍 파생 `src/data/catalystDrops.ts`, ADR-0029):

구 "변칙 경보"(시드 랜덤 제안형)를 대체한 능동 소모품이다. 성계 지도 출격 직전 주입하며, 런 시작 시 서버 원장에서 소모된다(서버 권위). 모든 촉매는 **페널티+보상을 한 몸**으로 가진다(순수 버프 없음·무등급). 스택은 **선형 가산**(장당 +perStack, 같은 축끼리 합산)이라 세면 셀수록 위험과 보상이 함께 커진다 — 위험-보상 커플링이 스택 몰빵을 자기 밸런싱한다.

- **보상 6축**: 드랍량 / 희귀도 / 경험치 / 자원 / 촉매 드랍률 / 파워(런 한정 스탯 강화 — 데미지·연사·이속·최대HP·스킬전체).
- **페널티 6축**: 적 HP / 적 속도 / 적 피해 / 적 수 / 적 탄속 / 기체 HP 하향(전부 "클수록 난이도 상승").
- **공용 30종**(id 0~29, 전 행성 드랍) + **특산 18종**(id 30~47, 6행성×3, **출신 행성 런 전용 주입**).
- 슬롯 상한(`SLOT_CAP`)까지 다중·중복 주입. 수치(perStack·드랍 가중치·상한)는 전부 출시 전 밸런스 대상(`// BALANCE`).
- 해금 게이트 없음: 1단계 런 드랍부터 즉시 주입 가능. 분해(`salvage_catalyst`)로 보유 촉매를 재화로 환산.
