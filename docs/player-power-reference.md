# 플레이어 능력 종합 레퍼런스

> 플레이어의 능력(전투력)에 관여하는 **모든 요소**를 한 문서에 정리한 레퍼런스입니다.
> 모든 수치는 실제 코드·데이터 파일 기준이며, 설계 문서(GDD)에만 있고 아직 구현되지 않은 항목은 **[계획(미구현)]** 으로 표기했습니다. 수치는 밸런싱 과정에서 변경될 수 있습니다.

**능력이 만들어지는 큰 그림:**

```
기본 스탯 (모든 기체 공통)
  × 장비 (주무기 타입 + 어픽스 + 유니크 효과)      ← 영구, 파밍으로 획득
  × 스킬트리 (기체 레벨업 포인트 투자)             ← 영구, 리스펙 가능
  × 계보 (계정 단위 보너스, 최대 +50%)             ← 영구, 퇴역/소멸로 성장
  × 파워업 (런 내 레벨업 3택)                      ← 런 한정, 종료 시 소멸
  + 상태이상·콤보·변칙 경보 등 상황 요소
```

퍼센트 스탯은 곱연산 배율, flat 스탯은 가산입니다. 장비 어픽스를 먼저 합산해 배율화한 뒤, 스킬 파생 스탯을 그 위에 곱하는 ARPG 표준 이중 스택 구조입니다 (`src/items/loadout.ts`).

## 2. 장비

### 2-1. 슬롯 구조 — 7종 8칸

`main`(주무기) / `sub`(보조무기) / `armor`(장갑) / `shield`(실드) / `engine`(엔진) / `core`(코어) / `module`×2(모듈 2칸).

- 슬롯 자체는 스탯을 주지 않습니다. **아이템에 붙은 어픽스의 합**이 능력치가 되고, 유일한 예외로 **주무기 타입**이 기본 무기 성능을 결정합니다.
- 등급 4단계: **노말**(어픽스 없음) → **매직**(1~2개) → **레어**(3~6개) → **유니크**(고정 능력치 + 고유 효과).
- 보조무기 5종의 개별 성능은 **[계획(미구현)]**.

## 5. 계보 (lineage) — 계정 영구 보너스

퇴역·소멸로 얻는 **계보 포인트**를 투자하는 계정 단위 트리. 리스펙 없음. (`data/lineage.ts`)

- **가지 2종**: 기체 가지(현역 기체 강화) / 수호 가지(모든 수호 기체 강화).
- **기체 가지 적용 스탯** (`src/items/loadout.ts` applyShipLineageBonus — 수호 가지와 대칭 3축): 데미지 ×(1+보너스), 발사 간격 ÷(1+보너스)(연사↑), 최대 HP +기준 100 대비 보너스%. 이동속도·탄속·자석 등 나머지 축은 비대상. 장비·스킬 위에 곱연산으로 겹침.
- **보너스 곡선**: 레벨 L에서 `+50% × L/(L+20)` — L=20에서 +25%, 무한 투자해도 **+50% 상한**에 점근.
- **투자 비용**: 다음 레벨 비용 = `40 + 현재레벨 × 10`.
- **포인트 획득**: 퇴역 시 기본 50 + 수호 기체 소멸 시 `전투력 점수 × 남은 성능%` 비례 회수.
- 수호 기체에 적용 시: 스냅샷 스탯 × 남은 성능% × 계보 보너스 (HP·접촉피해·탄피해·연사에 적용, 기하 값은 스냅샷 고정).
- 마일스톤 질적 노드(격추 재기동, 코어 근접 수비, 실드 공유)는 **[계획(미구현)]**.

## 6. 재화 → 능력 기여 경로

| 재화 | 능력에 기여하는 길 |
|---|---|
| **경험치 젬** | 런 내 즉시 XP → 레벨업 → 파워업 획득 + 기체 레벨(스킬 포인트). **유일하게 런 도중 실시간으로 전투력을 올리는 재화** |
| **크레딧** | 리스펙(빌드 교정), 창고 확장, 방어 시설 건설·정비 |
| **희귀 광물** | 어픽스 리롤(정제소) — 원하는 어픽스 잠금 리롤은 비용 3배. 상위 방어 시설 |
| **계보 포인트** | 계보 트리 투자 (§5) |

- 장비 분해: 노말·매직 → 크레딧, 레어 이상 → 희귀 광물.
- 리롤·업그레이드의 상세 비용 공식은 **[계획(미구현)]**.

**런 내 XP 관련 수치** (`src/sim/world.ts`):
- 레벨업 필요 XP: `10 + 레벨 × 6` (초과분 이월)
- 획득 XP = 젬 XP값 × 콤보 배율 × XP 보너스(어픽스·스킬·유물 증폭기 ×1.15)
- **젬 콤보**: 2초(120틱) 안에 계속 주우면 스택당 +0.05, 10스택 = **최대 ×1.5**
- **보급선**: HP 420, 20초 제한, 격추 시 젬 14개(각 XP 6) 확정 드랍

**변칙 경보** (수락 시, `src/sim/anomaly.ts`):

| 변칙 | 능력·보상 효과 |
|---|---|
| 중력 폭풍 | 적 탄속 ×0.7 (회피 쉬워짐), 드랍률 ×1.5 |
| 군체 대발생 | 적 수 ×2, 적 HP ×0.6 |
| 암흑 성운 | 유니크 드랍률 ×2 (시야 감소는 연출뿐, 판정 무영향) |

## 7. 원소 상태이상 3종

어픽스(작열의·빙결의·방전의)가 붙은 무기로 명중 시 발동. (`src/sim/status.ts`)

| 원소 | 효과 | 수치 |
|---|---|---|
| 화염 | 지속 피해 | 2초(120틱) 동안 틱당 어픽스 롤값(2~5) 피해 |
| 냉기 | 감속 | 1.5초(90틱) 동안 적 이동속도 ×0.55 |
| 전격 | 즉발 연쇄 | 반경 260 내 최대 3마리에게 어픽스 롤값(4~10) 피해 |

참고 — 반대로 **플레이어가 받는 감속**(감속 지대 등): 이동속도 ×0.5, 1.5초. 대시 임펄스에는 적용되지 않으므로 대시로 탈출할 수 있습니다.

## 8. 전투력 점수 (combat power)

장비 등급·어픽스 가치를 종합 평가한 수치입니다 (`src/save/combatPower.ts`). 직접 전투에 쓰이진 않지만:

- 퇴역 시 **수호 기체 스냅샷의 스탯 스케일**이 됩니다 (HP·접촉피해·탄피해를 전투력/100로 스케일).
- 수호 기체 **소멸 시 계보 포인트 회수량**의 기준이 됩니다.
