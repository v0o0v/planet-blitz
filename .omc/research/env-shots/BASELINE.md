# 카르곤 픽셀 기준선 (Phase 0, main `bea9f32` + `__pb.graphicsSettings` 노출)

테마 추출 리팩터(Phase 1)가 **카르곤 화면을 한 픽셀도 바꾸지 않았음**을 증명하기 위한 기준선이다.
테스트가 아니라 렌더된 픽셀로 판정한다 — 카르곤 레인에서 "각 파일이 자기 상수와만 일관해서
테스트는 전부 그린인데 화면이 틀린" 사고가 실제로 있었다.

## 촬영 절차 (재현)

1. `node scripts/env-verify/shot-server.mjs` (포트 5181, 출력 `.omc/research/env-shots/`)
2. dev 서버 5180 → `http://localhost:5180/?harness=1`
3. `scripts/env-verify/page-capture.js` 를 콘솔에 등록
4. 시드 1~4 × `ticks 900` × `mode bg`(엔티티·UI 제외) / `full`(UI만 제외)

**캡처 규율** — 셋 다 빼면 판정이 틀어진다:
- `quality: 'high'` 고정. 안 하면 하네스 일시정지 시 FPS 계측 10 → 티어 `low` → `gates.halo` false
  → **발광 4종이 통째로 꺼진 화면**을 보고 판정하게 된다.
- `requestAnimationFrame` 을 **await 하지 마라**. hidden pane 에서는 영영 안 불려 교착한다.
  `ticker.update()` + `renderer.render()` 를 직접 두 번 돌린다.
- `post` 슬롯보다 뒤에 있는 stage 자식을 전부 숨긴다. 안 하면 레벨업 파워업 오버레이(목재 패널)가
  화면 83%를 덮어 세 지표가 전부 그걸 잰다 — 실제로 첫 촬영에서 일어났다.

같은 절차를 두 번 돌린 두 프레임의 차이:

대조군(서로 다른 시드): mean **46.49**. 즉 신호가 바닥의 약 2000배다.

**회귀 게이트: `analyze.mjs regress --max 0.12`.** 바닥(0.02)보다 넉넉하되 시드 간 차이(46)의
0.3% 라, 의미 있는 렌더 변화는 전부 잡힌다.


## 레이어별 기여도 서명 (시드 1, 틱 900, 일시정지)

`env.solo()` 로 한 장만 켠 프레임과 전부 끈 프레임의 차이. **레이어마다 지표 모양이 다르므로
지표 하나로 전부 판정하면 오판한다** — 특히 데칼은 평균이 2.28이라 평균만 보면 "안 그린다"로
읽히지만 국소 14.45 · 변화 블록 47% 로 살아 있다.

| 레이어 | mean | 국소 상위1% | 변화 블록 | 성격 |
|---|---|---|---|---|
| parallax | 28.46 | 48.88 | 100% | 넓고 낮은 저주파 변조 |
| decals | 2.28 | 14.45 | 47% | 성긴 고주파 산포 |
| lava-light | 26.27 | 150.18 | 100% | 좁고 강한 국소 발광 |
| atmosphere | 6.86 | 61.81 | 47% | 입자 |
| grade | 17.64 | 26.65 | 100% | 균일 아핀 |
| (전부) | 40.35 | 180.56 | 100% | |

**Phase 2 레인 판정 기준**: 새 행성 테마의 각 레이어가 위와 같은 *차수*의 서명을 내야 한다.
어떤 레이어가 mean·국소 둘 다 바닥이면 그 레이어는 화면에 없는 것이다(1차 실패 재현).

## 카르곤 현재 상태 (시드 1, `bg`)

| 지표 | 값 |
|---|---|
| 명도 mean / p05 / p50 / p95 | 27.78 / 14.93 / 23.71 / 54.70 |
| dark(L<24) / mid / bright(L≥96) | 51.26% / 48.08% / 0.65% |
| 격자 excess x / y | −0.19 / −0.39 (대조 주기보다 **낮다** = 격자 없음) |
| 위장 최악 | `enemy_charger` **6.71%** |

주의 — `darkFrac` 은 서술이지 판정이 아니다. 비평가가 지적한 "재질 없는 검정"은 *어두움*이 아니라
*질감 없음*인데 이 지표는 둘을 구분하지 못한다. 실제 카르곤 암부에는 균열망 질감이 있다.

**위장은 적별로 분리해서 본다.** 4종 × 상위 3색을 OR 로 묶으면 값이 구조적으로 부풀고(24%),
무엇보다 어느 적이 문제인지가 사라진다. 적별로 보면 차저 6.71% / 용암분출 1.21% / 박격 0.26% /
지원 0.00% 이고, **고쳐야 할 대상은 차저 하나**임이 바로 드러난다(어두운 청동색 덩어리라
암부 지각과 실제로 닮았다).
