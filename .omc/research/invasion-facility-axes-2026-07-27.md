## 1. 수정 전 — 17종 중 10종의 강화축이 깨져 있었다

| 상태 | 설비 | lv1 → lv17 → lv50 → lv99 |
|---|---|---|
| **전 구간 0** | `rail` `heavyrail` `siegecannon` `spawner` `gravwell` | 0 → 0 → 0 → 0 |
| **역전** | `rapid` | 240 → 420 → **0** → **0** |
| **역전** | `toxinturret` | 55 → 44 → **0** → **0** |
| **완전 평탄** | `press` | 804 → 804 → 804 → 804 |
| 비단조 | `shock` · `demolisher` | 760 → 1412 → 870 → 840 |
| 정상 단조 | `mortar` `laser` `flame` `venomvent` `blightpool` `corrosivemist` `breachturret` | ✓ |

m8 §5.6 은 "설비 9종 중 5종"으로 봤는데, Lane9 신규 8종까지 재면 **17종 중 10종**이다.

## 2. 갈라지는 축은 **탄환 수**다 — 예외가 없다

| pellets | 설비 | 결과 |
|---|---|---|
| **1** | `rapid` `rail` `heavyrail` `siegecannon` `toxinturret` | **전부 0 또는 역전** |
| 3 (30도) | `breachturret` | 252 → 2226 ✓ |
| 5 (44도) | `mortar` | 8 → 3195 ✓ |

`fireFacilityBullets` 의 `spreadDeg` 는 `pellets > 1` 일 때만 부채꼴을 편다. 즉 **단발 포탑에는
확산이라는 축이 아예 없어** 조준이 한 점에 고정되고, 움직이는 표적을 구조적으로 못 맞힌다.
다발 포탑만 자체 확산으로 그 오차를 우회하고 있었다.

편대를 넣은 현실 조건에서도 같았다(`rapid` 설비단독 420 / 편대포함 490) — 격리 하네스의
인공물이 아니다.

## 3. 왜 "0" 이 아니라 "역전" 인가 — 교전이 사라진다

`rapid` lv50 은 빗나가는 게 아니라 **거의 쏘지 않는다**(6시드 18발 vs lv17 276발).
발사 게이트 계측:

| | outRange | outArc | LOS blocked | PASS |
|---|---|---|---|---|
| `rapid` lv17 | 99.7% | 0.2% | 0.0% | 0.1% |
| `rapid` lv50 | 98.8% | 1.2% | 0.0% | **0.0%** |

거부 사유는 **사거리**다(사계·LOS 아님). 그리고 생존 설비 수가 lv17 **10.75/12** → lv50 **12.00/12** 다.

**플레이어가 설비를 부수러 다가올 때만 교전이 일어난다.** HP 를 올리면 안 부서지고 → 강제 스크롤
창이 플레이어를 지나쳐 보내고 → 교전 기회가 줄어든다. 명중률이 바닥인 단발 포탑은 기회가 줄면
바로 0 이 되고, 명중률이 정상인 다발 포탑은 기회가 줄어도 발당 피해 증가로 계속 자란다.

> 난이도 복원의 핵심 장애물이 이것이었다: **난이도를 올리려고 방어체 레벨을 올리면 단발 포탑이
> 오히려 약해진다.**

## 4. 수정 ① — 단발 포탑에만 결정론 조준 흔들림

`turretAimAngle`(`src/sim/invasion/facility.ts`): `spec.pellets > 1` 이면 표적 방향 그대로,
단발이면 `TURRET_AIM_JITTER_DEG = 4` 도만큼 `tick`·`id` 의 순수 삼각파로 흔든다(RNG 미소비).

| 설비 | 전 | 후 |
|---|---|---|
| `rapid` | 240 / 420 / **0** / **0** | **168 / 224 / 270 / 477** ✓ 단조 |
| `toxinturret` | 55 / 44 / **0** / **0** | **30 / 55 / 100 / 176** ✓ 단조 |
| `mortar` | 8 / 378 / 1755 / 3195 | **동일** (회귀 0) |
| `breachturret` | 252 / 567 / 1239 / 2226 | **동일** (회귀 0) |

lv1 구간이 조금 내려가는 것(240 → 168)은 흔들림의 대가이고, 단조 복구가 그보다 중요하다.

### 4-1. 편차 사격(lead)은 **실측으로 기각**했다

표적 속도로 도달 지점을 예측하는 편차 사격을 구현해 재 봤으나 참조봇 기준으로 **해로웠다**:

| 변형 | `rapid` | `mortar` | `breachturret` |
|---|---|---|---|
| 원본 | 240/420/0/0 | 8/378/1755/3195 | 252/567/1239/2226 |
| **lead 0.85 단독** | 24/70/0/0 (역전 그대로) | 8/378/1677/3053 | 0/405/1239/2226 |
| **흔들림 단독** | **174/238/270/477** | 56/468/1706/2676 | 12/81/177/318 |
| lead + 흔들림 | 18/0/0/0 | 80/234/624/1037 | 0/162/411/547 |

참조봇은 탄도로 움직이지 않고 카이팅·회피로 **진동**하므로, 순간 속도를 외삽하면 표적이 지키지
않을 방향을 겨눈다.

> ⚠️ **이 판정은 참조봇 기준이다.** 사람은 봇보다 탄도에 가깝게 움직이므로 편차 사격이 사람에게는
> 유효할 수 있다(m8 §1.4). 플레이테스트 데이터가 생기면 다시 볼 항목이지 "편차 사격은 틀렸다"로
> 굳히지 마라.

### 4-2. 밟은 함정 — 사계 판정을 편차 각도로 하면 무발사가 된다

초판이 `withinArc` 를 **편차 각도**로 걸었다. 예측각이 사계를 조금만 벗어나도 **발사 자체를 거부**해
`breachturret` 이 2226 → **정확히 0** 이 됐다(정확도 저하가 아니라 구조적 무발사). 교전 판정은
표적의 실제 방향으로 하고, 겨누는 각도만 `clampToArc` 로 접는 것이 옳다.

## 5. 수정 ② — `press` 끼임 피해가 강화 3축을 타게

`resolveFacilityStats` 의 `rawDamage` 선택에 `FACILITY_BEHAVIOR_PRESS → spec.pressCrushDamage`
분기가 없어 `spec.damage`(프레스는 0)를 읽고 있었고, 스폰 갈래도 스탯 축을 통째로 건너뛰었다
(그 갈래의 주석은 이를 **의도**라고 적어 뒀지만, 결과는 레벨·등급·승급이 전부 무효였다).

## 6. 난이도에 미친 영향 — 필요조건이지 충분조건이 아니다

24시드 밴드:

| 밴드 | PR#160 직후 | 이 브랜치 | 목표 |
|---|---|---|---|
| 하위 | 100.00 | 100.00 | 85+ |
| 중하 | 99.40 | 99.40 | 55~80 |
| 중위 | 90.97 | **85.42** | 25~55 |

중위만 **−5.5pp** 움직였다. 하위·중하는 100/99.4 로 포화돼 있어 설비 피해 정도로는 안 내려간다.

**이 수정의 값어치는 난이도 하락 자체가 아니라 레버를 되살린 데 있다.** 지금까지는 방어체 레벨을
올려도 설비 10종이 반응하지 않았고 그중 3종은 **역방향**이었다. 이제 수치 튜닝이 의도대로 먹는다.

## 7. 남은 것

1. **아직 죽어 있는 5종** — `rail`(예고 36틱) · `heavyrail`(40틱) · `siegecannon`(단발·저연사·장거리) ·
   `spawner` · `gravwell`. 앞 셋은 m8 §5.2 가 "어떤 산탄 조합으로도 안 살아난다"고 실증한 계열이라
   **데이터 결정**(예고 단축 / 다발화)이 필요하다. 뒤 둘은 피해 축이 아예 다른 설계다(재검토 대상).
2. **비단조 2종** — `shock` · `demolisher` (760→1412→870→840). 원인 미조사.
3. **보스 램프 배정 역전** (m8 §5.5) — 손대지 않았다. 마이그레이션 SQL 정본 + 테스트 미러 13줄을
   동시에 고쳐야 하는 별건이다.
4. **밴드 목표 복원** — 위 레버가 살아났으니 이제 방어체 수치 튜닝이 유효하다. 하위·중하가 포화라
   설비 말고 편대·보스 축을 함께 올려야 한다.
