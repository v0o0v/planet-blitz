# 엔티티 AAA 레인 — 잔여 격차와 다음 패스 (2026-07-30)

세 레인(플레이어·적·해저드)이 각각 4~7 라운드를 돌고 비평가 판정을 받은 뒤 **남은 것**이다.
전부 소유 위치가 확정돼 있고, 계약 §3 항목표에는 **없는** 것들이다 — 항목은 채워졌고 이건
그다음 의제다.

정본 경위: `.omc/plans/entity-aaa-contract.md`(계약) · `.omc/research/entity-aaa-baseline-2026-07-30.md`
(기준선 결함 + 계측 규율).

## 이 레인이 반복한 단 하나의 실패 유형

**코드상 참, 화면상 거짓.** 열 번 넘게 같은 형태로 나왔고 **매번 단위 테스트는 전부 초록**이었다.

| 레인 | 재발 | 실체 |
|---|---|---|
| A | 1차 | 스프링 오버슈트가 실측 1.8% — "2차 운동을 넣었다"가 화면에서 지연과 구분 불가 |
| A | 4차 | 손상 가산 모델이 `texture × tint × alpha` 를 빠뜨려 크기 5배·채널 우열 반전 |
| A | 5차 | 판면 램프 기하가 긴 축 기준이라 최강 스트립 둘이 **0픽셀** |
| A | 6차 | 측정 상수의 **입력**이 틀림(롤 스쿼시 값을 base 로, 불투명 반폭 27~47% 과소) |
| A | 7차 | **합성 경로** — `Sprite` 마스크가 렌더 타깃을 만들어 곱연산 78%·가산 92% 소실 |
| B | 1차 | 예고 듀티를 **합성 시나리오**로 재서 "오탐 0" — 실제 88.9% |
| B | 2차 | 듀티 **측정 창**이 전투 시작 전 — 실전투에서 27~53% |
| B | 3차 | 듀티 **시드 선택**이 통과를 만듦(시드 4 를 건너뜀. 정직한 격자에서 2차 코드는 85.65%) |
| C | 1차 | `heat=0` — 재질 여섯 겹 중 다섯이 `heat` 에 곱해져 예열 내내 정확히 0 |
| C | 2차 | LOD 커서가 세션 누적이라 몇 초 만에 전 장판이 최하위로 굳음 |
| C | 5차 | 오염에 **감산 축 부재** — 밝은 원판 위 가산으로는 대비가 안 생김 |

**공통 처방**: 게이트를 상수·알파 진폭이 아니라 **화면 픽셀 실측**에 걸어라. 그리고 그 실측의
**입력이 런타임 실제값인지** 먼저 확인해라.

### 검증 도구 자체가 결함원이었던 경우 (여섯 번)
1. 캡처 프로토콜이 전이 연출을 얼려 **없는 회귀**를 만들었다(명도 4.2배 오진)
2. 정지 감시 스크립트가 **빈 디렉터리**를 정지로 오판
3. `pnpm lint` 가 **검증 부산물**(비평가가 남긴 계측 스크립트) 때문에 실패
4. PowerShell `$?` 가 native + `2>&1` 에서 **exit 0 인데 false** → 4,931건 통과를 실패로 오독
5. 게이트 척도가 **차지 면적에 의존**해 실루엣 한정 이펙트를 부당하게 반려
6. 자기증명 테스트 다수(자기 궤도 파라미터·자기 픽스처·0픽셀 스트립의 알파를 증인으로)
