# 하네스 치트 패널 씬 중심 개편 — 스펙 (2026-07-19)

## 사용자 요구
- 현재 패널이 기능 종류별(씬 런처/관전/개입/인스펙터) 배치라 산만함.
- **씬별로 구분**하고, 각 씬에서 **테스트해야 하는 내용 위주**로 재배치.
- 눈으로 테스트하면서 수정 대상을 바로 재현·확인할 수 있어야 함.

## 요구 분해
1. 씬 탭 구조: 한 번에 한 씬의 도구만 보인다 → 시각적 소음 제거.
2. 각 탭 = "이 씬 띄우기" + 그 씬에서 유효한 치트/관찰 도구만.
3. 재생 제어(배속/일시정지/틱/ff)는 모든 씬에서 쓰는 횡단 도구 → 상단 고정 미니바.
4. 오염 배지·힌트도 공통 영역 유지.
5. 탭 선택은 250ms 자동 재렌더를 넘어 보존(클로저 상태).
