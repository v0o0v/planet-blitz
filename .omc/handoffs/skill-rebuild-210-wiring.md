## 1. ⚠️ 환경 함정 — 이걸 모르면 거짓 그린을 만든다

**`pnpm` 이 이 환경의 PATH 에 없다.** Bash 도 PowerShell 도 `command not found` 다.
반드시 **`npx pnpm`**(또는 `corepack pnpm`)을 써라.

그리고 이것이 **조용한 거짓 성공**을 만든다. 리드가 실측했다:

```
pnpm verify 2>&1; echo "VERIFY_EXIT=$?"
```

→ 하네스는 **exit 0** 을 보고했다. 마지막 `echo` 가 성공했기 때문이고, 실제 `$?` 는
**127(명령 없음)** 이었으며 **테스트는 한 건도 안 돌았다.**

- `pnpm`/`vitest`/`verify` 뒤에 **다른 명령을 이어 붙이지 마라**(`;` 포함). exit code 가 뒤엣것이 된다.
- 파이프도 금지(`| tail` 은 `tail` 의 코드를 잡는다 — 리포 `CLAUDE.md` 규약).
- 출력은 **파일로 리다이렉트**하고 exit code 를 따로 확인하라.
- **"통과했다"고 적기 전에 `Test Files` 집계 줄을 눈으로 봐라.** 집계 줄이 없으면 안 돈 것이다.

### 이 넷에서 가장 조용한 함정 둘 — 반드시 읽어라

1. **S9 의 건너뛰기 술어를 `aux1 > 0` 으로 쓰면 안 된다.** 마커값(`0x5ea1` = 24,225 ·
   `0xc1a58e` = 12,691,342)이 **영구 정지**해 **S9 를 한 포인트도 안 찍어도 격전이 멈춘다.**
   반드시 구간 검사 `0 < aux1 <= STASIS_TICK_MAX`. 정지 틱(`45+5×Lv`)이 어픽스로 20 을 넘겨도
   세 자릿수라 두 마커값과 **수치 구간이 겹치지 않는 것**이 안전 근거다 — 상한 상수를 만지면
   함께 재확인하라.
2. **C-3 의 창 종료 에지도 `=== 360` 이 아니라 통과 판정**이어야 한다. PH5 가 `HOLD` 를 늘리고
   주입 스킬이 `aux0` 을 한 번에 여러 칸 올리므로, 등호면 임계를 건너뛴 틱에 토큰이 영영 안 서고
   **다섯 스킬이 통째로 조용히 죽는다.** 기존 `cloakEntryCrossed`(`src/sim/cloak.ts`)와 **같은
   파일에 같은 형태의 짝**을 만들어라.

### 부정됐지만 조치 불요 — 오히려 좋은 소식

`phantom.md` ⑥ 선결 2 의 **"오토파일럿은 회피를 안 해 은신을 못 잰다"는 거짓**이다.

## 4. 단계 4 — ADR-0050 의 전제가 틀렸다 (정정 절이 ADR 본문에 있다)

**ADR 을 문자 그대로 집행하면 아무것도 막지 못하는 문을 잠근다.**

1. **`items`·`ships` 는 "클라 rw 미러"가 아니다.** 클라가 **읽지도 쓰지도 않는다** —
   `.from('items')`·`.from('ships')` **각 0건**이고 주석 3곳이 이미 그 사실을 기록해 뒀다.
   `public.ships` 에 INSERT 하는 자리는 **NPC 시드 1곳**뿐이라 실 플레이어 기체 행은 영영 안 생긴다.
   → **진짜 위조 창구는 봉인 없는 `profiles.save` jsonb** 다. 봉인 트리거가 고정하는 **12컬럼에
   `save` 가 없고**, 아이템·기체·장착·XP·레벨이 전부 그 안에 산다.
   **표적을 `profiles.save` 봉인으로 재설정**(승인). ADR-0027 이 정한 *"save 에는 전투력 무권위
   상태만 남는다"* 의 **미이행 절반**을 완료하는 일이다.
2. **"드랍은 sim 재실행 불필요"는 결론이 맞고 근거가 틀렸다.** `rollItem` 은 순수하나 **드랍 시드가
   `dropRng` 소비 열의 함수**라 재현이 불가능하다 → 서버가 **자기 시드로 새로 굴린다**
   (`hash(server_run_secret, pve_run_id, drop_index)` — 클라 입력 0바이트).
   **바닥 전리품은 「개수만 계약」**(승인) — 런 중엔 "회수 N점"만, 개봉은 정산 때.
3. **`settle_pve_run` 은 claim-and-clamp** 라 *"클라는 무엇이 나올지 모른다"* 를 구조적으로 못 받는다
   → 재사용 대상은 **`commission_grants`·`daily_reward_claims` 배송함 패턴**(리포에 이미 두 벌).
   ⚠️ **`settle_pve_run` 본문은 고치지 마라**(5회 재정의됐고 그 복제가 PvE 정산을 100% 깨뜨린 전례).

**저장 예산(승인)**: payload 통째 저장 = 750MB 로 무료 티어 초과 → **`(dropSeed, rarity, source)`
3필드만 + 보유 상한 강제** ≈ 130MB. 원시 `pve_runs` 7일 GC ≈ 70MB, 롤업 연 89MB.
⚠️ **full-cross 롤업은 26,040셀/일 > 12,000런/일 이라 압축비가 1 미만** — 한 큐브로 못 만든다.
주변화 큐브 둘로 쪼갠다.

**반드시 인수해야 하는 것**: `apply_invasion_result` 의 재화 지급 2건(복수 보너스 광물 +50 ·
방어 성공 크레딧 +40)이 **`currency_grants` 원장을 우회**한다. 재실행이 사라지면 `attackerWon` 이
순수 클라 주장이 되고 그 주장이 **캡 밖 재화**를 직접 움직인다 → `grant_currency_for(…, 'invasion')`
으로 돌리고 **`CAP_INVASION_*` 을 등록**하라. ⚠️ 등록을 빠뜨리면 40/50 은 기본캡 1000 아래라
**증상 없이 통과**하고, 나중에 밸런스가 그 값을 올리는 날 조용히 절삭된다.

**서버 가드 실증**: 적용 스크립트로는 못 한다. `scripts/prove-*.ps1` 형식을 그대로 복제하라 —
JWT 클레임 위조 + `BEGIN…ROLLBACK` + **한 SELECT 안에 RPC+조회 금지**(스냅샷 때문에 거짓 실패) +
**BEFORE/AFTER 델타**(RPC 자기 응답만 믿지 않는다) + 판정 토큰 ASCII.

## 5. 단계 2 — 구조가 확정됐다 (실측이 인계 문서를 뒤집었다)

mallow 16 · bubble 19회). 그대로 팬아웃하면 병렬 이득이 머지 비용에 전부 먹힌다.

### 5-2. 선행 커밋 **S0** — 이것이 실재하는 유일한 레인 간 의존

**S0 는 거동·해시 불변이어야 하고, 그것이 S0 의 합격 조건이다**(골든 3종 초록 유지).

1. `WorldState` 에 **`skillCarry`/`skillStage` 고정폭 8 배열 2벌** + `replay.ts` 꼬리에
   **「16칸 전부 0이면 무폴드」** 조건부 폴드 + `commissionCarry` 분류 2줄
   (`skillCarry`→WORLD_CARRY · `skillStage`→WORLD_FRESH)
2. **`skillLv()` 정본 헬퍼 신설** — ⚠️ **주석에만 있고 구현이 없다**(`world.ts:790` ·
   `items/loadout.ts:146`). `skillAffixLv` 는 파생·폴드만 되고 **소비처 0**이다.
   `base < 1 이면 0` 한 줄이 "해금은 포인트로만" 계약의 전부다.
3. **감쇠 사슬의 스킬 슬롯 2칸**(감소·흡수) — 6기체가 같은 자리를 요구하는데 문서들이 서로
   "먼저 구현되는 레인이 세운다"고 적었다. **병렬에서는 여섯이 동시에 "먼저"가 되므로 성립하지
   않는다.** 계수 0이면 `v*1===v`·`v-0===v` 라 선행 커밋 자체는 해시 불변이다.
4. `crossed()` 통과 판정 leaf + `readSlot`/`writeSlot`(`Math.trunc` + `max(0,·)` 강제)
5. **앵커 9개를 빈 디스패처로 추출** — `onVolleyFired`·`onDashFired`·`onGemCollected`·
   `onPlayerDamaged`·`onKillsDelta`·`onBulletExpired`·`onWallContact`·`onDamageChain`·
   `onSignatureStep`. 각각 `if (!state.skillsOn) return;` 후 `switch (state.sigBit)`
6. `skillDerived` 파생 블록 — **`createWorld` 에서 1회 확정**(선례 `armorMaxStacks`,
   `world.ts:1130-1153` 이 근거까지 주석에 적어 뒀다). sim 루프는 정수만 읽는다.

그 뒤 **7레인은 `src/sim/skills/{ship}.ts`(신규) + `activeHandlers/{ship}.ts` +
`data/ships/{ship}.ts` + `skillSlots.ts` 자기 블록 + 자기 테스트**만 만진다 —
**이 경계면에서 `isolation: "worktree"` 가 비로소 유효해진다.**

⚠️ S0 는 **소비자 0 인 배선을 만든다**. 방어: S0 의 테스트는 **앵커가 실제로 불린다**를 증명하되
(호출 카운터), **"효과가 있다"를 단언하지 않는다.**

### 5-3. ⚠️ 「전부 0이면 무폴드」가 깨지는 조건 — 전수

1. **`-1` 센티넬**(`(-1)>>>0 = 4294967295`) → **규약: 0 = "없음"**. 엔티티 id 는 1부터라 자연 센티넬.
2. **투자 게이트 밖 쓰기** → 모든 쓰기는 `if (state.skillsOn && skillLv(...) >= 1)` 안쪽.
3. **`createWorld` 가 0 아닌 초기값** → 초기값 전 슬롯 0. "만충 시작"은 0을 만충으로 해석.
4. **다른 기체 코드가 게이트 없이 쓰기**(슬롯이 기체별로 겹친다) → 앵커에서 `state.sigBit` 디스패치.
5. 구간 승계로 carry 가 0이 아닌 것은 **의도된 거동**.

### 5-4. ⚠️ 골든은 레인마다 터진다 — **210스킬 = 1 PR**

골든 픽스처의 `skillInvest` 가 **비어 있지 않다** — `axisBuild(0,44)` 가 `v[0]=20,v[1]=20,v[2]=4`
로 **각 축 첫 인덱스부터** 채운다(`scripts/recordStrikerBaseline.ts:114-171` ·
`scripts/deno-verify/scenarios.ts:219-227,307-316`). **어느 레인이든 자기 축 앞쪽 스킬을 배선하는
순간 그 기체 골든이 갈린다.**

→ 레인당 1 PR 은 **불가능**하다. 커밋 2 형태를 반복하라 — **1 PR 안에 커밋을 쌓는다.**
**골든 재생성 목표 = 1회.** 순서: S0(골든 초록 유지) → 7레인 배선(이 구간 내내 골든 빨강 = 정상)
→ **재생성 전에** "안 바뀌어야 하는 것" 단언 통과 → 골든 3종 재생성 1회 → 증인 시드 4파일 갱신
(`fullRun`·`planetTierCompletion`·`autopilot`·`emergentRunLength`) → EF 재배포 → 클라.

### 5-5. E5 제약은 폐기됐다

`prerequisites.md` §5-7 · `skill-rebuild-commit2.md` §5 의 **"스트라이커 M5 가 먼저"는 무효**다.
E5 는 착지했고(`world.ts:1084,2174` · `commissionCarry.ts:183` · `tests/wallContactFlag.test.ts`)
해시 폴드 여부도 결정됐다(**접지 않는다** — `world.ts:1055-1060`). 벽을 무는 7스킬이 전부
**읽기만** 하므로 **레인 간 선후 의존은 0**이다.

### 5-6. 상태 예산 (전수 조사)

상태 0 = **173종** · 신규 상태 = **37종** · **신규 시스템 = 0종**(헌장 준수, 위반 0건).
신규 폴드 정수는 36칸이지만 **한 런의 동시 필요분은 최대 6칸**(기체가 하나뿐).
그래서 폭 8 = 실측 6 + 여유 2. ⚠️ **"넉넉하게 32"는 반대다** — 미배정 슬롯이 영구 0으로 남아
오인덱스가 **조용한 무연산**이 된다(이 저장소의 지배적 실패 모드).

⚠️ **B 태그 여유가 없다**: 스트라이커·브루저·말로우가 세 축 전부 2/2 포화.
**재설계가 B 를 하나라도 늘리면 즉시 헌장 위반**이므로 설계로 되돌아와야 한다.

## 6. 반복 금지 — 앞 레인들이 실제로 밟은 지뢰

- **`tsc` 는 위치 인자 삭제를 전부 잡지 못한다**(`(x, undefined, 5000)` 이 말이 되어 통과).
- **「시그니처 없음」은 제품에 없다.** 대조군은 **트리거 굶기기**로 만들어라.
- **접촉 술어를 `circleOverlapsWall` 로 바꾸자는 안은 실측으로 기각됐다**(부동소수 손실 31~43%,
  모서리 간극 5.8u). 근거가 `src/sim/world.ts:2088~2100` 주석에 있다 — **재제안 전에 읽어라.**
- **골든 재생성은 검증이 아니다.** 근거는 재생성 **전에** 통과시킨 불변식이어야 한다.
- **뮤테이션 없이 계측기를 믿지 마라.** 이 레인에서도 또 하나 나왔다(§2-1).
- **"정확히 0"은 구조적 무발사 신호다.**
- **`clamp` 가 앞단에 있으면 뒷단 상한은 한 방향으로만 검증된다.**
- **사용법을 문서에 적기 전에 실제로 한 번 돌려라.**
- **함수 본문을 옮기는 리팩터는 그 본문을 문자열로 읽는 계약 테스트를 조용히 깬다.**
- **동시 편집 중 워커가 본 일회성 오류는 증거로 못 쓴다** — 최종 판정은 전원 착지 후 리드의
  깨끗한 단독 실행에서만.

### 이 레인이 새로 추가하는 것

- **문서의 줄 좌표를 믿지 마라.** `element-inventory.md` 의 좌표가 **200~350줄 밀렸다**
  (감쇠 사슬 `3760-3930`→`4030-4140` · 대시 `1917`→`2065` · `collectGem` `3934`→`4176` ·
  `compact` `4026`→`4268` · aux 표 `1992-1998`→`2197` 등 10건). 그 문서 자신이 "상호참조가
  낡았다"고 경고하면서 **자기 좌표도 낡았다.** 심볼로 grep 해서 열어라.
- **`element-inventory.md` §9.4 의 "스트라이커 — 시그니처 없음"도 낡았다**(정조준 사이클 착지).
- **한 필드를 여러 파일이 각각 "아무도 안 쓴다"고 주석에 적고 동시에 쓰고 있을 수 있다** —
  `enemy.aux1` 이 정확히 그랬다(`midClash.ts:23` 과 `facility.ts:123` 이 둘 다 그렇게 적었다).
  **"미사용" 주석은 근거가 아니다. `src/sim/**` 전체 grep 이 근거다.**
