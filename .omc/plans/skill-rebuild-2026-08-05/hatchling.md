## ① 시그니처 확인 — 부화 (brood, 기존 유지)

**규칙(기존)**: 처치를 적립해 임계(`hatchThreshold`)에 닿으면 병아리 드론 1기가 자동 출격.
동시 4기 상한(`BROOD_MAX_DRONES`), 고정 4방향 배치, **RNG 미소비**가 계약이다
(`src/sim/world.ts:2244-2273` `stepHatchBrood`).

- 비트: `SIG_HATCHLING_BROOD = 21` (`src/sim/shipSignature.ts:40`) — wire 계약, 불변.
- `aux0` = 마지막 출격 시점 `state.kills` 스냅샷 · `aux1` = 미사용(0).
  출격 판정 `state.kills − aux0 >= hatchThreshold(state.kills)`.
- 임계 공식: `12 + floor(누적처치/60)×4`, 상한 40 (`shipSignature.ts:203-209`).
- 병아리 실체 = `turretPickup` + `ownerId = BROOD_MARK`(0xb400d5). 자동 조준·사격은
  `stepTurrets`(`world.ts:3113-3143`), 수명 `TURRET_LIFE_TICKS = 600`(`src/sim/events.ts:37`),
  컬링 제외는 `isGimmick`(`world.ts:1687`). 상한 계수는 `BROOD_MARK` 만 센다.
- 상한 만석이면 **aux0 을 갱신하지 않고 보류** — 자리가 나는 즉시 출격, 적립 비소멸.
- `advanceHatch`(`src/sim/activeHandlers/hatchling.ts:30-33`)는 **0 에서 클램프**한다 —
  스냅샷을 0 밑으로 미는 전진분은 **조용히 소각**된다(이월 없음). 이 소각을 정직하게
  계약으로 채택한다: aux0 전진형 스킬(NU5)은 전진량 1 이라 소각 노출이 미미하고, 초과
  적립의 이월은 별도 스킬(NU10 알 저금)이 **명시적 메커닉으로** 담당한다.
- 사연 카운터 `state.broodLaunches`(비-해시, `world.ts:1034·2270`) — **거동 게이트 사용 금지**.
- 액티브 6종(`data/ships/actives/hatchling.ts`)은 전부 스냅샷(aux0) 타이밍 조작이 축이다 —
  소환 자체는 시그니처만 한다(ADR-0041 Non-Goal ① 준수). 30스킬도 **직접 소환하지 않는다.**

### 저장처 grep 확인 (헌장 규율 — 1R 정정 반영)

- `BROOD_MARK` 점유처 전수(`src/` grep): `world.ts`(1687·2249·2266) + `shipSignature.ts:185`
  + 주석 언급 2건(racing.ts·contamination.ts). 충돌 없음.
- **병아리 `phase` 는 미사용 필드가 아니다** — 생사 스위치다: `events.ts:76` 이
  `phase = 1`(활성)을 세우고, `isActiveTurret`(`events.ts:82-84`)·스크롤 앵커 판정
  (`scrollMode.ts:118-120`)·렌더(`snapshot.ts` 포탑 분기)가 전부 `phase === 1` 을 읽는다.
  여기 값을 누적하면 첫 변경 즉시 비활성 판정(좀비화)+상한 계수 누락+앵커 반전+렌더 소멸.
  개체별 상태가 필요한 스킬(BD7)의 저장처는 **`timer` 로 확정** — turretPickup 경로
  (`events.ts`·`stepTurrets`)가 읽지 않고, `timer` 점유 선례(보조무기 사이클,
  `world.ts:2725`)는 **플레이어 엔티티 한정**이며, `replay.ts` 가 이미 해시하는 필드라
  레이아웃 불변. 구현 레인은 turretPickup kind 의 `timer` 미점유를 `src/sim/**` 전체
  grep 으로 최종 확인한다.
- 병아리 `aux1`: 편대 인코딩(`aux1` = 진형 진행 틱)은 `kind === 'enemy'` 편대원 소관 —
  turretPickup 의 `aux1` 점유는 grep 0건(SH9 소멸 사유 코드가 사용, ② 참조).

## ② 스킬 30종

표기: 구현 태그 **A(재사용) / B(신규 상태) / C(신규 시스템)**. 레벨 스케일은 20 초과 자연
연장 — 선형 또는 연속 체감 곡선 `base + k×c/(Lv+c)` 만. **분모·주기·배율에 레벨이 음의
계수로 들어가는 선형식은 금지**(1R: 0 교차·`%0`·음수 배율 사고 3건) — 감소 방향은 전부
체감 곡선으로 쓴다. 정수 계단은 양적 반올림이며 폭을 정직 표기. 곡선 나눗셈은
`createWorld` 가 투자 레벨당 1회 정수 확정(striker.md 선례).

### 부화 (brood / offense) — BD1..BD10

### [BD1] 조기 부화 (early-hatch)
- 본체: **부화 요구 처치 수가 줄어든다** — 같은 청소량으로 더 자주 부화한다.
- 레벨 스케일: 실효 요구치 = `max(6, hatchThreshold(k) − (1 + floor(Lv/5)))` (Lv20 감산 −5,
  5레벨 폭 정수 계단. **`max(6,…)` 명시** — 기본항 12 의 절반이 바닥, 어픽스로도 불변).
- 1레벨 가치: 첫 부화가 11킬로 당겨진다. / 20레벨 몰빵 가치: 초반 요구 7(후반 상한 40
  구간 35) — 부화 리듬 전체가 당겨지는 몰빵 축.
- 연계: 시그니처(직접 — `hatchThreshold` 호출부 파생) · BD2·NU10 과 부화 빈도/이월 결합.
- 구현: A — `stepHatchBrood` 임계 판정에서 읽는 시점 감산(신규 상태 0).

### [BD2] 쌍둥이 부화 (twin-hatch)
- 본체: **N번째 출격마다 병아리 2기가 동시 출격**한다(상한·보류 규율 유지 — 자리 1칸이면
  1기만 나가고 카운터 유지).
- 레벨 스케일: N = 2 + round(18/(Lv+2)) (Lv1 = 8, Lv20 = 3, 점근 2 — 연속 체감).
- 1레벨: 가끔 쌍둥이. / 20몰빵: 3회에 1번 — 무리 밀도의 몰빵 축.
- 연계: 시그니처(직접 — 출격 지점 훅) · BD1(빈도) · SH10(자리 확보).
- 구현: B — 출격 횟수 카운터 WorldState 평평 정수 1개("0이면 무폴드" 조건부 꼬리 폴드).

### [BD3] 작별 격발 (farewell-volley)
- 본체: **병아리가 소멸하는 틱**(모든 소멸 경로 — ②말미 소멸 경로 표 참조)에 그 자리에서
  부채꼴 작별 사격을 남긴다.
- 레벨 스케일: 탄수 3 + floor(Lv/4) (4레벨 폭 계단), 탄당 피해 = 병아리 탄 피해의 60% + 2%p/Lv
  (Lv20 = 100%, 20 초과 계속 성장 — 특이점 없음).
- 1레벨: 죽음이 마침표가 된다. / 20몰빵: 세대 순환 빌드에서 소멸 자체가 화력 이벤트.
- 연계: 병아리 죽음(재료 축) · SH1·SH7(희생 소모가 격발 유발) · `fanStrike` 동형.
- 구현: A — 소멸 처리 지점에 `fanStrike`. 방향은 소멸 틱에 표적각 즉석 재계산(표적 없으면
  플레이어 조준각 폴백 — `resolveDirFallback` 규율).

### [BD4] 표적 공유 (target-share)
- 본체: 병아리가 **플레이어의 현재 자동 조준 표적을 우선 공격**하고, 플레이어 탄이 그
  표적에 명중한 틱부터 **30틱 창** 동안 병아리 탄의 같은 표적 명중이 증폭된다(증폭 적용
  시점 = 병아리 탄 명중 틱, 창 판정 = `state.tick − 기록틱 <= 30`).
- 레벨 스케일: 집중 증폭 +15% + 2%p/Lv (bp 정수). 창 30틱 고정.
- 1레벨: 무리 화력이 흩어지지 않는다. / 20몰빵: 단일 대상 용해 — 저피해 고연사의 보스전 답안.
- 연계: 자동 조준(1.6) · 엘리트·보스(7.2·7.3) · BD7 과 "집중 사냥" 축.
- 구현: B — WorldState 평평 정수 2개(표적 엔티티 id · 마지막 플레이어 명중 틱), "둘 다
  0이면 무폴드" 조건부 폴드. `stepTurrets` 의 `nearestTarget` 앞 우선 표적 조회 1회.

### [BD5] 격발 공명 (volley-resonance)
- 본체: **플레이어가 주무기 볼리를 발사하는 틱**에 살아 있는 병아리 전원의 발사 쿨다운이
  깎인다 — 모선의 연사가 무리의 연사를 끌고 간다.
- 레벨 스케일: 볼리당 −(1 + floor(Lv/5)) 틱 (5레벨 폭 계단). `Math.max(0, …)` 클램프 필수.
- 1레벨: 연사 파워업이 무리에 간접 전이. / 20몰빵: 연사 몰빵에서 병아리 실효 연사 배가.
- 연계: 발사 리듬(3.1 — 병아리 `cooldown` 은 정수 틱, 256 단위 함정 없음) · brood 트리 성향.
- 구현: A — 발사 코드에서 `BROOD_MARK` 순회 감산(신규 상태 0).

### [BD6] 부화 충격파 (hatch-shockwave)
- 본체: **출격 틱에 출격 지점에서 알이 깨지는 충격파** — 반경 폭발 피해 + 적탄 소거.
- 레벨 스케일: 반경 110 + 9×Lv, 피해 12 + 3×Lv.
- 1레벨: 부화가 방어 이벤트를 겸한다 — **단 발생지는 "출격 좌표"다**: 기본 배치(플레이어
  곁)에서는 자위 폭발이지만, NU7 원정 부화 투자 시 **원격 모이밭 폭격**으로 축이 바뀐다
  (NU7 항목의 출격 좌표 상호작용 절 참조 — 의도된 변주). / 20몰빵: 부화 빈도 빌드의
  주기적 광역 폭격.
- 연계: 시그니처(직접 — 출격 지점) · 적탄(7.8) — 무기 밖 요소 · NU7(발생지 이전).
- 구현: A — `blastDamage` + `clearEnemyBullets` 합성(출격 좌표 기준).

### [BD7] 노병 병아리 (veteran-chick)
- 본체: 병아리가 **발사를 거듭할수록 그 개체의 탄이 강해진다** — 오래 산 병아리가 노병.
- 레벨 스케일: 발사 1회당 +1.5% + 0.15%p/Lv, 개체당 상한 = round(20 + 60×Lv/(Lv+15))%
  (Lv20 ≈ 54%, 점근 80% — 연속 체감).
- 1레벨: 수명 후반 병아리가 매워진다. / 20몰빵: 수명 연장(NU6)·정예(BD10)와 "늙은 무리" 기둥.
- 연계: 병아리 수명(재료 축) · NU6 · BD10.
- 구현: A — 개체별 발사 횟수를 병아리 **`timer`** 에 기록(①절 확정 — `phase` 는 생사
  스위치라 절대 금지, 1R CRITICAL-1). 엔티티 필드 재활용(관용구 ②)·레이아웃 불변.

### [BD8] 브루드 강습 (brood-assault)
- 본체: brood 액티브(`as_hatchling_brood_lo/hi`) **발동 틱에 살아 있는 병아리 전원이
  쿨다운을 무시하고 즉시 1발 격발**한다.
- 레벨 스케일: 일제 사격 탄 피해 = 100% + 4%p/Lv.
- 1레벨: 액티브가 무리 지휘 신호가 된다. / 20몰빵: 액티브 = 무리 알파 스트라이크.
- 연계: 액티브 brood 2종(직접) · BD5 와 축 구분(상시 리듬 vs 발동 순간).
- 구현: A — **기존 발사 헬퍼는 없다**(1R MINOR): `stepTurrets` 내부의 표적 조회→`spawnBullet`
  블록(`world.ts:3125-3141`)을 함수로 추출해 핸들러와 공유한다. 추출은 동작 불변
  리팩터라 A 유지(0c 동결 대상 헬퍼 5종의 시그니처는 건드리지 않는다).

### [BD9] 과밀 본능 (overcrowd-instinct)
- 본체: **상한 만석으로 출격이 보류 중인 동안**(적립 임계 초과 + 자리 없음) 병아리 전원의
  발사 간격이 짧아진다 — 태어나지 못한 조바심이 무리를 몰아친다.
- 레벨 스케일: 보류 중 발사 간격 배율 bp = 5500 + 4500×10/(Lv+10) (Lv1 ≈ ×0.96, Lv20 =
  ×0.70, 점근 ×0.55 — **연속 체감, 0 교차 없음**. 1R 의 선형식 0.85−0.01Lv 폐기).
- 1레벨: 만석 유지가 소소한 보너스. / 20몰빵: "만석 + 적립 초과" 유지가 목표가 되는 역발상
  — BD1 과 긴장(빨리 낳을수록 보류 창이 길다). **영구 ON 아님**: 보류 상태는 병아리가
  하나라도 죽으면 즉시 해소(출격)되므로 자연 순환한다 — NU10 신판(이월)과도 충돌 없음
  (이월은 출격 후 잔여 적립일 뿐, 보류 술어를 바꾸지 않는다).
- 연계: 시그니처(직접 — 보류 규율 `world.ts:2251-2253` 을 상태로 읽는다) · SH3 과 조건
  공유·산출 상이.
- 구현: A — 술어 파생(신규 상태 0).

### [BD10] 여왕 사출 (matriarch-launch)
- 본체: **동시 상한이 1 줄어들고, 강화 배율이 "기본 상한 4 대비 실효 상한의 결손"에
  비례**한다 — 결손 1기당 출격 병아리의 탄 피해·수명이 오른다. **실효 상한 = 4 −
  BD10투자유무 + SH10투자유무 (하한 1)** 이 정본 합산식이고, 강화는 `결손 = max(0, 4 −

## ④ 침공(PvP) 판정 표 (1R 재판정 — 제2 기준 + 스크롤 앵커)

판정 기준(헌장 정본, 2기준):
- **기준 1**: PvE 에서 작동하던 억제(대가·제약)가 침공 환경에서 소실되어 순이득만 남는가.
- **기준 2(신설)**: PvE 에 없던 순이득이 침공에서 새로 생기거나, 효과의 부호가 반전되는가.

**스크롤 앵커 전제(1R 신설)**: 활성 포탑(병아리)은 **ANCHOR**(`scrollMode.ts:118-120`)이고
침공 3레이어는 전부 강제 스크롤이다 — **침공에서 병아리는 창과 함께 이동하며 뒤에 남지
않는다.** PvE 비스크롤 무대의 "병아리를 두고 오는" 위치 관리 억제는 침공에서 구조적으로
소실되나, 이는 **시그니처 자체의 기존 침공 거동**(스킬이 만든 것이 아님)이므로 시그니처는
게이트하지 않고, 그 소실 위에 추가 순이득을 얹는 스킬만 개별 재판정한다.

**시그니처(소환) — 공격측/방어측**:
- **공격측**: 처치 적립은 편대 적 처치로 그대로(억제 불변) — **허용**. 병아리 사격은
  `nearestTarget`/`isPlayerTargetable` 규칙 그대로(플레이어 탄과 동일 — 무적 코어 차폐
  선례 경로, 별도 우대 없음).
