## ② 스킬 30종

표기: 구현 태그 **A(재사용) / B(신규 상태) / C(신규 시스템)**. 레벨 스케일은 20 초과 자연
연장 — 선형 또는 연속 체감 곡선 `base + k×Lv/(Lv+c)`(단조·점근 상한·clamp 없음)만.
정수 계단(`floor`/`ceil`/`round`)은 전부 양적 반올림이며 정직 표기(헌장 규율).
곡선의 나눗셈은 `createWorld` 가 투자 레벨당 1회 정수 확정해 config 파생값으로 싣는다
(catalystMods 선례 — 스트라이커 문서와 동일 규약).

**축 ID 규약**: blade/morph/fortify 의 이니셜 b/m/f 대신 충돌 없는 **BL/MO/FO** 를 쓴다.

**B 태그 저장처 공통 확인(재발 주의 패턴)**: 본 카탈로그의 B 스킬 6종은 전부 **`WorldState`
평평 정수 신설**(관용구 ①, "전부 0이면 무폴드" 조건부 꼬리 폴드)이다 — 신설이므로 점유
충돌이 원리적으로 없다. **기존 Entity 필드 재활용 주장은 0건**(적 `timer`·`aux` 등 포화
필드를 일절 쓰지 않는다). 브루저 `aux0/aux1` 은 자기 소유(위 ① 실측)라 추가 확인 불요.

**접촉 피격 판별 공통 규약(BL8·FO3, CRIT-3 반영)**: "접촉 처리 분기"라는 별도 코드는
**존재하지 않는다** — `world.ts:3739-3757` 은 적탄·적·보스·해저드 등 모든 피해원을 한
루프에서 돌며 **최댓값(max) 하나만** 수집한다. 따라서 접촉 트리거 스킬은 이 수집 루프에서
①접촉원(enemy kind) 기여 여부 플래그와 ②그 접촉 적 인덱스, ③**접촉원이 기여한 피해분**
(max 채택 여부와 별개로 보존)을 지역 변수로 남기고, 루프 종료 후 피해 적용 블록에서 그
지역 변수로 판정·정산한다. max 가 다른 피해원(적탄 등)일 수 있으므로 **트리거·기준값은
항상 접촉원 기여분**이지 그 틱의 최종 피해가 아니다. 지역 변수뿐이라 신규 상태 0 — A 유지.

### 칼날 (blade) — BL1..BL10

### [BL1] 응전 사출 (retort-volley)
- 본체: **실제로 HP 가 깎인 피격 틱**에 조준 방향으로 반격 볼리 1회를 자동 발사한다(쿨다운 미소비, 내부 쿨 60틱).
- 레벨 스케일: 반격 볼리 피해 = 50% + 2%p/Lv.
- 1레벨 가치: 맞는 게 일상인 기체에서 피격이 곧 사격이 된다. / 20레벨 몰빵 가치: 난전 피격 빈도 × 90% 볼리 — 탱킹이 화력이 되는 주포.
- 연계: 시그니처(직접 — 피격이 자원이라는 정체성의 화력 표현) · 피격 후속 블록(2.8 — 막·무효화된 피격은 미발동이 일관 규칙).
- 구현: A — 2.8 블록에서 발사 헬퍼 1회. 내부 쿨은 `aux1`(피격 시 0 리셋) < 60 판정으로 대체 가능해 신규 상태 0.

### [BL2] 백병 격발 (point-blank-doctrine)
- 본체: **자동 조준 표적과의 거리가 근접 임계(350u) 이내**일 때 발사되는 볼리는 관통 +1 을 얻고 피해가 증폭된다 — 붙을수록 강해진다.
- 레벨 스케일: 근접 볼리 피해 +8% + 1.5%p/Lv. 임계 350 고정.
- 1레벨: 관통 +1 이 즉시 온전(임계 밖은 무보정일 뿐 페널티 없음). / 20몰빵: 근접 유지가 곧 화력 — 이 기체의 존재 이유를 스킬로 못박는다.
- 연계: 자동 조준(1.6 `nearestTarget`) · 시그니처(근접 = 피격 리스크 = 장갑 적립의 선순환) · FO3·MO6 과 "붙어서 싸우는" 아키타입.
- 구현: A — 발사 시점 1회 거리 술어(스트라이커 F5 의 각도 술어와 동형, 발사 시점 한정 규율 승계).

### [BL3] 만재 중탄 (full-plate-slug)
- 본체: **장갑 스택이 만재(상한)일 때** 발사되는 탄은 「중탄」이 되어 명중 지점에 소형 폭발을 남긴다.
- 레벨 스케일: 폭발 반경 50 + 5×Lv, 폭발 피해 = 탄 피해의 25% + 1.5%p/Lv.
- 1레벨: 만재 유지에 광역이라는 보상이 붙는다. / 20몰빵: 만재 상태의 볼리 전체가 유탄 — FO1(상한 확장)·FO9(빈사 적립 강화)와 만재 유지 빌드의 주력 딜.
- 연계: 시그니처(직접 — 만재 술어 `aux0 >= 상한`) · fortify 액티브(만재 고정)가 이 스킬의 가동률을 끌어올린다.
- 구현: A — 발사 시점 만재 술어 + 명중 처리에서 `blastDamage`. 만재 판정은 FO1 의 확장 상한을 따른다(고정 8 하드코딩 금지).

### [BL4] 과적 배출 (overflow-vent)
- 본체: **만재 상태에서 실피격**당하면(적립할 곳이 없는 잉여 스택이) 전방 파편 부채꼴로 배출된다 — 넘치는 장갑이 무기가 된다.
- 레벨 스케일: 파편 수 = 4 + ceil(Lv/3)(3레벨 폭 정수 계단, 양적 반올림), 파편 피해 8 + 2×Lv.
- 1레벨: 만재 중 피격이 공짜가 아니게 된다. / 20몰빵: 만재 탱킹 = 지속 산탄 — BL3 과 함께 "만재가 화력" 축의 쌍.
- 연계: 시그니처(직접 — 만재+피격 이중 술어) · 피격 후속 블록(2.8) · BL3(만재 축 공유, 트리거는 발사 vs 피격으로 상이).
- 구현: A — 2.8 블록에서 만재 술어 + `fanStrike`.

### [BL5] 충각 절단 (ram-cleave)
- 본체: 기동 액티브(blink 돌진) **이동 경로상의 적**이 절단 피해를 받는다 — 돌진이 참격이 된다.
- 레벨 스케일: 경로 피해 30 + 6×Lv, 경로 폭(반경) 60 고정.
- 1레벨: 돌진이 "이탈"에서 "돌파 공격"이 된다. / 20몰빵: MO10·morph_hi(900u 돌진)와 함께 화면을 가로지르는 참격.
- 연계: 액티브 `as_bruiser_morph_lo/hi`(직접) · 선분 판정 선례(point-blank swept collision — 출발→도착 선분 vs 적 원).
- 구현: A — 핸들러에서 `blink` 전후 좌표로 선분 피해 1회(swept 판정 기존 틀 재사용). 대상은 enemy·boss(blastDamage 동일 범위).

### [BL6] 중량 탄자 (mass-slug)
- 본체: **탄이 무거워진다** — 탄속이 절반이 되는 대신 명중한 적을 좌표 직접 변위로 밀어내고 피해가 강화된다(보스·엘리트 변위 반감).
- 레벨 스케일: 피해 +20% + 2%p/Lv, 변위 16 + 2×Lv. 탄속 ×0.5 고정.
- 1레벨: 트레이드 즉시 온전 — 근접 기체라 탄속 손실이 작다(붙어 쏘면 비행시간이 짧다). / 20몰빵: 볼리 자체가 넉백 파도 — 접근 거부와 단일피해를 동시에.
- 연계: 넉백 규율(7.1 — 속도 대입이 아니라 좌표 변위) · BL2(근접일수록 탄속 페널티가 무의미해지는 설계 결합) · baseBp(느린 기체가 느린 탄을 쓰는 정합).
- 구현: A — 발사 시점 탄속 배율 + 명중 처리 1회 변위(filmBurstPush 동형). 사거리 계약(3.1 `weaponReach`=`reachLife` 동일값) 준수 — 탄속만 줄이고 수명 보정으로 도달 거리 불변.

### [BL7] 파성퇴 (wall-breaker)
- 본체: 볼리가 **파괴가능 벽(`hp>0`)·destructible 을 일격 파괴**하고, 파괴 틱에 그 자리에서 전방 충격파가 나간다.
- 레벨 스케일: 충격파 피해 20 + 4×Lv, 충격파 반경 100 + 8×Lv. (일격 파괴는 1레벨 해금 자체의 질 — 레벨 성장은 충격파만.)
- 1레벨: blockBreak 행성·엄폐 지형에서 동선이 뚫린다 — 1레벨 유틸. / 20몰빵: 지형 파괴가 광역 딜을 겸한다.
- 연계: 벽·destructible(8.2·8.3) — 무기 밖 요소 · destructible 젬 드랍과 MO7 의 경제 축.
- 구현: A — 탄 vs 벽 명중 분기에서 `hp>0` 이면 즉사 처리 + `blastDamage`. 목표 판정은 `modes/objective.ts` 단일 지점 규율 존중(파괴 집계는 기존 경로 그대로).
- 침공: **허용**(제2 기준 재판정 — ④ 표 참조, 게이트 아님·밸런스 각주).

### [BL8] 격돌 담금질 (impact-temper)
- 본체: **몸통 접촉으로 실피격**당할 때마다 「담금질 탄」이 1발 적립되고, 이후 발사되는 볼리의 선두탄이 적립분을 소모해 대구경화(피해 증폭 + 관통 +1)된다.
- 레벨 스케일: 적립 상한 = round(1 + 5×Lv/(Lv+10)) (Lv1 = 1, Lv20 ≈ 4, 점근 6 — 연속 체감), 대구경탄 피해 +60% + 3%p/Lv.
- 1레벨: 접촉 피격 1회 = 강화탄 1발 — 몸으로 부딪히는 플레이에 보상. / 20몰빵: 접촉 탱킹이 강화탄 탄창이 된다.
- 연계: 시그니처(직접 — 같은 피격 자원을 스택이 아니라 **탄약**으로 환산하는 두 번째 축) · 접촉 피격 판별 공통 규약(② 상단 — CRIT-3 반영) · BL1(트리거는 같은 피격이되 산출이 즉발 볼리 vs 적립 탄약으로 상이).
- 구현: B — WorldState 평평 정수 1개(적립 카운터, 신설 — 점유 충돌 없음) + "0이면 무폴드" 조건부 꼬리 폴드. 접촉 판별은 공통 규약의 지역 변수 플래그(그 틱 실피격이 성립했고 접촉원 기여가 있을 때만 적립 — max 가 적탄이어도 접촉 기여가 있으면 적립, 기준은 트리거뿐이라 이중 정산 없음). **접촉원 kind 는 enemy·boss·guardian·defenseBoss 전부 포함**(택일 확정, R-4 — 여기서 접촉원은 **트리거일 뿐** 대상 지정이 없어 어떤 kind 여도 무해하다. FO3 반사는 접촉원에게 **피해를 되돌리는** 스킬이라 enemy kind 한정인 것과 기준이 갈린다).

### [BL9] 중압 리듬 (crush-cadence)
- 본체: **N번째 명중마다 확정 강타**(피해 2배)가 터지고, **N 은 장갑 스택이 많을수록 짧아진다** — 무확률 결정론 크리의 브루저 변형.
- 레벨 스케일: **N = max(1, round(48/(4+스택)))** — 스택 0 = 12, 만재 8 = 4. **FO1 의 확장은 점근 상한 +4 라 스택 ≤ 12, 그 범위에서 N ≥ 3** 이고, 곡선 자체는 스택 93 이상에서 round 가 0 이 되므로 **`max(1, …)` 하한을 배선에 포함**한다(장래의 다른 상한 확장까지 `% 0` 을 원천 차단 — R-2 로 "곡선이라 어떤 확장에도 N ≥ 1" 오서술 정정. 1판 `12 − 스택` 은 CRIT-2 로 교체됨). round·max 는 양적 계단(정직 표기). 강타 피해 = +80% + 4%p/Lv.
- 1레벨: 만재 탱킹 중 4타마다 강타 — 즉시 체감. / 20몰빵: 근접 최고 단일피해 정체성의 정점 — 엘리트·보스 용해.

- 구현: B — WorldState 평평 정수 1개(명중 카운터, 신설) + 조건부 꼬리 폴드. N 은 명중 틱마다 현재 스택으로 재계산(정수 나눗셈 1회). RNG 0 소비(공통-B 무접촉).

### [FO2] 응혈 장갑 (clot-plating)
- 본체: 실피격으로 **잃은 HP 의 일부가 「응혈 풀」에 적립**되고, **장갑이 만재에 도달하는 상승 엣지 틱**에 풀 전액이 회복으로 정산된다 — 맞아서 잃은 피를 만재가 돌려준다.
