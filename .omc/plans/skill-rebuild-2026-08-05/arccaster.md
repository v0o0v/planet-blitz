## ① 시그니처 확인 — 과충전 (기존 유지, 신규 부여 없음)

**규칙(현행 그대로)**: 입력 기반 정지(`moveX===0 && moveY===0 && !dash`, `world.ts:2069`)가
연속되면 `aux0` 이 틱마다 +1. **단 `aux0 < OVERCHARGE_TICK_CAP`(600) 가드가 있어 600 에서
증가가 멈추고 고정된다**(`world.ts:2071` — 2판에서 전 스킬의 주기·에지 판정이 이 사실을
전제로 재설계됐다). 90틱(`OVERCHARGE_STILL_TICKS`)에서 과충전 진입(+1500bp), 틱당 +25bp,
**190틱에서 상한 4000bp**(`shipSignature.ts:98-118`). 이동 입력 즉시 `aux0 = 0`. 증폭은
주무기 발사 시점 1곳에만 적용(`world.ts:2573-2574`).

- **grep 확인 완료 좌표**(`src/sim/**` 전수):
  - 판정·적립: `world.ts:2066-2075` (**입력 기반이 계약** — 속도는 감속 장판·모듈 배율로 오염).
  - 적용: `world.ts:2573`(발사 피해) · `world.ts:4046,4061`(`overchargeKills` 사연 카운터, 비해시).
  - 인코딩: `aux0` = 연속 정지 틱(0..600) · **`aux1` = 미사용(0) — 이 설계도 건드리지 않는다**
    (액티브 6종 헤더 계약). 스킬 상태는 전부 WorldState 평평 정수로 간다(관용구 ①).
  - 액티브 6종은 전부 `aux0` 을 사고판다: chain_lo(90 주입) · chain_hi(방전=탄수 전환 후 0) ·
    barrage_lo(blink 후 하한 90 보존) · barrage_hi(blink 후 190 세팅) · barrier_lo(매 틱 +2) ·
    barrier_hi(매 틱 190 고정) — `src/sim/activeHandlers/arccaster.ts`.
- **시그니처 변경 없음 → uniqueMask·골든 영향 없음.** 마이그레이션은 ⑥ 참조.

### 이 문서의 핵심 문법 (스킬들이 공유하는 술어)

- **정지 중**: `aux0 > 0` (입력 기반 적립의 파생).
- **과충전 중**: `overchargeBp(aux0) > 0` (= `aux0 ≥ 90`).
- **진입 통과**: "이전 틱 aux0 < 90 **&&** 현재 틱 aux0 ≥ 90" — `===` 에지가 아니라 **통과
  판정**이다. BR7 피해 전환·BA8 배속·barrier_lo SUSTAIN(+2/틱)처럼 폭 2 이상으로 가산되는
  경로가 90 을 건너뛰어도 발화한다(1R 심각 6 — 팬텀 배치도 같은 `===` 결함으로 반려됐다.
  이 문서의 에지류 판정은 전부 통과형).
- **주기 판정**: `state.tick % 주기 === 0` + 상태 술어 — **`aux0 % 주기` 금지.** aux0 은 600
  에서 고정되므로 aux0 기반 주기는 만충 빌드에서 영구 침묵한다(1R 심각 1). tick 기반이면
  BR7 가산·BA9 감쇠가 aux0 위상을 흔들어도 주기가 교란되지 않는다.
- **전격 연쇄 부여는 정확히 3종**: CH1(상시축 — 과충전 탄 명중) · BR2(피격축 — 반격) ·
  CH10(액티브축 — strike 투사체). 그 외 스킬은 연쇄를 부여하지 않는다(1R 심각 2 —
  스트라이커 1R FAIL 패턴 재발 방지). CH2 는 부여가 아니라 연쇄 규칙 자체의 변형(허브).

## ② 스킬 30종

표기: 구현 태그 **A(재사용) / B(신규 상태) / C(신규 시스템)**. 레벨 스케일은 20 초과 자연
연장 — 선형 또는 연속 체감 곡선 `base + k×Lv/(Lv+c)` 만. 정수 계단은 양적 반올림으로 정직
표기. 체감 곡선의 나눗셈은 `createWorld` 가 투자 레벨당 1회 정수 확정해 config 파생값으로
싣는다(인벤토리 11.1 선례).

### 연쇄 (chain / offense) — CH1..CH10

### [CH1] 유도 낙뢰 (guided-arc)
- 본체: **과충전 중 발사한 탄이 명중하면 전격 연쇄(`applyChain`)가 터진다** — 정지 포격이 단일 대상에서 광역으로 번진다. (연쇄 부여 3종 중 상시축.)
- 레벨 스케일: 연쇄 피해 = 탄 피해의 20% + 2%p/Lv (bp 정수).
- 1레벨 가치: 과충전만 유지하면 모든 명중이 소형 광역. / 20레벨 몰빵 가치: 연쇄가 주력 딜 — 정지 유지가 곧 화력 밀도.
- 연계: 시그니처(직접 — 발사 시점 과충전 술어로 탄에 표식, CH8 과 같은 발사 시점 1회 규칙) · 원소 전격(3.3 leaf, 엔티티 배열 순서 결정론).
- 구현: A — 명중 처리에서 `applyChain` 호출(부여 지점 `world.ts:3599-3604` 단일 정본에 합류).

### [CH2] 연쇄 확장 회로 (relay-circuit)
- 본체: **모든 출처의 전격 연쇄**(CH1·BR2·CH10·장비 전격 어픽스)의 도약 반경과 도약 대상 수가 늘어난다 — 연쇄라는 규칙 자체를 굵게 만든다.
- 레벨 스케일: 반경 = `CHAIN_RADIUS`(260) + 12×Lv, 대상 = 3 + floor(Lv/7) (Lv20 = 5, Lv28 = 7 — 7레벨 폭 정수 계단, 20 초과 자연 연장).
- 1레벨: 즉시 반경 +12. / 20몰빵: 반경 500·5도약 — 화면 절반이 한 번개에 이어진다.
- 연계: 원소 전격 · CH1·BR2·CH10 허브. **장비 전격 어픽스 곱연산 판정(1R 권고)**: `applyChain` 의 유일 호출부(`world.ts:3603`)를 지나는 어픽스 연쇄도 함께 굵어진다 — 어픽스는 불리언 게이트(3.3 냉기와 동형)라 "어픽스 × CH2" 는 곱이 아니라 게이트+변형 관계이고, 어픽스로 스킬 레벨이 20 을 넘어도 반경은 선형·대상 수는 7레벨 계단이라 폭주 없음(Lv40 = 반경 740·대상 8).
- 구현: A — `applyChain`(`status.ts`) 반경·대상 수 파라미터화(0c 동결 목록(액티브 공용 헬퍼 5종) 밖 leaf, 기본값 호출은 비트 동일).

### [CH3] 종말점 방전 (endpoint-burst)
- 본체: **과충전 중 발사한 탄이 사거리를 다해 소멸**(reachLife 만료)하면 그 지점에서 방전 폭발을 남긴다 — 최장 사거리 기체의 빗나간 탄도 일한다. 과충전 게이트가 스트라이커 F4(관통 소진 폭발)와의 분화점(소멸 사유·시그니처 결속 모두 다름).
- 레벨 스케일: 폭발 반경 50 + 5×Lv, 폭발 피해 = **발사 확정 피해**의 25% + 2%p/Lv (아래 기준 정의 참조).
- 1레벨: 장거리 견제가 지역 거부를 겸한다. / 20몰빵: 사거리 끝이 상시 포격 지대 — rangeFlat 노드와 곱연산.
- 연계: 시그니처(직접 — 발사 시점 표식, CH1 과 공유) · 사거리 계약(3.1 — `weaponReach`·`reachLife` 동일 값 계약이 "만료 지점 = 사거리 끝"을 보장).
- 구현: A — **`blastDamage` 는 플레이어 중심 고정**(`activeTypes.ts:137-151`, 1R 심각 4)이라 재사용 불가. 신규 leaf `blastDamageAt(state, x, y, r, dmg)` 를 추가하고 기존 `blastDamage` 가 위임하게 한다 — 동결 5종의 시그니처는 불변, 신규 상태 0 이라 태그 A 유지. 수명 만료 소멸 분기 한정(관통 소진 소멸과 별개 분기 — 이중 발화 없음).
- **폭발 피해 기준 정의(3R MAJOR 수정)**: 3판의 "`state.weapon.damage` 원본 고정"은 **과교정이었다** — 과충전 증폭은 발사 시점에 `wDamage` 로 확정돼 탄에 실리므로(`world.ts:2573-2574`), `state.weapon` 을 읽으면 **과충전 증폭·CH5·파워업 배율이 전부 누락**되어 과충전 게이트 스킬인 CH3 만 과충전을 못 받는 자기모순이 된다. 확정 기준은 **"발사 시점에 확정된 `wDamage`"** — 표식을 불리언이 아니라 **그 시점의 `ocBp`(또는 확정 `wDamage`) 정수로 저장**해, CH3 이 "CH6 이월 미반영 + 발사 시점 증폭 반영" 값을 읽게 한다. 이월(CH6)은 비행 중 `b.damage` 가산이라 자연 배제된다. **표식 칸 배정은 구현 레인 확인 항목 ①에 합류**(CH10 `aux0`·CH8 `aux1` 과 경합 — 세 표식이 같은 탄에 공존 가능하므로 칸 3개 확보 또는 비트 패킹 판단 필요).

### [CH4] 진입 뇌격 (entry-lance)
- 본체: **과충전 진입 통과 틱**(이전 틱 < 90 && 현재 ≥ 90)에 조준각(`player.angle`)으로 고관통 방전 1발을 자동 사출한다 — "자리를 잡았다"는 선언사격.
- 레벨 스케일: 피해 30 + 6×Lv, 관통 3 + floor(Lv/5) (5레벨 폭 정수 계단).
- 1레벨: 정지 리듬마다 공짜 저격 1발. / 20몰빵: 진입을 반복하는 빌드(BA9·chain_lo)의 주포.
- 연계: 시그니처(직접 — 진입 통과) · 액티브 chain_lo/barrage_lo 의 90 주입·하한 고정도 통과를 만들면 발화(이미 90 이상이면 미발화가 일관 규칙) · 조준(1.6).
- 구현: B — 통과 판정의 비교 기준은 **"직전 틱 말 aux0 스냅샷"** 이다(2R 권고 4 확정). 지역 변수 한정 비교로는 안 된다 — 피격 후속 블록(BR7 전환)·액티브 핸들러(chain_lo 90 주입·barrage_lo 하한 고정)가 `stepShipSignature` **밖**에서 aux0 을 올리므로, 함수 지역 스냅샷은 그 주입 통과를 다음 틱에 유실한다. 저장처 = **WorldState 평평 정수 1개**. **발화 순서 못박기(3R MINOR)**: 틱 안의 모든 aux0 갱신 경로(`stepShipSignature` 적립·BA8 배속·BA9 감쇠·BR7 전환·액티브 핸들러 주입·SUSTAIN)가 끝난 **단일 지점에서 ①`스냅샷 < 90 && 현재 aux0 ≥ 90` 비교 후 발화 → ②그 자리에서 스냅샷 = 현재 aux0 갱신** 순으로 한 번에 처리한다(두 지점으로 쪼개지 않는다 — 쪼개면 그 사이 경로가 늘 때 조용히 유실된다). 미투자 런은 기록하지 않아 0 유지 = 무폴드(관용구 ①). 1R 심각 6(=== 에지) 수정 유지 — 폭 2 이상 가산·틱 중간 주입 모두 통과로 잡힌다.

### [CH5] 전위차 저격 (potential-snipe)
- 본체: **800u 이상 비행한 뒤 명중한 탄**은 피해가 증폭되고 관통 +1 을 얻는다 — 거리가 곧 전압.
- 레벨 스케일: 증폭 +15% + 1.5%p/Lv.
- 1레벨: 멀리서 쏘는 습관에 즉시 보상. / 20몰빵: 사거리 노드·CH3 과 "최대 이격" 포지셔닝의 기둥.
- 연계: 사거리·탄속 정체성 · BR1 척력(적을 밀어 이격 생성)과 합.
- 구현: A — 명중 시 `(발사 수명 − 잔여 수명) × bulletSpeed ≥ 800` 파생 술어(reachLife 계약 덕에 수명↔거리 동형, 탄 신규 필드 0).

### [CH6] 과잉 전하 이월 (overkill-carry)
- 본체: **탄이 적을 처치하고 남은 초과 피해가 탄에 다시 실려**, 잔여 관통으로 맞는 다음 대상에게 전달된다 — 과충전 고피해가 한 줄에서 낭비되지 않는다. (1R 재설계 — 구 "연쇄 종점 폭발" 폐기, 연쇄 부여 3종 한정.)
- 레벨 스케일: 이월 비율 = 40% + 3%p/Lv.
- 1레벨: 관통 라인 사격의 오버킬이 절반쯤 회수된다. / 20몰빵: 이월 100% — 정렬된 적 열을 전압이 순서대로 태우는 처형 라인.
- 연계: 시그니처(과충전 증폭이 클수록 이월분이 굵다 — 간접) · 관통(3.1) · CH8·BR1(정렬)과 3점 시너지 · F4형 폭발이 아니라 **탄 내부 가산**이라 광역 축과 분리.
- 구현: A — 처치 판정 시 `b.damage += round(초과 × bp / 10000)` (이미 해시되는 탄 필드의 값 갱신 — 신규 상태 0). 탄 소멸 시 자연 소실. **재증폭 택일 확정(2R 권고 3)**: 별도 가산항 분리는 탄 신규 필드가 필요해 배제하고, ①**CH5·CH8 배율이 이월 가산분에도 실리는 것은 의도로 수용**한다 — 라인을 따라 단조 증가하되 각 대상 잔여 HP 와 이월 상한 100% 가 유계를 만든다(무한 폭주 없음). ②**CH3 종말점 폭발의 비율 산정만 "발사 시점 확정 피해(`wDamage`)" 기준으로 고정** — 비행 중 갱신되는 `b.damage` 가 아니라 탄에 저장된 발사 시점 값을 읽어 이월 재증폭만 차단하고 과충전 증폭·CH5·파워업 배율은 그대로 반영한다(3R MAJOR — 3판의 `state.weapon` 원본 기준은 증폭까지 잘라내는 과교정이었다. ### [CH7] 잔류 방전 (residual-discharge)

### [BA8] 절연 포좌 (insulated-mount)
- 본체: **감속 장판 위에서 정지하면 aux0 적립이 2배**(틱당 +2)가 되고 용암 피해가 경감된다 — 남들이 피하는 자리가 최적 포좌. (스트라이커 S5 와 같은 해저드 훅이지만 결속 변형이 다르다: S5 는 감속의 부호 역전, 이것은 **시그니처 적립 배속** — 감속 자체는 그대로 받는다.)
- 레벨 스케일: 용암 경감 30% + 1.5%p/Lv (적립 2배 고정 — 기존 적립의 배속, 질적 변화 아님).
- 1레벨: 해저드 지형이 충전소로 읽히기 시작한다. / 20몰빵: 해저드 밀집 행성에서 급속 충전 포지셔닝.
- 연계: 해저드(8.4 `hazardActive`) — **무기 밖 요소** · 시그니처(직접 — 적립 속도).
- 구현: A — `stepShipSignature` 분기에서 장판 술어 시 `aux0 += 2`(기존 600 클램프 유지). CH4 통과 판정이 폭 2 가산을 삼키지 않음(핵심 문법).
- 침공: ④ 표 참조(**제2 기준 게이트**).

### [BA9] 이동 포격 술식 (march-fire)
- 본체: **이동해도 aux0 이 0 으로 리셋되지 않고 틱당 k 씩 감쇠**한다 — "이동 = 전소"라는 시그니처 기본 규칙을 "이동 = 누출"로 완화한다.
- 레벨 스케일: 이동 틱당 감쇠 k = ceil(24/(Lv+3)) (Lv1 = 6, Lv20 ≈ 2, Lv45 = 1 — 연속 체감의 정수 계단. 0 에는 영영 안 닿아 "이동 무손실" 질적 정지점 없음).
- 1레벨: 짧은 위치 조정이 충전 전량을 태우지 않는다. / 20몰빵: 미끄러지듯 재배치하는 유격 포병 — 이 기체 판타지("이동 중 과충전")의 패시브 판.
- 연계: 시그니처(직접 — 리셋 규칙 그 자체) · barrage_lo(순간 보존)와 역할 분담(상시 감쇠).
- 구현: A — `world.ts:2070` 의 `aux0 = 0` 을 투자 시 `aux0 = max(0, aux0 − k)` 로 분기(미투자 런은 기존 줄 그대로 — 바이트 불변). 주기류가 전부 tick 기반이라 감쇠의 위상 교란 없음(핵심 문법).

### [BA10] 일제 사격 통제 (salvo-doctrine)
- 본체: **발사 간격과 볼리 탄수가 함께 2배** — 같은 DPS 를 "굵고 느린 일제사"로 재포장하는 리듬 교환(순이득 아님).
- 레벨 스케일: 탄수 ×2 고정, 간격 배율 = 2 − 0.6×Lv/(Lv+10) (Lv1 ≈ ×1.95, Lv20 = ×1.6, 점근 ×1.4 — 1.0 밑으로 영영 안 내려가 순이득 전환점 없음).
- 1레벨: 근등가 교환 — 발당 부가 효과(CH1·CH8·CH3·관통) 빌드에서만 이득. / 20몰빵: 간격 페널티가 줄어 일제사 자체가 강해진다.
- 연계: 발사 간격(3.1 fireCooldownQ — Q 정수 반올림 1회)·탄수 · BA7.
- 구현: A — 읽는 시점 배율 2곳(bulletCount·fireCooldownQ). **무기별 의미 명시(1R 권고)**: 발칸/스프레드 = 부채꼴 2배 · 미사일 = 유도탄 2배 · **레일건 = 같은 표적 방향 2연발** · **빔 = 적용 제외(no-op)** — 빔은 탄수가 아니라 사거리·재도포로 정의된 정적 세그먼트(3.1 코드 4)라 "볼리 탄수" 축이 존재하지 않는다(오프빌드 no-op, 파워업 필터 계약(6장)과 같은 사상).

### 방벽 (barrier / defense) — BR1..BR10

### [BR1] 정전 척력장 (static-repulsor)
- 본체: **과충전 중 45틱마다 척력 펄스** — 반경 내 적을 좌표 직접 변위로 밀어낸다. 포대에 걸어서 접근할 수 없다.
- 레벨 스케일: 변위 20 + 3×Lv, 반경 140 + 8×Lv (주기 45틱 고정).
- 1레벨: 저HP·저이속 기체의 근접 압박이 구조적으로 완화. / 20몰빵: 접근 거부 요새 — CH5(이격 보상)·CH6/CH8(정렬 관통)과 기하 시너지.
- 연계: 시그니처(직접 — 과충전 술어) · 넉백 규율(7.1 — 속도 대입 금지·좌표 직접 변위, `filmBurstPush` 선례).
- 구현: A — 주기는 **`state.tick % 45 === 0` + 과충전 술어**(1R 심각 1 수정 — `aux0 % 45` 는 600 고정에서 영구 침묵·BR7/BA9 위상 교란도 회피). 대상 `kind === 'enemy'` 한정. **위상 특성(2R MINOR)**: tick 전역 위상이라 과충전 진입 직후 첫 펄스까지 최대 44틱 공백이 있을 수 있다 — 결함이 아니라 tick 기반 주기의 특성으로 수용(진입 즉시 보상은 CH4 의 몫).

### [BR2] 피뢰 접지 (lightning-rod)
- 본체: **HP 가 실제로 깎인 피격 틱**에 주변으로 전격 연쇄 반격이 터진다 — 나를 때린 전류가 되돌아간다. (연쇄 부여 3종 중 피격축.)
- 레벨 스케일: 반격 연쇄 피해 15 + 4×Lv.
- 1레벨: 피격 1회가 반격 1회 — 전 빌드 1레벨 유틸. / 20몰빵: 낮음(의도 — 피격 의존).
- 연계: 피격 후속 블록(2.8 — 흡수·무효화된 피격 미발동 일관 규칙) · CH2 허브.
- 구현: A — 2.8 블록에 `applyChain` 1줄.

### [BR3] 위상 결합 방벽 (phase-coupling)
- 본체: **barrier 액티브(buff) 지속 중 받는 피해가 감소**한다 — 버프 창이 "무너지지 않는 포격 창"이 된다.
- 레벨 스케일: 감소 15% + 1%p/Lv (bp).
- 1레벨: barrier_lo 180틱이 안정 포격 창. / 20몰빵: barrier_hi 300틱 고정 과충전 + 고감쇠 — 정면 버티기의 축.
- 연계: 액티브 barrier_lo/hi(직접 — `activeBuff` 잔여 틱 술어) · 감쇠 사슬(2.6).
- 구현: A — 감쇠 사슬의 **스킬 슬롯**(striker S4/S8 신설 위치 공유 — ⑥-4 참조)에 합류. 기체 내 순서 "감소(BR3·BR5) → 흡수(BR4)" 고정.

### [BR4] 잉여 전하 방벽 (surplus-shield)
- 본체: **과충전 상한 초과 구간(aux0 190..600)의 정지 틱** — 피해 증폭으로는 낭비되는 꼭대기 충전 — 이 매 틱 피해 흡수량으로 적립되고, 피격 시 흡수가 HP 보다 먼저 소모된다.
- 레벨 스케일: 초과 1틱당 적립 1, 흡수 총량 상한 = 20 + 4×Lv.
- 1레벨: 오래 버틴 포대에 얇은 보험. / 20몰빵: 상한 100 — 장기 정지가 곧 방어력인 "만충 요새". (aux0 이 600 에 고정돼도 "≥190 인 매 틱" 술어라 적립은 계속된다 — 600 고정의 수혜 스킬.)
- 연계: 시그니처(직접 — 상한 4000bp 이후 구간이라는 시그니처 곡선의 사각을 메운다) · CH7 과 만충 사용처 경쟁 · 감쇠 사슬 스킬 슬롯(흡수 위치).
- 구현: B — WorldState 평평 정수 1개(적립 흡수량) + "0이면 무폴드" 조건부 꼬리 폴드. `aux0 ≥ OVERCHARGE_APEX_TICKS`(190 유도 상수, `activeHandlers/arccaster.ts:41`) 술어.

### [BR5] 접지 케이블 (ground-tether)
- 본체: **벽에 접촉한 채(직전 틱 벽 슬라이드 발생) 정지 중이면** 받는 피해가 감소한다 — 구조물에 몸을 잇대는 포대. (스트라이커 S4 와 같은 벽 훅이지만 **정지(시그니처 술어) 이중 조건**이 이 기체만의 결속 변형 — S4 는 접촉 단독, 이것은 접촉×정지라 과충전 유지와 자리가 일치한다.)
- 레벨 스케일: 감소 12% + 1.2%p/Lv.
- 1레벨: 벽 낀 지형에서 자리 고르는 기준이 생긴다. / 20몰빵: blockBreak·침공 방어선 등 벽 많은 무대의 요새화.
- 연계: 벽(8.1·8.2) — **무기 밖 요소** · 시그니처(직접 — 정지 술어) · BR1 과 "벽 등지고 전방 척력" 기하.
- 구현: A — "직전 틱 벽 접촉" 엔진 플래그 공유(⑥-5, striker M5 와 동일 규칙 — `SlideResult.hit` 읽기만·헬퍼 시그니처 불변). 침공 이동벽 피해는 감쇠 통로 밖(2.6)이라 미적용 명시.

### [BR6] 전하 역류 (charge-backflow)
- 본체: **HP 가 30% 이하로 떨어지는 피격 틱**에 자동 발동: 쌓인 aux0 을 **전량 소각**해 소각 틱에 비례한 HP 를 즉시 회복한다(내부 쿨다운 동안 재발동 없음) — 방전(chain_hi)이 충전을 화력으로 바꾸듯, 이것은 충전을 생명으로 바꾼다. (1R 재설계 — 구 "소거+주입+연쇄" 페이로드는 유니크 ⑩ 위상 전환막(`world.ts:3917-3927`)과 사실상 동일했다. **재발 주의 패턴 ② 위반 사례로 명기**: "미사용/신규" 판정을 스킬 계층 안에서만 보고 유니크 계층을 grep 하지 않았다.)
- 레벨 스케일: 소각 틱당 회복 bp = 500 + 50×Lv (만충 600틱 소각 시 Lv1 = 33, Lv20 = 90 HP), 내부 쿨다운 = 1200 + 43200/(Lv+11) 틱 (Lv1 = 4800, Lv20 ≈ 2594, 점근 1200 — 연속 체감).
- 1레벨: 만충 포대의 목숨 보험 1회. / 20몰빵: 빈사 반복 플레이의 회복 엔진 — 단 회복 후 aux0 = 0 이라 과충전 화력을 잃는 진짜 대가가 있다.
- 연계: 시그니처(직접 — aux0 소각, chain_hi 방전과 대칭 문법) · HP(2.4 — 회복은 정수 게이트 안쪽) · BR4/CH7 과 만충 사용처 3파전.
- 구현: B — WorldState 평평 정수 1개(내부 쿨다운 잔여) + "0이면 무폴드" 조건부 꼬리 폴드. 발동은 2.8 피격 후속 블록의 경계 **통과** 판정(이전 HP > 30% ≥ 이후 HP — 핵심 문법의 통과형).

### [BR7] 완충 콘덴서 (buffer-condenser)
- 본체: **피격으로 깎인 피해량이 aux0 충전으로 전환**된다 — 얻어맞을수록 과충전이 빨라지는 역발상 포대(BR4 와 정반대 방향: 저쪽은 충전→방어, 이쪽은 피해→충전).
- 레벨 스케일: 전환 = round(피해 × (0.5 + 0.05×Lv)) 틱 (Lv20 = 피해 1당 1.5틱).
- 1레벨: 피격이 완전 손해가 아니게 된다. / 20몰빵: 피격 30 = +45틱 — 난전 속 과충전 유지의 브루저식 번역.
- 연계: 시그니처(직접 — aux0 가산, 600 클램프 유지) · 피격 후속 블록(2.8) · BA9 와 "리셋 없는 과충전" 두 기둥.
- 구현: A — 2.8 블록에서 `aux0 += k`(`setStillTicks` 동형 클램프). 폭 k 가산이 90 을 건너뛰어도 CH4 는 통과 판정이라 발화(핵심 문법).

### [BR8] 정지 수복 회로 (still-repair)
- 본체: **과충전 유지 중 일정 틱마다 HP 1 회복** — 자리를 지키는 것이 곧 수리다.
- 레벨 스케일: 회복 주기 = 20 + 1200/(Lv+14) 틱 (Lv1 = 100, Lv20 ≈ 55, 점근 20 — 연속 체감), 회복량 1 고정.
- 1레벨: 장기전에서 잔피해가 서서히 메워진다. / 20몰빵: 55틱당 1 — 회복 픽업이 없는 게임(5.6)에서 희소한 상시 회복 축.
- 연계: 시그니처(직접 — 과충전 술어) · HP(2.4 — 정수 게이트 안쪽 회복).
- 구현: A — **`state.tick % 주기 === 0` + `overchargeBp(aux0) > 0`**(1R 심각 1 수정 — 구판 `aux0 % 주기` 는 600 고정에서 영구 침묵·BR7/BA9 위상 교란). maxHp 클램프.

### [BR9] 척력 외피 (repulse-hull)
- 본체: **무적프레임(피격 무적·대시 무적) 동안 몸 주변의 적탄이 소거**된다 — 무적이 시간 벌기가 아니라 탄막 청소가 된다.
- 레벨 스케일: 소거 반경 32 + 4×Lv (판정점 8 밖 — 2.1 의 이로운/해로운 접촉 이원 반경과 무관한 제3 반경임을 명시).
- 1레벨: 피격 직후 40틱 무적이 연쇄 피격 차단기가 된다. / 20몰빵: 캡스톤 탄막 잔상(대시 소거 320)·위상 재구성과 겹층 — 무적 창이 전부 청소 창.
- 연계: 무적(2.3) · 적탄(7.8 — 소거는 부수효과만·반환 없음 규율 준수) — **무기 밖 요소**.
- 구현: A — `iframes > 0` 술어 + `clearEnemyBullets` 매 틱(반경이 작아 부담 없음).

### [BR10] 최후 접지 (terminal-ground)
- 본체: **캡스톤 위상 재구성(런당 1회 치명 무효)이 발동하는 틱**에 aux0 = 600(카운터 상한)으로 세팅되고 무적이 연장된다 — 죽음 직전의 일격이 완전 충전 포대를 깨운다. (1R 페이로드 분화: 전 화면 소거는 위상 전환막의 고유 동작이라 제거 — 이 스킬은 **주입+무적 연장**만, BR6 은 소각+회복, CH7 은 여진.)
- 레벨 스케일: 무적 연장 +2 + floor(Lv/2) 틱 (2레벨 폭 정수 계단).
- 1레벨: 캡스톤 1회가 반격 개시 신호로 승격. / 20몰빵: 무효 후 창이 길어져 "부활 일제사"(BA1·CH7)를 안전하게 잇는다.
- 연계: 캡스톤(barrier 트리 직결) · 시그니처(직접 — 상한 주입, barrage_hi 의 190 세팅과 같은 문법의 극단값).
- 구현: A — ~~캡스톤 무효 처리 지점(`world.ts:3862` `targetX` 소진 표식 부근) 훅~~ + iframes 가산.

## ④ 침공(PvP) 판정 표 — 헌장 개정 기준(제1·제2) 재판정

- **제1 기준**: PvE 에서 작동하던 억제(대가·제약)가 침공 환경에서 소실되어 순이득만 남는가.
- **제2 기준(개정)**: 침공 전용 요소와의 상호작용이 **PvE 에 없는 순이득/부호 반전**을
  만드는가(방어 설비 강화 = 공격자 버프 — 스트라이커 S5 선례). 이 둘 밖의 사유는 게이트가
  아니라 밸런스 각주. 같은 훅은 기체 간 일관 판정하고 선행 배치 판정을 인용한다.

## ⑥ 마이그레이션 / 선결 과제

1. **시그니처 변경 없음** — uniqueMask·`SIGNATURE_BITS`·골든 전부 불변. 해시 마이그레이션 불요.
2. **신규 WorldState 정수 6개**(CH4·CH7·BA7×2·BR4·BR6)는 "전부 0이면 무폴드" 조건부 꼬리
   폴드 — 미투자 런의 상태 해시 바이트 불변(관용구 ①·인벤토리 10-(b)).
3. **leaf 개정 2건**: ①`applyChain` 반경·대상 수 파라미터화(CH2 — `status.ts`, 0c 동결 5종
   밖·기본값 호출 비트 동일) ②신규 leaf `blastDamageAt`(CH3 — 기존 `blastDamage` 가 위임,
   동결 시그니처 불변).
4. **감쇠 사슬 스킬 슬롯**(BR3·BR5 감소 → BR4 흡수): striker S4/S8 슬롯과 같은 위치 공유 —
   먼저 구현되는 레인이 슬롯을 세우고 나중 레인이 합류(2.6 계약 개정은 1회만).
5. **"직전 틱 벽 접촉" 엔진 플래그**(BR5): striker M5 와 공유, 같은 규칙.
6. **BA6 신규 센티널 마커** 1개: 기존 마커들과 값 충돌 없는 큰 상수 + `isGimmick` 제외 +
   상한 출처별 분리(해츨링 선례) + **조준 enemy kind 한정 필터**.
7. **구현 레인 확인 항목**: ①**플레이어 탄 표식 칸 배정** — CH10 마커(`aux0`)·CH8 초기 관통
   기록(`aux1`)·**CH3/CH1 의 발사 시점 `ocBp` 표식**(3R 신설) 세 축이 같은 탄에 공존할 수
   있다. 플레이어 탄의 미점유 필드 전수 조사 후 칸 3개 확보 또는 비트 패킹(예: `aux1` 상위
   비트에 ocBp, 하위에 초기 관통)을 결정하고, 어느 쪽이든 `ENTITY_HASH_LAYOUT` 불변(이미
   해시되는 필드 재활용)을 지킬 것 ②침공 전리품 드랍 유무(CH9 no-op 여부 — 판정 불변)
   ③기존 포탑 조준 로직의 구조물 포함 여부(BA6 필터 필요성).
8. **`src/sim/**` 변경이므로 EF 재배포 필수**(공통-C).
9. **오토파일럿 의존성**(인벤토리 11.4): 오토파일럿은 액티브·대시를 안 누를 뿐 아니라
   **정지하지도 않는다** — 시그니처 자체가 벤치에서 발동하지 않으므로 30종 대부분이 자동
   측정 불가. 밸런스 자동 측정에는 "정지 파일럿" 정책이 필요(별도 레인 과제 — 의존성만 기록).
