## ① 시그니처 확인 — 기존 유지 (은신, SIG_PHANTOM_CLOAK = 20)

**규칙(정본, 이미 배선 완료)**: 연속 무피격 240틱(`CLOAK_UNHIT_TICKS`)을 채우면 120틱
(`CLOAK_HOLD_TICKS`) 은신(적의 공격 방출 4곳 게이트, 이동·램은 그대로) → 자동 해제 후 재적립.
해제 첫 타 배율 `CLOAK_BREAK_BP`=25000(2.5배). 피격은 사이클을 즉시 0 으로 되돌린다.

### aux0/aux1 인코딩 (grep 실증 — `src/sim/**` 전수)

```
팬텀  aux0 = 연속 무피격 틱(0..359, 구조적 상한 = UNHIT+HOLD−1)   — world.ts:2105-2114 가 적립·되감기
      aux1 = 은신 해제 첫 타 배율 토큰(0/1)                        — 세움: fireCloakEntry(진입 에지 정본, 본 설계) + AS3 재장전(0/1 그대로 재세움)
                                                                    소진: world.ts:2585-2593(유일) · 리셋: 3892-3895(피격)·2113(되감기)
```

(3판 갱신 — 토큰은 0/1 이진을 유지한다. AS3 재장전도 같은 1 을 다시 세울 뿐이라 인코딩
표는 불변이고, 세우는 경로가 fireCloakEntry·AS3·기존 액티브 4경로로 늘어난 것만이 변화다.
그래서 아래 헬퍼 절이 **쓰기 경로 단일화**를 계약으로 못 박는다.)

- 은신 술어 단일 정본: `src/sim/cloak.ts` `playerCloaked` (침공이면 무조건 false).
- **침공 취급(선례의 본체)**: `world.ts:2104` 에서 적립 분기가 통째로 반환 — aux0/aux1 이
  적립 경로로는 끝까지 0. 단 **3892 피격 리셋과 2585 소진 지점의 게이트는 `signatureOn`
  뿐이라 침공에서도 실행된다**(1판 오류 정정 — M-3). 억제(조준 제외)를 방어체 어픽스 좌표
  계약 때문에 걸 수 없으므로 배율도 대칭 차단(cloak.ts invariants-4)이 기존 계약이다.

### ⚠️ 이번 설계의 구조 전제 — 사이클 조작 단일 헬퍼 (심각-1 수정, 30종 공통 정본)

실코드의 진입 판정은 `aux0 === CLOAK_UNHIT_TICKS` **정확 일치**(world.ts:2108)이고
`setUnhitTicks` 는 359 clamp(activeHandlers/phantom.ts:33-36)다. 이 위에 `aux0+k` 주입을
얹으면 ①임계를 건너뛰어 토큰·진입 에지가 영영 안 서고(2.5배 조용한 소실 + PH7·DI7·DI8
동반 사망) ②창 안 주입은 359 clamp → 다음 틱 360 → **즉시 사이클 리셋**(은신을 앞당기는
게 아니라 파괴)이다. 따라서:

1. **`setUnhitTicks(aux0+k)` 직접 주입 전면 금지.** 모든 사이클 조작은 신설 단일 헬퍼
   `advanceCloak(state, player, k)` 를 경유한다.
2. **진입 판정을 에지로 승격**: `prev < 240 && next ≥ 240` (정확 일치 폐기). 정본 발화
   함수 `fireCloakEntry`(aux1 = 1 + 진입 에지 훅 PH7·DI7·DI8 일괄 호출) 한 곳만 토큰을
   세운다. world.ts:2108 의 자연 적립(`+1`)도 같은 에지 판정으로 교체(값 동일 — `===` 는
   `+1` 전제의 특수형이었다).
3. `advanceCloak` 규칙: 침공(`invasion3`) → no-op / **창 안(aux0 ≥ 240) → 무효(no-op,
   택일 확정 — 창 연장은 PH5 의 전유 축으로 남긴다)** / 창 밖 → `next = min(aux0+k, 240)`
   후 에지 통과 시 `fireCloakEntry`.
4. **aux1 쓰기도 단일 헬퍼로 모은다 (SEVERE-3)**: `advanceCloak` 은 aux0 헬퍼라 **aux1
   직접 주입을 못 막는다** — 현행 4경로가 그 구멍이다: `activeHandlers/phantom.ts`
   `breakCloak`(:45-48) 경유 `assassin_lo`(:54)·`assassin_hi`(:68), `disrupt_hi`
   발동(:96) + SUSTAIN 매 틱 재세움(:108). 신설 헬퍼 `setBreakToken(state, player)` 로
   전 쓰기 경로를 일원화한다(침공 no-op 내장).
5. **소진 지점 침공 게이트 (SEVERE-3 핵심)**: `world.ts:2585` 는 `aux1 !== 0` 만 보고
   침공을 안 본다 — 헬퍼를 우회한 잔존 쓰기가 하나라도 있으면 침공에서 전 발사 2.5배가
   된다. **`invasion3 === undefined` 게이트를 2585 에 직접 추가**한다(cloak.ts
   invariants-4 대칭 차단 논리의 소진 지점 확장 — 심층 방어 2겹: 쓰기 헬퍼 + 소진 게이트).
6. **기존 액티브 이관 목록(전량)**: `as_phantom_phase_lo`(advance 도약 — 임계 건너뜀)·
   `phase_hi`/`disrupt_lo` 의 `enterCloak`(진입 에지 훅 건너뜀) → `advanceCloak`/
   `fireCloakEntry` 경유, **그리고 `assassin_lo`·`assassin_hi`·`disrupt_hi`(발동 +
   SUSTAIN) 의 aux1 쓰기 4경로 → `setBreakToken` 경유**(구현 레인 필수 작업).

- **이 설계의 침공 핵심 쟁점**: aux 를 "읽는" 스킬은 침공에서 자동 no-op(aux 상시 0)이나,
  aux 에 "값을 심는" 스킬은 침공에서 2.5배 토큰을 억제 없이 부활시킬 수 있다 — aux0 은
  `advanceCloak`, aux1 은 `setBreakToken` + **2585 소진 게이트**가 일괄 차단한다(스킬별
  판정은 ④ 표).

## ② 스킬 30종

표기: 구현 태그 **A(재사용) / B(신규 상태) / C(신규 시스템)**. 레벨 스케일은 20 초과 자연
연장 — 선형 또는 연속 체감 곡선 `base + k×Lv/(Lv+c)` 만. 정수 계단은 전부 양적 반올림
(질적 변화 없음)이고 계단임을 표기한다. 곡선의 f64 나눗셈은 `createWorld` 가 투자 레벨당
1회 정수 확정해 config 파생값으로 싣는다(striker.md 규약 동일).

### 암살 (assassin / offense) — AS1..AS10

### [AS1] 이중 각인 (twin-mark)
- 본체: 해제 첫 타 배율이 소진되는 틱(`world.ts:2585`)에 **강화가 한 발 더 이어진다** — "첫 타"가 "첫 두 타"가 된다.
- 무기별 거동(MINOR 정정 — 명시): 발칸/스프레드 = 같은 볼리의 후속 탄 1발 · 레일건 = 첫 타 탄이 **관통 2번째 대상까지** 배율 유지 · 미사일 = 두 번째 미사일 1발 · 빔 = 첫 재도포 세그먼트 1개(짧은 수명이라 효과 미미 — 정직 표기).
- 레벨 스케일: 후속 배율 bp = 25000 × (0.3 + 0.6×Lv/(Lv+15)) (Lv1 ≈ 34%, Lv20 ≈ 64%, 점근 90% — 원배율을 절대 안 넘는 연속 체감).
- 1레벨 가치: 첫 타 낭비(잡몹 오버킬)가 절반쯤 회수된다. / 20레벨 몰빵 가치: 해제 1회 = 2.5배 + 1.6배 — 사이클당 화력 종착점.
- 연계: 시그니처(직접 — 소진 지점 확장) · AS8(적립 배율과 곱연산) · AS9 와 축 구분(탄 강화 vs 폭발 생성).
- 구현: A — 소진 지점의 볼리 생성 루프 안 지역 카운터(레일건은 탄 `phase` 관통 카운트 술어 재사용).

### [AS2] 은막 침투 (cloak-pierce)
- 본체: **은신 창(`cloakWindowActive`) 동안 발사한 탄**은 관통 +1 과 탄속 증가를 받는다 — 숨어서 쏘는 사격이 "정찰 사살"이 된다.
- 레벨 스케일: 탄속 +6% + 1.5%p/Lv (bp 정수).
- 1레벨: 관통 +1 이 즉시 온전(은신 중 한정이라 자체 억제). / 20몰빵: 은신 창이 곧 일제 소사 창.
- 연계: 시그니처(직접 — 창 술어) · PH5(창 연장과 곱) · AS10(창 중 사격의 다른 축 — 이쪽은 스탯, 저쪽은 지형 규칙).
- 구현: A — 발사 시점 `cloakWindowActive(player.aux0)` 술어 1회 + pierce/speed 가산.

### [AS3] 처형 재장전 (execution-reload) — 3판: 배율 단순화 (M2-1)
- 본체: **해제 첫 타(강화탄)로 적을 처치하면 배율 토큰(aux1)이 그 자리에서 재장전**된다 — 창 안에서 처치가 이어지는 한 강화탄이 연쇄한다. **재장전 토큰의 배율은 원배율과 동일**(aux1 은 0/1 이진 그대로 — 첫/재장전 토큰을 구분할 상태가 없으므로 구분하지 않는 것을 설계로 확정). 창 종료(되감기)의 `aux1 = 0` 이 자연 회수라 창 밖으로 새지 않는다.
- **처치 인정 범위(4판 확정 — 잔여-1)**: **명중 틱 즉시 처치만 인정**한다. 지연 처치(화염 dot 등) 포섭은 마커가 탄에 있고 탄은 관통 소진 시 소멸(`world.ts:3624-3628`)하므로 **적 필드 신규 상태**가 필요한데, 적 필드는 포화다(화염 `iframes`+`dashCooldown` / 냉기 `ownerId` / 엘리트 어픽스 `pierce` / 편대 `aux0`·`aux1`). B 로 가면 암살 축 B 가 3개가 되어 헌장 상한(축당 2)을 위반한다 — 그래서 범위를 좁히는 쪽을 택한다.
- 레벨 스케일: 재장전 타의 **관통 +floor(Lv/5)** (Lv20 = +4 — 5레벨 폭 정수 계단, 양적 반올림. 발사 시점 탄 파라미터라 신규 상태 0, 20 초과 자연 연장).
- 1레벨: 첫 타 처치 성공 시 두 번째 처형이 온전한 배율로. / 20몰빵: 재장전 타가 관통 +4 로 줄줄이 꿰뚫어 다음 처치까지 이어진다 — 연쇄가 스스로를 먹인다.
- 연계: 시그니처(직접 — 소진 지점 + `setBreakToken` 경유 재장전) · 처치(4.2) · PH5(창이 길수록 연쇄 상한 상승) · AS1(재장전 타에도 이중 각인 적용 — 곱연산).
- 구현: A — 강화탄에 탄 `aux0 = 1` 마커(플레이어 탄 aux 미점유를 구현 레인이 전수 확인, 점유 시 대안 `phase` 상위 비트) + 명중 처치 분기에서 `setBreakToken` 호출(창당 횟수 제한 없음 — 재장전마다 처치라는 대가가 다시 걸려 자체 억제). **aux0 주입 없음** — 사이클은 건드리지 않는다.

### [AS4] 급소 해부 (vital-dissection)
- 본체: **만피(hp === maxHp) 적에게 명중하는 첫 타**가 추가 피해를 받는다 — 기습의 첫 인상이 가장 아프다.
- 레벨 스케일: 추가 +12% + 1.8%p/Lv (bp).
- 1레벨: 새 웨이브 조우마다 공짜 선타. / 20몰빵: 해제 첫 타(2.5배)와 겹치면 신규 엘리트가 등장 즉시 반토막 — 개전 화력 특화.
- 연계: 시그니처와 곱연산(둘 다 "첫 타" 철학의 다른 축 — 이쪽은 대상 상태, 시그니처는 내 상태) · 엘리트/보스 등장(7.2·7.3). **재생 어픽스(엘리트 4)가 만피로 되돌리면 재발동한다 — 의도다**(재생 엘리트 카운터 역할, MINOR 표기).
- 구현: A — 피해 적용부에서 `e.hp === e.maxHp` 술어 1회(스폰 직후 정수 동일 보장 — f64 오염 경로는 구현 레인 확인). **실드 검증(MINOR — 침공 표와 동일 항목을 여기에도 기재)**: 침공 실드 경로(`world.ts:3561-3569`)에서 실드가 피해를 대신 받으면 `hp === maxHp` 가 상시 참이 되어 매 타 선타 보너스가 된다 — 실드 보유 구조물·포탑은 판정을 `hp+실드 === maxHp+실드최대` 로 하거나 대상에서 제외, 구현 레인 확정.

### [AS5] 배후 격살 (backstab) — 2판 서술 정정 (M-4)
- 본체: **플레이어가 적의 후방 반구에 있을 때**(적→플레이어 벡터와 적 이동 방향의 내적 음수) 명중 피해 증폭 — 등을 보인 적을 처형한다.
- 레벨 스케일: 증폭 +10% + 1.5%p/Lv (bp).
- 1레벨: 측면 기동·관통 후 사격에 즉시 보상. / 20몰빵: **돌진형(나를 향해 오는 적)에게는 구조적으로 안 걸린다 — 의도(배후가 없는 적은 못 찌른다).** 몰빵 가치는 견제형(standoff)·통과형·도주형이 섞인 무대 한정으로 성립하며, 전 무대 주력 딜은 아니다(정직 하향 — M-4).
- 연계: 적 이동 컴포넌트(7.1 — vx/vy 는 매 틱 대입이라 이동 방향이 항상 신선) · PH 축 기동과 합 — 무기 밖 요소(적 이동 상태). 정지 적(0,0)은 증폭 없음.
- 구현: A — 명중 시점 `(player.x−e.x)×e.vx + (player.y−e.y)×e.vy < 0` 술어.

### [AS6] 무성 격살 (silent-kill)
- 본체: **은신 창 동안 처치한 적은 죽음의 잔재를 남기지 않는다** — 폭발성 엘리트(어픽스 6)의 사망 폭발과 BK_SPLIT 자탄 분열이 무효가 된다.
- cloak.ts 의도 제외 2종을 뒤집는 근거(MINOR 판정): 기본 규칙("은신은 피탐지 회피이지 물리 법칙 면제가 아니다")은 **불변**이다 — 이 스킬은 잔해를 은신이 "막는" 것이 아니라 **처치 방식이 잔해를 만들지 않는** 소멸 규칙 변형이고, 포인트로 산 opt-in 이라 정본 철학(기본 은신의 범위 정의)과 충돌하지 않는다.
- 레벨 스케일: 은신 창 밖 사망 잔재 피해도 경감 −20% − 2%p/Lv (부분 효과 — 20 초과 자연 연장, 100% 도달은 Lv40).
- 1레벨: 은신 중 처형이 완전히 안전해진다 — 1레벨 유틸 대표. / 20몰빵: 폭발성 엘리트·분열탄 무대에서 근접 암살 해금.
- 연계: 시그니처(직접 — 창 술어) · 엘리트 어픽스(7.2)·적탄 분열(7.7) — 무기 밖 요소.
- 구현: A — `explodeElite`·BK_SPLIT 분열 분기에서 `playerCloaked` 술어 1회(사망 원인 귀속 불요 — 은신 중이면 전부).

### [AS7] 원한 청산 (grudge-settlement)
- 본체: **마지막으로 내 HP 를 깎은 적**이 「원한 표적」이 되고, 그 표적에게 주는 피해가 증폭된다. 표적 처치 시 해제.
- 레벨 스케일: 증폭 = 20% + 60%×Lv/(Lv+12) (Lv1 ≈ 25%, Lv20 ≈ 58%, 점근 80% — 연속 체감).
- 1레벨: 은신을 깬 자에게 즉시 반격 보너스. / 20몰빵: "맞으면 그놈부터 죽인다" — 피격이 화력으로 환류하는 이 축의 몰빵 대표.
- 연계: 피격 후속 블록(2.8 — 실피해만) · 시그니처와 긴장(피격은 은신을 잃는 대가, 이 스킬이 그 대가를 화력으로 보상) · AS3 과 반대 방향(성공 보상 vs 실패 보상).
- 구현: B — WorldState 평평 정수 1개(`grudgeTargetId`) + "0이면 무폴드" 조건부 꼬리 폴드(관용구 ①). 침공 코어모듈 반사·응징의 직접 피해(2.7 우회)는 2.8 블록 밖이라 표적 갱신 없음 — 일관.

### [AS8] 처형인의 적공 (executioner-tally)
- 본체: **처치가 다음 해제 첫 타 배율을 적립**한다 — 처치 스택이 쌓이고, 해제 첫 타 소진 틱에 전량 소모돼 배율에 가산된다.
- 레벨 스케일: 스택당 +150bp + 15bp/Lv, 스택 상한 = round(6 + 10×Lv/(Lv+10)) (Lv20 ≈ 13, 점근 16 — 연속 체감).
- 1레벨: 청소 후 첫 해제 타가 조금 굵어진다. / 20몰빵: 13스택 × 450bp ≈ +58%p — "많이 죽이고 크게 터뜨리는" 몰빵 축.
- 연계: 시그니처(직접 — 소진 지점) · 처치(4.2) · AS1(후속 탄에도 감쇠 반영) · AS3(**적공 스택은 창당 최초 소진 1회에만 실리고 재장전 타에는 미적용** — 재장전 배율이 원배율과 동일해진 3판에서도 이 구분은 유지된다: 스택 소모 시점이 "창 최초 소진"으로 유일해 이중 지급이 원리적으로 불가, M2-1 재정리).
- 구현: B — WorldState 정수 1개(처치 스택) + "0이면 무폴드" 폴드. 적립은 `state.kills` 델타(compact 수렴)로.

### [AS9] 절멸 선고 (annihilation-verdict)
- 본체: 해제 첫 타가 **명중한 지점에서 표식 폭발**이 터진다 — 한 방이 광역 처형 선고가 된다.
- 레벨 스케일: 반경 100 + 10×Lv, 폭발 피해 = 첫 타 실피해의 25% + 1.5%p/Lv.
- 1레벨: 암살 한 방에 주변 정리가 따라온다. / 20몰빵: 해제 타 자체가 소형 폭격 — 밀집 웨이브 순삭.
- 연계: 시그니처(직접) · AS1 과 축 구분(탄 강화 vs 오브젝트 생성) · AS3(재장전 연쇄마다 폭발 반복 — 곱).
- 구현: A — 소진 지점 명중 처리에서 `blastDamage` 1회.

### [AS10] 유령 탄도 (ghost-trajectory) — 3판: 파괴가능 벽 거동 확정 (M2-3)
- 본체: **은신 창 동안 발사한 탄이 벽을 통과한다** — 단 **파괴가능 벽(hp > 0)은 "피해를 주고 통과"**, 불파괴 벽만 순수 통과. 아군탄이 파괴가능 벽에 피해를 주는 유일 경로가 직접 스윕(`world.ts:3248`)이라, 순수 통과로 정의하면 blockBreak 목표 진행이 정지하기 때문이다(M2-3).
- 레벨 스케일: 통과 후 탄 피해 유지율 = 100 − 65×13/(Lv+13) (Lv1 ≈ 40%, Lv20 ≈ 74%, 점근 100% — 단일 공식이 20 을 넘어 같은 파라미터로 계속 자라고 100% 에 닿지 않아 특이점·포화가 없다).
- 1레벨: 벽 뒤 적에게 반값 사격이 열린다 — 지형 무시 견제. / 20몰빵: 은신 = 벽 너머까지 사선(射線)이 열리되, **blockBreak 에서는 "벽도 깎고 뒤의 적도 맞히는" 이중 타격**이지 벽 무시가 아니다(정정 — M2-3).
- 연계: 시그니처(직접 — 창 술어) · 벽/LOS(8.1·8.2) — 무기 밖 요소 · AS2 와 축 구분(스탯 vs 지형 규칙) · DI9(몸의 벽 통과와 대구).
- 구현: A — 창 중 발사탄에 탄 `aux1 = 1` 마커(미점유 여부 구현 레인 전수 확인 — AS3 의 `aux0` 마커와 칸 분리) + **수정 지점 3곳**:
  ① `world.ts:3245` 차단 판정 — 마커 시 소멸 대신 유지율 감쇠 후 진행. ※현재 이 분기는 침공 no-op 경로라 사실상 죽은 코드지만, **미래에 침공 통과가 열릴 때를 대비한 방어 표기로 남긴다**(MINOR).
  ② `world.ts:3248` 파괴가능 벽 피해 — 마커여도 피해는 그대로 적용. **탄 하나가 같은 벽에 주는 피해는 1회로 제한**한다(관통 예산 동형) — `sweptCircleOverlapsWall` 이 벽 두께를 지나는 여러 틱 동안 계속 참이라 제한이 없으면 한 발이 3~4회 타격한다(잔여-3). 피해 귀속 기록은 탄의 관통 예산 감소로 대신한다(신규 상태 0).
  ③ **`world.ts:3103` 표적 선택** — `segmentBlocked` 가 벽 뒤 적을 후보에서 제외하므로 자동 조준 sim 에서는 이 게이트를 풀지 않으면 "벽 너머 처형" 본체가 성립하지 않는다. **은신 창 중에만 표적 선택의 `segmentBlocked` 를 무시**한다(창 밖에서는 유지 — 상시 무시하면 벽에 막혀 안 닿는 표적을 향해 쏘는 헛발사 결함이 부활한다, 잔여-2).
  - 다중 벽 연속 통과: 유지율은 **벽마다 곱연산**(2장 통과 시 유지율²) — 관통 예산과 별개 축이며, 예산이 0 이 되면 통과 여부와 무관하게 소멸한다.

### 위상 (phase / utility) — PH1..PH10

### [PH1] 잔상 이탈 (afterimage-exit) — 2판: 헬퍼 경유 (심각-1)
- 본체: **대시 발동 틱에 무피격 스트릭이 전진**한다 — 회피 기동 자체가 은신을 앞당긴다. 전진은 `advanceCloak` 경유: 240 에서 멈추고 에지를 정상 발화하며, **창 안 대시는 무효**(창 조작은 PH6 의 축 — 동시 투자 시 상호 배타로 충돌 없음, MINOR 정의).
- 레벨 스케일: 전진 = 20 + 4×Lv 틱 (Lv20 = 100).
- 1레벨: 대시 습관이 사이클 단축으로 환류. / 20몰빵: 대시 2~3회 = 은신 1진입 — 기동이 곧 은신인 빌드의 축.
- 연계: 대시(1.2) — 무기 밖 요소 · 시그니처(직접 — advanceCloak) · PH8·DI6 과 가속 3축(트리거 대시/젬/벽 전부 상이).
- 구현: A — 대시 발동 분기에서 `advanceCloak(state, player, k)` 1줄. 침공 no-op 은 헬퍼 내장.

### [PH2] 위상 착지 (phase-landing)
- 본체: 위상 액티브(blink) **착지 지점** 주변 적탄을 소거하고 냉기를 건다 — 나타나는 자리가 안전지대가 된다.
- 레벨 스케일: 소거 반경 140 + 10×Lv.
- 1레벨: 도약 착지가 탄막 속으로 떨어지는 사고를 막는다. / 20몰빵: 도약 = 이동식 정화.

### [PH3] 그림자 장부 (shadow-ledger) — 2판 재설계 (M-2, 규칙 축)
- 본체: **은신 창 동안 콤보 유지 창(`state.comboTimer`)이 감소하지 않는다** — 숨어 있는 동안 콤보 시계가 멈춰, 수확 리듬이 은신 사이클을 견딘다.
- 레벨 스케일: 창 중 젬 수거 시 comboTimer 회복량 +2 + 1×Lv 틱 (기본 회복에 가산 — 선형, 20 초과 자연 연장).
- 1레벨: 은신 2초가 콤보를 끊는 사고가 사라진다 — 1레벨 유틸. / 20몰빵: 은신 창이 콤보 ×1.5 유지 구간이 된다 — 수확 유령 빌드의 접착제.
- 연계: 콤보(4.4 — XP 에만 걸리던 콤보의 유지 규칙 변형) · 젬(5.3) — 무기 밖 요소 · 시그니처(직접 — 창 술어) · PH8(수집→은신)과 순환 완성. striker S8(콤보 부분 회복)과 계열 유사하나 이쪽은 **시계 정지**(감쇠 규칙 자체 중단)이고 은신 창에 결박 — 헌장 "시그니처와 얽힌 변형" 요건. 정지는 창 안으로 유계라 콤보 감쇠 규칙이 살아남는다(재발 주의 패턴 1 판정 통과).
- 교차 레인 계약: 아크캐스터 BA5(과충전 중 콤보 반속)와 분화 — PH3 는 **유한한 은신 창 동안 완전 정지**, BA5 는 **무기한 과충전 중 반속**. 창 구조가 달라 영구화 위험도 서로 다른 방식으로 차단된다(PH3 는 적립 240틱 > 콤보 창 120틱, BA5 는 단조 감소 보존).
- 콤보 수지 판정(MINOR — S8 선례 형식): 사이클당 정지 = 기본 창 120틱, **PH5 몰빵(창 246틱) 조합에서도 정지/주기 = 246/(240+246) ≈ 51%** — 나머지 49%(적립 구간 240틱)는 콤보 창(120틱)보다 길어 젬 수거 없이는 콤보가 반드시 만료된다. 사격·은신만으로 콤보 영구화 없음, 트레이드(수거 지속 ↔ ×1.5 배율) 보존.
- 구현: A — comboTimer 감소부에서 `playerCloaked` 술어(창 동안만 — 여운 없음, 신규 상태 0).

### [PH4] 무흔 보행 (traceless-stride)
- 본체: **은신 창 동안 이동 속도 상승 + 이동 감속(플레이어 슬로우·감속 장판) 면역** — 숨은 유령은 붙잡을 수 없다. (이속 계열은 30종 중 이 하나뿐 — M-1 정리)

- 1레벨: 은신 중 재배치 자유. / 20몰빵: 은신 창 = 최고속 창 — PH6 정지 예산과 함께 "은신 순항".
- 연계: 시그니처(직접) · 감속 장판(8.4)·감속(3.3) — 무기 밖 요소.

### [PH5] 연장 위상 (extended-phase)

### [PH6] 정지된 시계 (frozen-clock) — 2판 유계화 (심각-2)
- 본체: **은신 창 중 대시하는 틱에 사이클 시계(aux0 증가)가 멈춘다 — 단 창당 정지 총량에 예산이 있다.** 예산 소진 후 대시는 정지 없음. 창이 되감길 때 예산 리셋.
- 레벨 스케일: 창당 정지 예산 = min(12 + floor(2.4×Lv), HOLD/2) 틱 (**floor 확정** — MINOR. Lv20 = 12+48 = 60 = 120/2 도달, PH5 연장 시 상한도 절반으로 따라 는다). **점유율 ≤ (HOLD×1.5)/(360+…) 로 여전히 1 미만 유계 — shipSignature.ts:138-148 이 폐기한 영구 은신 재현 없음.**
- 1레벨: 은신 중 대시 몇 번이 공짜 연장. / 20몰빵: 은신 실사용 최대 1.5배 — PH5(상한 연장)와 다른 축(소비 정지).
- 연계: 시그니처(직접 — 적립 루프 2105 개입) · 대시(1.2) — 무기 밖 요소 · PH1 과 상호 배타(창 밖 대시 = PH1 전진, 창 안 대시 = PH6 정지 — 위상이 겹치지 않아 우선순위 문제 없음, MINOR 정의).
- 구현: B — 창당 정지 예산 소모 카운터(WorldState 정수 1) + "0이면 무폴드" 폴드. 정지 판정은 대시 임펄스 틱(`dashCooldown` 만충 직후 파생 술어) 한정.

### [PH7] 진입 섬광 (entry-flash)

### [DI10] 공허 계약 (void-covenant)
- 본체: **최대 HP 를 추가로 깎는 대신 해제 첫 타 배율이 영구 가산**된다 — 유리를 더 얇게 갈아 칼날을 세운다.

## ④ 침공(PvP) 판정 표 (2판 — M-3 반영: 실행 지점별 게이트 실증 기준)

판정 기준(헌장 정본): "PvE 에서 작동하던 억제가 침공 환경에서 소실되어 순이득만 남는가".
팬텀 구조 — **적립 분기(2104)만 침공 차단**이고 리셋(3892)·소진(2585)은 `signatureOn`

①절-5). 따라서 ①창/토큰/스트릭을 **읽는** 스킬은 값이 상시 0 이라 자동 no-op(단 **상수항이
있으면 그 항은 남는다** — 행별 명시), ②aux 에 **심는** 스킬은 aux0 = `advanceCloak` ·
aux1 = `setBreakToken` 의 침공 no-op + 2585 소진 게이트가 2겹으로 차단, ③은신 무관

### 공통 구현 고지

1. **`advanceCloak`/`fireCloakEntry`/`setBreakToken` 헬퍼 3종이 이 설계 전체의 선결

3. 진입 에지 훅 3종(PH7·DI7·DI8)은 `fireCloakEntry` 한 곳에서 순서 고정 호출(제안:

   합연산 1회, 순서는 DI9(무적 지속 연장) → PH10(발각 보너스)** 로 고정하고 같은 틱에
