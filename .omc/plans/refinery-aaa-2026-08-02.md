타이틀·인트로·기지·격납고와 하위 화면 셋(촉매 보관함 PR#247 · 예비역 로스터 PR#248 ·

**시각 정체성 = 시네마틱 전환**(사용자 확정). 나무 nine-slice(`ui_panel.png`)·나무 판때기 버튼
(`ui_btn_*.png`)·나무 배너(`ui_banner.png`)·나무 칩(`ui_chip.png`)은 이 화면에서 **은퇴**한다.
붓: 페인터리 디지털 페인팅, 금빛 고대 석재, 청록·자홍 성운, 짙은 실루엣, 따뜻한 금색 램프광.

⚠️ **비평 서브에이전트는 사용자가 요청할 때만 돌린다**(칩 특별 지시). 구현 → 하네스 실화면
스크린샷 → **사용자에게 제시**. 판정 기준은 스크린샷이고 사용자가 최종 판정자다.

## 0. 절대 규칙 (연구소 §0 · 챔피언 선택 §0 · 격납고 §0 승계)

1. **순수 render/UI 레이어(ADR-0005)** — sim 을 읽지도 쓰지도 않는다. 시간축은 벽시계.
2. **품질 티어를 런타임 수렴 상태로 판단하지 마라**(`getActiveTier()` 단독 사용 금지).
3. **띠를 겹쳐 그라디언트를 근사하지 마라.** 램프는 폭 1px 캔버스에 픽셀로 굽고 `linear` 로
   늘린다. ⚠️ `titleScreen.ts` 광선 스윕(`slabs = 7`)에 이 결함이 아직 남아 있다 — 복사 금지.
4. **Pixi v8**: `Sprite` 에 자식 금지(형제 + 변환 미러). `tint` 는 곱연산. 컬러 이모지 금지
   (`★ ✕ ▶ ◀` 는 보존 목록).
5. 자산은 **덧붙임이지 전제가 아니다** — 텍스처가 `undefined` 여도 화면이 서야 한다.
   **이 레인은 새 자산을 만들지 않는다**(§1-① 참조).
6. 캔버스 없는 환경(vitest)에서 `Text.width`·`document.createElement`·`ColorMatrixFilter`·
   `FillGradient`(**`new Text` 시점**에 던진다)가 전부 던진다. 관용구는
   `typeof document === 'undefined' || typeof document.createElement !== 'function'`.
   ⚠️ **캔버스 굽기 함수에만** 붙인다 — DOM 조회(`hudEl`)에 붙이면 HUD 숨김이 죽는다.
7. `npx tsc --noEmit` 0 · `npx eslint src tests --max-warnings 0`.

## 1. 이 화면 고유의 판단 넷

### ① 창을 뚫는가 → **뚫지 않는다(`windows: []`)**

형제 화면 넷의 결론: **창은 "배경이 보이는 구멍"이 아니라 "무언가를 보여주는 자리"다.**
정제소에서 선택에 따라 바뀌는 것은 **장비 하나**인데, 그 장비의 유일한 그림은 인벤토리
아이콘(`equipIconTexture`, 실크기 48~88px)이다. 400px 창에 그걸 세우면 **확대된 UI 아이콘**이
되지 회화가 아니다(챔피언 선택은 전용 함선 원화가 있어서 성립했다).

창에 세울 만한 진짜 피사체는 **노(furnace) 원화**인데 그건 신규 자산이고, 이 레인은 자산을
만들지 않는다(만들면 별도 레인). 게다가 창 400px 을 떼면 상세 패널이 1188 → 788 로 줄어
어픽스 행이 제목+설명 2줄을 못 담는다 — **정보 밀도가 이 화면의 목적이다**(격납고 §0-bis-3).

→ 배경 노출은 **헤더 밴드(1920×104)와 패널 사이 틈**뿐이다. 촉매 보관함·예비역 로스터·
연구소와 같다.

### ② 하단 [기지로 돌아가기] 버튼은 **없앤다**

현재 화면은 헤더 우상단 ✕ 와 하단 중앙 버튼으로 **같은 일(close)을 두 번** 제공하고, 그
버튼 하나 때문에 패널 바닥이 894 에서 끊겨 화면 하단 186px 이 통째로 비어 있다. 형제 화면
넷은 전부 헤더 ✕ 하나만 쓴다. 되찾은 세로는 두 패널이 받는다(하드코딩 금지 —
`PANEL_H = DESIGN_HEIGHT - BOTTOM_PAD - PANEL_Y` 파생).

### ③ 빈 자리를 남기지 않는다 — 상세 패널의 **버려지는 세로를 0 으로**

패널을 940 으로 키우면 어픽스가 1~6개뿐인 상세 패널에 큰 공백이 생긴다. 처방은 셋이다.

- **공정 뭉치(노 출력 → 비용 → 굴리기)를 콘텐츠 상자 바닥에 못 박는다** →
  `lastBottom === boxBottom` 이 **등호로** 성립한다(버려지는 하단 0).
- 어픽스 목록과 뭉치 사이에 **용해 위험 트로프**를 신설한다(§1-④).
- 어픽스 영역 높이는 **트로프에서 역산**한다(`AFFIX_REGION_BOTTOM = TROUGH_Y - 20`).
  최대 행 수도 그 높이에서 파생 — 상수 6 을 박으면 등급 정의가 바뀔 때 조용히 잘린다.

### ④ 신설: **용해 위험 트로프** — 공백을 메우는 것이 아니라 이 화면의 주제를 그린다

ADR-0040 의 진술: "정련 연출의 무게중심은 결과 공개가 아니라 **누르기 전 긴장**이다."
그런데 현재 위험은 비용 줄 끝에 붙은 **글자 조각**(`… · 용해 위험 34%`)일 뿐이고, 고착 수는
반대편 끝에 따로 떠 있다. 둘은 같은 하나("얼마나 걸었는가 / 얼마나 위험한가")다.

→ 상자 폭 전체를 쓰는 **파인 트로프**(석재 홈) 안에 `고착 n/총` + **위험 게이지 바** +
`용해 위험 n%` 를 한 덩어리로 모은다. 위험 0 이면 게이지가 없고 "위험 없음"만 남는다 —
위험이 없다는 사실이 시각적으로도 없어야 한다(기존 규칙 유지). 비용 줄에서는 위험 문구를
**뺀다**(두 곳에서 같은 수치를 말하면 하나는 노이즈다).

트로프 높이는 **고정 84** 이고, 남는 세로는 어픽스 영역이 받는다(§1-③).

## 2. 레이아웃 (디자인 스페이스 1920×1080)

여백 어휘(32 / 28 / 20 / 하단 28)와 헤더 높이 104 는 형제 화면과 **같은 값**이다.

| 요소 | x | y | w | h |
| --- | --- | --- | --- | --- |
| 헤더 밴드(배경 노출) | 0 | 0 | 1920 | 104 |
| 장비 목록 패널 (slab) | 32 | 112 | 640 | 940 |
| 정련 공정 패널 (slab) | 700 | 112 | 1188 | 940 |

- `PANEL_Y = HEADER_H + 8 = 112`, `PANEL_H = 1080 − 28 − 112 = 940`.
- `DETAIL_W = (1920 − 32×2) − 28 − 640 = 1188`, `DETAIL_X = 32 + 640 + 28 = 700`.
  우변 `700 + 1188 = 1888 = 1920 − 32` ✓ (전부 파생 — 숫자를 박지 않는다).

헤더 컨트롤(전부 y 26 · h 52):

| 컨트롤 | x | w |
| --- | --- | --- |
| (각인 제목 = 중앙 960, 대역 ±280) | — | — |
| 광물 칩 | 1424 | 190 |
| 크레딧 칩 | 1628 | 190 |
| 닫기 ✕ | 1832 | 56 |

- 좌상단 x<120 · y<120 은 **설정 톱니 예약 밴드**다. 이 화면은 헤더 좌측에 컨트롤이 없으므로
  구조적으로 안전하지만, 테스트로 잠근다(나중에 좌측에 뭔가 놓을 때가 진짜 위험이다).
- 제목 대역 680..1240 과 첫 칩 1424 사이가 184 — 중앙 정렬 Text 는 사각형이 없어 겹침
  테스트가 못 잡으므로 `TITLE_BAND_HALF_W` 로 대역을 못 박고 잠근다(연구소에서 실제로 겹쳤다).

### 패널 안(패널 로컬, 제목 띠 있는 슬래브: box = x24 · y68 · w W−48 · h H−92)

**목록 패널** box = 592×848 (y 68..916):

- **정렬 줄**(상자 맨 위, y 68 · h 42): 획득순 · 등급순 · 슬롯순 · 어픽스순 4칸.
  칸 폭은 상자 폭 파생(`(592 − 10×3) / 4 = 140`). 선택 표시는 노 출력 버튼과 **같은 어휘**
  (금색 링 + 미선택 0.72) — 한 화면에 라디오 관용구가 둘이면 하나는 버튼으로 안 읽힌다.
  정렬은 자원을 쓰지 않는 중립 조작이라 톤은 `stone`(청록은 "자원을 쓴다"에 배정돼 있다).
- 6열 격자는 **정렬 줄 아래**(y 122)에서 시작한다. 셀 한 변은 남은 세로에서 역산 →
  `CELL 79` · `GAP 10` → 피치 89 · `GRID_W = 6×89 − 10 = 524`(상자 안 중앙 정렬).
- 마스크 높이는 행 피치의 배수로 클램프. 버려지는 세로는 **한 행 피치 미만**(테스트가 잠근다).
- 정렬은 **표시 순서만** 바꾼다 — `rerollable()` 은 "굴릴 수 있는 것"의 정의이고 회귀 테스트가
  쓰는 표면이라 거기에 순서를 섞지 않고 순수 함수 `sortRefineryItems` 를 따로 둔다.
  세 정렬 다 **동률에서 획득순으로 되돌아간다**(원래 인덱스가 tie-break) — 아니면 같은 등급
  장비들의 자리가 굴릴 때마다 미묘하게 바뀌어 방금 고른 칸을 눈으로 못 쫓는다.
- 휠은 **클립 Container**(`makeScrollArea`). 클릭은 셀 Container.

**정련 공정 패널** box = 1140×848 (y 68..916). 세로는 전부 파생이다:

| 요소 | y | h | 파생식 |
| --- | --- | --- | --- |
| 장비 머리(아이콘 88 + 이름 + 부제) | 68 | 88 | `box.y` |
| 어픽스 목록 영역 | 180 | **428** | `TROUGH_Y − 20 − 180` |
| 용해 위험 트로프 | 628 | 84 | `HEAT_Y − 20 − 84` |
| 노 출력 3버튼 | 732 | 56 | `box.bottom − BLOCK_H` |
| 비용 줄 | 804 | 30 | `heatY + 56 + 16` |
| 굴리기 · 공정 멈추기 | 848 | 68 | `costY + 30 + 14` |

- `BLOCK_H = 56 + 16 + 30 + 14 + 68 = 184` · `lastBottom = 848 + 68 = 916 = box.bottom` **등호**.
- 어픽스 행: `H 64` · `GAP 8` → 피치 72. 최대 행 수 = `floor((428 + 8) / 72) = 6` → 6행이
  `6×72 − 8 = 424 ≤ 428`. 레어 6어픽스가 스크롤 없이 들어간다(잔여 4).
  더 많은 어픽스가 생기면 목록은 스크롤 영역이 받는다(`makeScrollArea`).
- 어픽스 행 한 줄이 아니라 **두 줄**이다(제목 + 설명). 지금은 설명이 hover 툴팁에만 있는데
  1140px 폭에 64px 높이면 설명이 그냥 들어간다 — 폭을 정보로 바꾼다.
- 노 출력 버튼 `W 200` · `GAP 14` → 628. 오른쪽 남는 496 에 노 출력 안내를 접어 넣는다.

## 4. 재렌더 규율

현재 구현은 `render()` 가 루트를 통째로 지우고 다시 그린다. 시네마틱 전환 후 그대로 두면
**노 출력 버튼 한 번, 고착 한 번, 스핀 프레임마다** 배경과 석재 패널 2장이 다시 **구워진다**
(스핀은 70ms 간격 12프레임이다 — 초당 14회 재굽기).

- `buildChrome()` — 배경·패널 2장·헤더·정적 위젯은 **한 번만**. 자산 도착 시 1회 재건,
  그리고 **목록 개수가 바뀌면** 재건(목록 패널 제목이 `refine.listHeader{n}` 이고 각인 제목
  띠는 패널에 구워지기 때문 — `builtForItemCount`).
- `syncValues()` — 재화 칩 · 힌트만.
- `renderGrid()` — 목록 격자 셀만 `gridHost` 안에서.
- `renderDetail()` — 상세 내용만 `detailHost` 안에서.
- `renderSpinFrame()` 은 **글자만** 갈아끼운다(기존과 동일 — 재렌더하지 않는다).
- `update(dt)`: **`main.ts` 가 매 프레임 부른다**(`refinery.update(frame)` 를
  `researchLab.update(frame)` 바로 옆에 배선한다). 숨겨져 있으면 즉시 반환한다.
  ⚠️ 연구소가 이 배선을 빠뜨려 배경·패널 연출이 통째로 멈춘 적이 있다.

## 5. 기능 불변식 — 깨면 즉시 불합격

1. **결과 확정·저장이 언제나 연출보다 먼저다**(`persist()` → `startFx`). 새로고침으로 나쁜
   롤을 무를 수 없는 근거가 그 순서다.
2. `reroll()` 의 4중 방어를 한 줄도 건드리지 않는다: `busy` 재진입 가드 · `heat` 진입 시점
   스냅샷(비용과 판정이 같은 값) · `chain.baseline.id !== item.id` 재개방 ·
   복귀 후 `stillSame`/`stillVisible` 재검증.
3. 서버 권위(ADR-0027): `ok`/`unconfigured`/`insufficient`/그 외 4분기 유지.
   `insufficient` 는 **서버 잔액을 그대로** 보여 준다.
4. 저장은 `persist()` → `saveProfile(profile, store ?? undefined)`. 명시적 null 금지.
5. 고착은 **굴림당 1개 · 해제 불가**. 무시 판별식은 **참조 비교**(`next === chain`).
   완주 판정은 `fasten()` 에서 한다.
6. private 메서드 이름 `select` · `reroll` · `fasten`, 필드 `chain`/`selectedId`/`heat`/
   `spinning` 은 **회귀 테스트가 캐스팅으로 직접 찌른다**(`tests/pixiScreenPersistence.test.ts`
   `RefineryProbe`). 바꾸지 마라.
7. `refineryDetailLayout(affixCount)` 의 **공개 필드 6종**(`rowsEnd`·`heatY`·`costY`·`actionY`·
   `lastBottom`·`boxBottom`)과 그 부등식 3종(`lastBottom ≤ boxBottom` · `heatY ≥ rowsEnd` ·
   `heatY < costY < actionY`)을 유지한다.
8. 연출 참조(`heatHalo`/`rollNode`/`fxOverlay`/`spinTexts`)는 재렌더 **전에** 끊는다 —
   파괴된 노드를 `Ticker` 콜백이 만지면 안 된다.
9. **휠 스크롤은 클립 Container 에**(마스크 Graphics 는 히트 테스트 제외). **행 클릭은 행
   Container 에.**
10. ⚠️ 진입 시 런 HUD 숨김 · 닫을 때 **원래 값 복원**(`hudPrevVisibility`). 기존 구현은 무조건
    `visibility = ''` 로 되살렸다. `hudEl()` 에 캔버스 가드를 붙이지 않는다.
11. `close()` 는 연출 중·서버 왕복 중 이탈을 막는다(1차 방어). 누수를 실제로 막는 것은
    `reroll()` 의 `stillVisible` 이다.

## 6-bis. 실화면에서 고친 것 · 사용자 지시 (1차 제시 이후)

1. **어픽스 1개짜리에서 목록 영역 428px 중 330px 이 빈 갈색 면**이었다. 어픽스 수는 장비가
   정하므로 행으로는 못 채운다 → 영역을 **파낸 노 챔버**로 그려 남는 자리에 **이름을 준다**
   ("빈 패널"이 아니라 "비어 있는 노 안"). 트로프와 같은 파인 면이라 둘이 한 설비로 읽히고,
   어픽스가 꽉 찬 장비에서는 행이 덮으므로 비용이 0이다.
2. **장비 미선택이면 상세 패널 1140×848 이 통째로 비었다**(이 화면 최악의 빈 자리) → 설비
   (챔버·트로프·노 출력·꺼진 굴리기)를 그대로 그리고 **빈 소켓 옆에서** 무엇을 할지 말한다.
   굴리기는 `!hasItem` 로 **명시 비활성화** — 비용이 0 이라 `canAfford` 가 참이 되어 활성으로
   보이던 자리다.
3. 상세 패널 제목 `리롤` → **`정련 공정`**(신규 키). 사문화된 `refine.reroll` 삭제.
4. **사용자 지시**: `노 출력이 높을수록…` → **`화력이 높을수록…`**(`노` 한 글자 한자어가
   먼저 다르게 읽힌다). `refine.chain.noBand` 의 "노 출력" 도 같이 정리.
5. **사용자 지시**: 목록 패널에 **정렬 버튼**(§2 참조).

## 7. 지표 운용 규율 (승계)

1. 대리 지표를 **"균일해야 할 것의 상한"** 으로 주면 그림이 지워진다. **하한(보존)으로만 안전.**
2. **평균은 결함을 가린다.** 게이트는 `타일 최소` + `임계 미만 픽셀 비율`로.
3. 대비는 **곱연산(AO)** 으로. **절대 델타는 곱연산 편차의 지표가 아니다.**
4. **표본 정의가 다르면 반대 결론이 나온다** → 정의 비의존 속성을 보고하게 하라.
5. **판정 기준은 스크린샷이고 수치는 대리 지표다.**
6. **처방을 내리기 전에 그 지표가 올바른 축을 재고 있는지 먼저 검토한다.**
