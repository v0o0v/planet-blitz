## 0. 절대 규칙 (관제탑 §0 승계)

1. **순수 render/UI 레이어(ADR-0005)** — sim 을 읽지도 쓰지도 않는다. 시간축은 벽시계.
2. **품질 티어를 런타임 수렴 상태로 판단하지 마라**(`getActiveTier()` 단독 사용 금지).
3. **띠를 겹쳐 그라디언트를 근사하지 마라.** 램프는 폭 1px 캔버스에 픽셀로 굽고 `linear` 로 늘린다.
4. **Pixi v8**: `Sprite` 에 자식 금지(형제 + 변환 미러). `tint` 는 곱연산. 컬러 이모지 금지
   (`★ ✕ ▶ ◀` 는 보존 목록).
5. 자산은 **덧붙임이지 전제가 아니다**. **이 레인은 새 자산을 만들지 않는다.**
6. 캔버스 없는 환경(vitest)에서 `Text.width`·`document.createElement`·`ColorMatrixFilter`·
   `FillGradient` 가 전부 던진다. 관용구는
   `typeof document === 'undefined' || typeof document.createElement !== 'function'`.
   ⚠️ **캔버스 굽기 함수에만** 붙인다 — DOM 조회(`hudEl`)에 붙이면 HUD 숨김이 죽는다.
7. `npx tsc --noEmit` 0 · `npx eslint src tests --max-warnings 0`.

## 1. 이 화면 고유의 판단 여섯

### ① 창을 뚫는가 → **뚫지 않는다.** 초상은 128×128 이라 개구부를 채울 수 없다

형제 화면 아홉의 결론: 창은 "배경이 보이는 구멍"이 아니라 **무언가를 보여주는 자리**다.
여기서 후보는 파일럿 파일 탭의 **기체 초상**(`shipPortraitName`)뿐인데 실측하면
`assets/ship_portrait_*.png` 는 **전부 128×128** 이다. 상세 열의 개구부는
`cinematicWindowOpening(1108, 776, true)` = 1094×702 라, 초상을 거기 채우면 **5.4배 확대**로
뭉개지고 정사각을 세로 창에 넣으면 위아래에 맨 배경 띠가 생긴다 — 방어 사령부에서 사용자가
신고한 바로 그 형태다. 창을 초상 크기로 줄이면 남는 자리가 다시 빈 면이 된다.

그리고 **기록 파편 탭에는 세울 피사체가 아예 없다.** 모든 탭이 같은 패널 기하를 써야 재건
없이 탭이 바뀌는데(방어 사령부 §1-②), 한쪽 탭에서 개구부가 빌 것이므로 조건이 깨진다.

→ 패널 둘 다 `variant: 'slab'`. 배경 `windows: []`. 초상은 상세 열 안의 **파낸 챔버**에
   176px 로 앉는다(원본 128 대비 1.4배 — 형제 화면들의 목록 썸네일과 같은 배율대).

### ② 팝업을 없애고 **2열 목록/상세**로 간다

옛 구현은 파일럿 파일 행을 누르면 `makePilotFileModal`(나무 팝업)이 떴다. 2열로 바꾸면:

- 상세 열이 **행을 바꿀 때마다 바뀌는 자리**가 되어 두 탭 모두 오른쪽이 비지 않는다.
- 팝업 암막 알파를 실측할 일도, 캔버스 위 DOM 을 걷어낼 일도 없어진다(이 화면에는 팝업이 0).
- 기록 파편 본문이 목록 행 안에서 세로로 늘어나던 **가변 행 높이**가 사라진다
  (옛 구현은 본문 길이로 행 높이를 재서 쌓았다 — 높이를 역산할 수 없는 구조였다).

⚠️ `makePilotFileModal`(`storyModal.ts`)의 소비처는 **이 화면 하나뿐**이다(챔피언 선택은
2026-08-02 전환에서 사연을 이 화면으로 넘기고 호출을 지웠다 — 파일 헤더 주석만 남아 있다).
그래서 이 레인에서 `storyModal.ts` 를 **삭제**하고 `tests/modalTitleBand.test.ts` 의
"파일럿 파일 팝업 기하" 블록도 함께 지운다(같은 파일의 **`makeModal` 밴드 계약 블록은
남긴다** — 나무 팝업을 쓰는 화면 다섯의 회귀 가드다).

### ③ **프롤로그 탭을 없앤다** — 탭 하나 전체가 버튼 하나였다

옛 프롤로그 탭의 내용은 안내 한 문단 + `[프롤로그 다시 보기]` 버튼이 전부라, 1400×760 패널이
그것만을 위해 존재했다. 방어 사령부가 같은 형태의 `모듈` 탭을 없애고 진입점을 관련 블록으로
옮긴 것(탭 5→4)과 **같은 판단**이다.

→ 탭 **3 → 2**(파일럿 파일 · 기록 파편). `[프롤로그 다시 보기]`는 **하단 액션 띠**로 내려
   상시 표시한다. 안내 문단(`intro.records.body`)은 인트로 슬라이드 본인이 이미 말하므로
   여기서 다시 쓰지 않는다(문구 키는 인트로가 계속 쓰므로 카탈로그에 그대로 남는다).
   `onReplayIntro` 콜백 계약은 한 줄도 바뀌지 않는다.

### ④ 열을 고정한다 — **두 탭이 같은 패널 사각형 둘**을 쓴다

패널 2장(목록 720 · 상세 1108)을 `buildChrome()` 에서 한 번 세우고 탭 전환은 host 안 내용만
갈아끼운다. 탭마다 패널 배치가 다르면 전환할 때 배경과 석재가 통째로 다시 **구워진다**.

⚠️ 패널 제목은 탭에 따라 갈리지 않는다 — 각인 제목은 패널 텍스처에 **구워지므로** 상태에
따라 바뀌면 재건이 필요해진다. 제목은 `기록 목록` · `열람` 둘로 고정하고, 어느 탭인지는
탭 줄이 이미 말한다(방어 사령부가 `배치 슬롯` 제목 하나로 세 레이어를 덮은 것과 같은 처방).

### ⑤ 빈 자리를 남기지 않는다 — 잠긴 파편은 **불 꺼진 소켓**이다

- 목록이 짧으면 `fillRowHeights` 로 행이 남는 세로를 나눠 갖는다(파일럿 7행 · 파편 8행 —
  둘 다 상한 전에 영역을 채운다. 잔여는 행 수 미만이고 테스트가 등호로 잠근다).
- **기록 파편은 대부분 잠긴 상태가 정상이다**(에코 신호로만 열린다). 잠긴 행은 볼록한
  `rowPlate` 가 아니라 **파낸 소켓**(`recessedWell`)으로 그린다 — "잠겨 있다"를 조명 부호가
  말한다. ⚠️ **`?` 글리프는 얹지 않는다**: 관제탑에서 잠금 표식으로 `?` 를 크게 찍었더니
  화면에서 가장 튀는 물체가 됐다(사용자 신고 2026-08-03). 몇 개가 열렸는지는 **탭 줄 오른쪽의
  `n / N` 진행 문구**가 말한다.
- 상세 열은 **진입 시 첫 항목이 이미 선택돼 있어** 원리적으로 비지 않는다. 그래도 방어적으로
  `emptyWell` 경로를 남긴다.
- 파편 본문 챔버는 상자 바닥까지 내려간다 — 짧은 본문은 챔버 **세로 가운데**에 앉는다
  (`emptyWell` 과 같은 처방: 빈 면이 아니라 "이름 있는 자리").

⚠️ **`fillRowHeights` 는 늘려만 주고 줄여 주지 않는다.** 자연 높이가 상한을 넘으면 패널을
뚫는데 예외도 로그도 없다 — 사연 챕터 셋은 본문 길이에 따라 넘칠 수 있으므로 **스크롤을
붙인다**(휠은 클립 Container 가 받는다).

### ⑥ 헤더에 **재화 칩을 두지 않는다**

이 화면은 크레딧·광물을 쓰지 않는다. 형제 화면의 칩 x(1424/1628)는 재화를 쓰는 화면의
어휘이고, 안 쓰는 화면에 얹는 것은 "그 화면의 결정을 돕지 않는 진입점"이다(§0-bis).
헤더는 각인 제목(중앙) + 닫기 ✕(x 1832) 둘뿐이다. 옛 부제(`archive.subtitle`)는 헤더에서
내려 **하단 띠 왼쪽의 쉬는 문구**로 재사용한다(관제탑 §1-⑤ 와 같은 이동).

## 2. 레이아웃 (디자인 스페이스 1920×1080)

여백 어휘(32 / 28 / 20 / 하단 28)와 헤더 높이 104 는 형제 화면과 **같은 값**이다.

| 요소 | x | y | w | h |
| --- | --- | --- | --- | --- |
| 헤더 밴드(배경 노출) | 0 | 0 | 1920 | 104 |
| 탭 1 · 2 | 32 / 398 | 124 | 354 | 56 |
| 진행 문구(우측 정렬) | ..1888 | 124 | — | 56 |
| 목록 패널 | 32 | 196 | 720 | 776 |
| 상세 패널 | 780 | 196 | 1108 | 776 |
| 하단 액션 띠 | 32 | 988 | 1856 | 64 |

전부 파생이다 — `TAB_Y = GEAR_BAND_H + 4`(**헤더 104 아래가 아니다**: 첫 탭이 x 32 라 설정
톱니 예약 밴드와 가로로 겹치므로 세로로 120 아래여야 한다) · `PANEL_Y = TAB_Y + TAB_H + 16` ·
`FOOT_Y = 1080 − 28 − 64` · `PANEL_H = FOOT_Y − 16 − PANEL_Y` ·
`DETAIL_W = 1920 − 32 − DETAIL_X` · `TAB_W = floor((LIST_W − TAB_GAP) / 2)`.
우변 `780 + 1108 = 1888 = 1920 − 32` ✓ · `32 + 354 + 12 + 354 = 752 ≤ 32 + 720` ✓

헤더 컨트롤(전부 y 26 · h 52): 닫기 ✕ x 1832 w 56. 좌측은 **비워 둔다**(톱니 예약 밴드).
제목 대역은 중앙 ±280(`TITLE_BAND_HALF_W`) — 중앙 정렬 Text 는 사각형이 없어 겹침 테스트가
못 잡으므로 상수로 못 박는다.

### 패널 안(패널 로컬, 제목 띠 있는 슬래브: box = x24 · y68 · w W−48 · h H−92)

- 목록 box = 672×684 · 상세 box = 1060×684.
- **파일럿 행**: 자연 높이 84(상한 132). 초상 썸네일 64 · 이름 20 · 태그라인 14 ·
  우측에 해금 `n / 3`. 글자 폭 = `672 − 88 − 96`.
- **파편 행**: 자연 높이 72(상한 120). 해금 = `rowPlate`(볼록) · 잠금 = `recessedWell`(파임).
- **상세(파일럿)**: 초상 챔버 200 정사각 + 오른쪽 이름·태그라인·해금 수 → 아래 **챕터 3장**이
  남는 세로를 나눠 갖고 넘치면 스크롤.
- **상세(파편)**: 제목 챔버 72 → 본문 챔버가 **상자 바닥까지**. 짧으면 세로 가운데.

### 하단 액션 띠

`[프롤로그 다시 보기 320]` 을 **오른쪽 끝(1888)에 몰고**, 왼쪽 1504px 에는 부제/상태 문구가
앉는다. 띠 안에 빈 자리가 없다.

### 팝업 — **없다**(§1-②). 암막 알파도, 캔버스 위 DOM 도 이 화면엔 없다.

**복제하고 헤더에 출처를 밝힌다** — 그 파일들은 공용 모듈이 아니라 화면이다.

## 4. 재렌더 규율

현재 구현은 `render()` 가 루트를 통째로 지우고 다시 그린다(wipe-then-rebuild). 그대로 두면
탭 전환 한 번, 행 클릭 한 번마다 **배경과 석재 패널이 다시 구워진다**.

- `buildChrome()` — 배경 · 패널 2장 · 헤더 · 탭 줄 · 하단 띠는 **한 번만**. 자산 도착 시 1회 재건.
  ⚠️ **크롬(헤더·탭·하단 띠)은 패널보다 뒤에 붙인다**(§5-1).
- `syncValues()` — 탭 활성 링/알파 · 진행 문구 · 하단 부제.
- `renderList()` / `renderDetail()` — 각자 host 안에서만.
- `update(dt)`: **`main.ts` 가 매 프레임 부른다**(`recordsArchive.update(frame)` 를
  `controlTower.update(frame)` 바로 옆에 배선). 숨겨져 있으면 즉시 반환.
  ⚠️ 연구소가 이 배선을 빠뜨려 배경·패널 연출이 통째로 멈춘 적이 있다.

## 5. 기능 불변식 — 깨면 즉시 불합격

1. ⚠️ **크롬은 패널보다 뒤에 붙인다.** Pixi v8 은 자식을 역순으로 훑다가 픽셀에 걸리면 거기서
   멈추고 가장 가까운 상호작용 조상을 반환한다 — 그림자 스프라이트가 `passive` 여도 탐색은
   끝난다. 석재 패널은 접지 그림자·글로우를 텍스처에 구워 **자기 사각보다 30px 가까이 번지므로**
   탭이 패널보다 먼저 붙으면 아래 절반이 클릭 불가가 된다(방어 사령부 실제 신고).
   여백으로는 못 푼다. **소스 조립 순서를 테스트가 잠근다.**
2. ⚠️ **흐림(미선택 0.72)은 `PixiButton` container 에 걸지 마라** — `pointerout` 이 alpha 를 1로
   되돌려 스쳐 지나가기만 해도 영영 풀린다. 감싸는 host 에 걸고, host 가 판 전체
   `hitArea` + `pointertap` 을 받으며 버튼에는 `stopRowPropagation`.
3. ⚠️ **`setEnabled(false)` + `gold` 톤 금지.** 이 화면에 비활성이 될 수 있는 버튼은 없다.
4. **`show()`/`hide()`/`visible` 공개 인터페이스와 `RecordsArchiveCallbacks`(`onBack` ·
   `onReplayIntro`) 를 바꾸지 않는다** — `main.ts:806 openArchive()` 가 그대로 쓴다.
   **suspend/resume 은 없다**(show/onBack 규약).
5. **`onReplayIntro` 왕복 계약**: 인트로는 보관소 **위 오버레이**로 뜨고 끝나면 `openArchive()`
   가 화면을 다시 세운다. `show()` 가 탭·선택·스크롤을 초기화하는 거동을 유지한다.
6. **`hide()` 는 콜백과 프로필 참조를 비운다.** `back()`/`replayIntro()` 는 `hide()` **전에**
   콜백을 캡처한다(관제탑 §5-5 와 같은 순서 계약).
7. ⚠️ 진입 시 런 HUD 숨김 · 닫을 때 **원래 값 복원**(`hudPrevVisibility`). 옛 구현은 무조건
   `visibility = ''` 로 되살렸다. `hudEl()` 에 캔버스 가드를 붙이지 않는다.
8. **휠 스크롤은 클립 Container 에**(마스크 Graphics 는 히트 테스트 제외). **행 클릭은 행
   Container 에**(바탕 Graphics 에 걸면 위 텍스트가 삼킨다).
9. **수집 판정은 `profile.collectedShards` 를 읽는다**(Phase E 에서 정식 필드가 됐다 —
   `src/save/profile.ts:186`). 해금 판정은 `storyUnlock`(=`src/save/storyProgress.ts`)이 소유하고
   이 화면은 읽기만 한다.
10. **`raise()`** — `show()` 에서 root 를 stage 최상위로 올리는 거동을 유지한다.
