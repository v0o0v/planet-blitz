# 격납고 카툰 UI 파일럿 계획

2026-07-19 grill-with-docs 인터뷰 합의. 게임 메타 UI를 카툰풍으로 리스킨하는 첫 파일럿 —
격납고(InventoryOverlay) 한 화면을 대상으로 하고, 평가 게이트 통과 시 다른 화면으로 확산한다.

## 결정 사항 (인터뷰 확정)

| # | 갈림길 | 결정 |
|---|--------|------|
| 1 | 아트 스타일 | **픽셀아트 카툰** — 참조 이미지(나무 프레임·금색 별·광택 버튼 무드)를 PixelLab로 픽셀아트 재해석. 참조 이미지는 무드 보드로만 사용 |
| 2 | 고정 배치 구현 | **Pixi 캔버스 안으로 이관** — 기존 1920×1080 디자인 스페이스 + 레터박스 정수배 스케일(src/render/app.ts)을 그대로 탐 |
| 3 | 이관 범위 | **격납고 파일럿 후 결정** — 패널·버튼·그리드·툴팁을 재사용 가능한 공용 모듈로 설계. 확산 여부는 평가 게이트에서 |
| 4 | 자산 구성 | **9-slice 부품 킷** — 나무 패널 프레임, 버튼(기본/hover/disabled), 슬롯 셀, 타이틀 바, 아이콘. Pixi NineSliceSprite로 확장 |
| 5 | 기체 이미지 | **쇼케이스 일러스트 신규 생성** — 격납고 전시용 대형(128~192px). 현재 활성 기체 타입부터 1장, 타입 추가 시 확장 |
| 6 | 잔여 요소 배치 | **타이틀바 + 패널 부착** — 상단 중앙 타이틀바(제목·재화·닫기 X), 일괄 분해는 인벤토리 패널 하단, 창고 확장은 창고 패널 하단 |
| 7 | 스탯 상세 | **인라인 상시 표기 + 숨은 스탯 추가** — 기존 10개 각 행 아래 1줄 설명, 원소 강도(화염·냉기·번개, 0이면 숨김)·계보 기체 보너스·유니크 효과 목록 추가 |
| 8 | 툴팁 | **전부 유지** — 등급 색 프레임 + 어픽스 목록 + 장착 장비 비교를 Pixi 툴팁 패널로 재구현 |
| 9 | 등급 색 문법 | **유지** — 노말 회백 / 매직 파랑 / 레어 노랑 / 유니크 주황 (파밍 시각 언어 보존) |
| 10 | 평가 게이트 | **스크린샷 비교 선행** — 구현 전 목업(자산 샘플 합성 레이아웃 시안)을 먼저 보여주고 승인 후 구현 착수. 구현 후 사용자 직접 플레이 판정 |

## 레이아웃 사양 (1920×1080 디자인 스페이스, 고정 좌표)

```
┌──────────────────────────────────────────────────────┐
│           [타이틀바: 격납고 · 크레딧 · 광물 · ✕]           │
├───────────────────────┬──────────────────────────────┤
│ 좌상: 스탯 패널          │ 우상: 기체 쇼케이스               │
│  - 스탯 행 + 1줄 설명    │  - 대형 기체 일러스트              │
│  - 원소·계보·유니크      │  - 장착 8슬롯이 기체 부위와          │
│    (조건부 표시)         │    연결선으로 이어짐                │
├───────────────────────┼──────────────────────────────┤
│ 좌하: 창고 (96칸)        │ 우하: 인벤토리 (48칸)             │
│  - 스크롤 그리드         │  - 8열 그리드                    │
│  [창고 확장 버튼]        │  [일괄 분해 버튼]                 │
└───────────────────────┴──────────────────────────────┘
```

- 장착 슬롯 8칸(주무기·보조무기·장갑·실드·엔진·코어·모듈×2)은 기체 일러스트 주변에 배치하고,
  각 슬롯에서 기체의 해당 부위로 연결선을 그린다("비행기 장비" 느낌).
- 창고 96칸은 Pixi 마스크 스크롤 컨테이너.
- 어느 해상도든 레이아웃 불변 — 레터박스 스케일만 달라진다.

## 단계

1. **PixelLab 자산 생성** — 9-slice 부품 킷 + 기체 쇼케이스 일러스트.
   - 생성분은 같은 세션에서 pixellab-forge 리포 `library/` 동기화까지 완료(전역 규칙).
2. **목업 시안** — 생성 자산을 합성한 격납고 레이아웃 이미지 1장.
   - 로컬 http 서버로 서빙해 사용자 브라우저 탭으로 확인(전역 규칙 — SendUserFile 금지).
   - **승인 게이트**: 사용자 승인 전 구현 착수 금지.
3. **공용 UI 모듈 구현** — `src/ui/pixi/` (가칭): NineSlice 패널, 버튼, 슬롯 그리드, 툴팁, 타이틀바.
4. **격납고 재구축** — InventoryOverlay와 기능 동등(장착/해제·분해·확장·툴팁·비교·스탯) + 신규(연결선·상세 스탯).
5. **검증** — vitest 통과 + 기능 동등성 수동 확인 + 사용자 직접 플레이 판정.
6. **확산 결정 게이트** — 통과 시: 다른 메타 화면 순차 이관 + "메타 UI DOM→Pixi 이관" ADR 작성
   (되돌리기 비쌈 · 미래 독자가 의아해할 결정 · 실제 트레이드오프 — 3조건 충족).

## 참고 좌표

- 현재 격납고: `src/ui/inventory.ts` (483줄, DOM, 반응형 flex-wrap)

- 기존 기체 스프라이트: `assets/player.png`, forge 라이브러리 `pb_ship_fighter_cyan`
- 인게임 텍스처 로더: `src/render/textures.ts` (`assets/*.png` glob — UI 킷도 동일 경로 사용 가능)
