## 0. 배경·목표

- **문제 1 (지루함)**: 침략 대상 행성 4개가 등장 몹·보스만 다르고 플레이 스타일이 동일(무한 스크롤 아레나 서바이벌)하다.
- **문제 2 (베제)**: 행성별 `dropTable`이 심층 행성일수록 상향되는 사다리라, 최고 행성만 파는 게 최적이고 나머지 행성이 베제된다.
- **목표**: ① 행성마다 플레이 스타일을 크게 차별화 ② 어떤 행성도 베제되지 않고 침략 필요성이 존재 ③ 난이도를 3티어에서 무한 단계로.

## 1. 행성 모드 프레임워크

**행성 모드** = 공통 아레나 서바이벌 코어 위에 얹히는 행성별 게임플레이 규칙 세트. (용어 정의는 `CONTEXT.md` 참조.)

| 구분 | 축 | 전 행성 |
|---|---|---|
| **불변** | 기체 8방향 이동·자동공격·판정점·런 내 파워업 3택·드랍/자원 획득 | 동일 |
| **가변** | 카메라·강제 스크롤·지형·적 배치·진행 게이트·실패 경계 | 모드별 |

- **진행 게이트**: 런이 다음 구간·보스로 나아가는 조건. 모드마다 형태가 다르되(처치 할당 / 스크롤 완료 / 코스 통과 / 대피소 도달) "강하면 빨리 통과"의 창발 난이도 철학은 공유(전멸 가속과 동형).
- **보스 종착점 공통**: 모든 모드는 최종적으로 보스 처치로 완주한다. 파밍의 핵심 보상(보스 확정 드랍)이 전 모드 일관.
- **모드 보정 파워업**: 모드 정체성은 영구 스탯 축이 아니라 런 내 3택 파워업 풀에 섞이는 소수의 모드 문맥 선택지로 표현(임시, 런 종료 시 소멸 → 아이템 베제 0).

## 2. 6개 모드 상세

### 모드-행성 배정 (확정 2026-07-22)

| 행성 | 배정 모드 | 근거 |
|---|---|---|
| 카르곤 (첫 행성) | 뱀서류 | 기본 모드 온보딩 — 신규 유저가 코어 조작 선학습 |
| 베르단 | 수축 지대 | 곤충 군체 물량 = 공간 압박 |
| 니플헤임 | 추격·탈출 | 유령 기함 = 포식자, 서리 안개 = 시야 제한 |
| 아르케 | 레이싱 | 기계 정밀·속도 |
| 톡사르 (신규) | 오염 확산 | 독성 늪지 — 부식·중독 설계도 테마 |
| 크라스 (신규) | 블록격파 | 소행성대 — 파괴·관통 설계도 테마 |

기존 4행성은 로스터·보스·특산을 유지한 채 모드만 덧입힌다. 신규 2행성 세부(이름·테마·로스터·보스·특산·설계도 테마)는 §7 참조.

### 2.1 뱀서류 (현행)
- 카메라: 무한 스크롤 자유추적(현행 그대로). 진행 게이트: 처치 할당. 실패: 사망. 보스: 웨이브 후 등장.
- 재설계 영향 없음(기준 모드). 다른 모드의 "공통 코어" 정의가 곧 이 모드다.

### 2.2 블록격파
- 카메라/스크롤: **하→상 강제 종스크롤**(`scroll.ts`의 `−Y` 축 재사용, 침공 L1과 동일 방향).
- 블록 = **하이브리드**: 상단에서 내려오는 파괴가능 벽(`wall` kind 재사용, 파괴가능 서브타입 추가) + 그 뒤/안에 숨은 적. 벽을 자동공격으로 부수면 적이 드러난다.
- 진행 게이트: 구간 벽 돌파. 보스: 최상단.
- 실패·경계: `clampToWindow`로 창에 가두고, **못 부순 벽과 화면 하단 경계 사이 끼임 = 압사 누적 피해**(M7c 압축 프레스의 sticky side/되밀기 없음 로직 재사용). 즉사 아님 → 격추 시 런 실패.
- 레퍼런스 느낌: "ball x pit / 블록격파".

### 2.3 레이싱
- 카메라/스크롤: **좌→우 강제 횡스크롤 페이스메이커**(`scroll.ts`의 `+X` 축 재사용, 침공 L2와 동일 방향). 스크롤 속도 = 최소 요구 속도.
- 경쟁 상대: **없음**(유령/AI 레이서 도입하지 않음 → 결정론 간단). 앞서 나가면(체크포인트·적을 빨리 처리) 전멸 가속처럼 보너스.
- 레이싱다움: **트랙 부스트 패드 지형 + 모드 보정 파워업(순간 가속)**으로 살린다.
- 진행 게이트: 체크포인트 통과. 보스: 코스 끝.
- 실패·경계: `clampToWindow` + **뒤 경계 압박존 지속 피해**(블록격파와 대칭). 즉사 아님.

### 2.4 추격·탈출
- 카메라: 자유추적 + **시야 제한**(암흑, 레이더 의존도 급등). 강제 스크롤 없음.
- 포식자: **무적 1체가 끝없이 추격**. 도주 내내 무적이라 **자동공격은 잡몹·자원 획득에만 유효**(자동공격과 도주가 시간축으로 분리 → "따로 노는" 문제 해소).
- 진행 게이트: 대피소 도달. 실패: 포식자 접촉.
- 보스: **포식자 = 최종 보스**. 대피소들을 거쳐 마지막 구간에서 "반격 조건"이 열리면 무적 해제 → 포식자 처치 = 보스전.

### 2.5 수축 지대
- 카메라/맵: **유한 원형 아레나**(고정 경계) + 내부 안전 원. 배틀로얄식. 맵 경계·카메라 클램프 인프라는 신규(무한 월드와 다름).
- 안전 원: **처치 기반 수축** — 현재 링의 적을 전멸하면 다음 수축까지 여유·보너스(전멸 가속 철학 일관), 못 하면 수축이 압박. 진행 게이트 = 각 링 전멸.
- 안전 원 밖: 지속 피해(자기장). 실패: 밖 피해 누적 사망. 보스: 마지막 최소 지대에서.
- 차별축: **공간 압박·포지셔닝** — 기존 모드에 없는 유일한 축.

### 2.6 오염 확산
- 지형: 파괴가능 **오염 노드가 실시간 확산**(정수 상태). 오염 지형을 밟으면 지속 피해, 확산하면 안전공간↓.
- 억제: **노드 파괴로 확산 억제**(능동 방어). 진행 게이트 = 정화율 달성. 보스: 오염원 본체(코어급).
- 실패: **맵 임계 오염**(확산 못 막음) + 기체 사망.
- 차별축: **표적 우선순위·역방어** — 수축 지대(못 막는 강제 압박)와 달리 능동적으로 억제 가능.

## 3. 침략 단계 시스템 (구 난이도 티어)

- **정의**: 행성별 독립 무한 정수 축(1부터 상한 없음). 구 3티어(정찰/교전/섬멸) 대체.
- **개방 규칙**: 도전 가능 상한 = `max(10, 그 행성 최고 클리어 단계 + 5)`. 초기 1~10 개방. 행성마다 최고 클리어 단계를 따로 추적.
- **기체 레벨**: 잠그지 않는 **순수 앵커**(기체 Lv50 ≈ 단계 50). 구 `ANNIHILATION_UNLOCK_LEVEL=60` 게이트 폐지 — 개방은 오직 클리어 기반.
- **난이도 상승 구조**: **연속 수치 + 구간 마일스톤**. HP·밀도·드랍은 단계마다 연속 상향(수치), 정한 구간 경계(예: 10·20·30단계)에서 질적 요소 해금(구 정찰/교전/섬멸의 엘리트 어픽스·패턴 변형·엘리트 증원을 구간에 재배치).
- **베제 방지 (품질⟂종류 직교)**:
  - 품질 축 = 침략 단계: rarity·아이템레벨 스케일(전 행성 동일 공식).
  - 종류 축 = 행성: 특산 광물·행성 전용 어픽스풀/유니크/방어체 테마·모드별 고유 보상 독점.
  - 프리미엄: 각 행성 간판 최상급 종류에만 그 행성 고단계 문턱.
  - 구 `dropTable` 심층 사다리 폐기.

## 4. 아이템·스킬 영향

- **영구 축 불변**: 새 스탯 축(시야·레이더 사거리·부스터 등)을 만들지 않는다. 모든 기존 아이템·스킬이 전 모드에서 유효(아이템 베제 0).
- **모드 보정 파워업**: 런 내 3택 파워업 풀에 모드 문맥 선택지를 소수 섞는다(추격=순간 가속, 블록격파=상방 광역화, 레이싱=부스트 연장 등). 임시.
- **모드별 기존 스탯 상대 가치**(밸런스 = 출시 전 튜닝): 추격=이동·회피↑, 레이싱=이동↑, 블록격파=전방 화력·관통↑. 수치가 아니라 밸런스 패스에서 조율.

## 5. 코드 접점 (Explore 2026-07-22 기반)

- **런 분기**: `src/run/runConfig.ts` `buildRunConfig` 단일 정본. 현재 `invasion3` 유무로 PvE/침공 분기 → **행성 모드 분기를 `WorldConfig`에 실어 sim에서 분기**(기존 패턴: `state.config.planet`을 `src/sim/waves.ts`·`patterns/index.ts`에서 읽음).
- **강제 스크롤 재사용**: `src/sim/invasion/scroll.ts`(정수 스크롤·`clampToWindow`·`windowCenterX/Y`·전멸 가속). 블록격파=`−Y`, 레이싱=`+X`. PvE 카메라(현재 `snapshot.ts`에서 플레이어 추적 파생)에 스크롤 모드 예외 배선.
- **끼임/압사**: M7c 압축 프레스(`wall` kind, sticky side, 상대 프레임 스윕). 블록격파·레이싱 경계 압박에 재사용.
- **난이도**: `data/waves.ts` `TIER_PARAMS`·`canEnterTier` 폐지 → 단계 함수 + 마일스톤 테이블. `src/sim/drops.ts` `tier>=1` 게이트 → 단계 함수.
- **드랍 종류/품질 분리**: `data/planets/index.ts` `dropTable` 사다리 폐기, `data/planets/blueprints.ts` 테마 축(종류)은 유지.
- **세이브**: 행성별 최고 클리어 단계 벡터 추가(SAVE_VERSION 증가). 서버 `profiles.save` jsonb 읽기 경로 영향 점검(현재 credits·minerals만 읽음).
- **UI**: `src/ui/planetSelect.ts`·`src/ui/pixi/planetSelect.ts` 티어 3버튼 → 침략 단계 선택(개방 상한까지). `data/planets.ts` `TIERS` 폐지.
- **결정론**: 모든 모드가 ADR-0005 결정론 규율 안에서 sim 틱 함수로 구현(리플레이 검증 재사용). 강제 스크롤·시야는 렌더가 아니라 sim 권위 상태.

## 6. 구현 레인 (순서·분해 초안)

1. **침략 단계 코어** (모드 독립, 선행): `TIER_PARAMS`→단계 함수·마일스톤 테이블, 개방 규칙, 세이브 스키마, 드랍 품질⟂종류 분리, UI 단계 선택. 골든/결정론 회귀 유지.
2. **행성 모드 프레임워크**: `WorldConfig`에 모드 필드, sim 분기 골격, 모드 보정 파워업 훅. 뱀서류=기본 경로가 회귀 없이 통과하는지 게이트.
3. **스크롤 모드 이식**: `scroll.ts`를 침략에 재사용(블록격파 `−Y`, 레이싱 `+X`), `clampToWindow`·경계 압박(압축 프레스 재사용).
4. **블록격파 콘텐츠**: 파괴가능 `wall` 서브타입, 하이브리드 배치, 구간 돌파 게이트.
5. **레이싱 콘텐츠**: 체크포인트, 부스트 패드 지형, 앞지르기 보너스.
6. **추격·탈출**: 무적 포식자 AI(결정론), 시야 제한 렌더+레이더 강조, 대피소 게이트, 반격창 보스 전이.
7. **수축 지대**: 유한 원형 아레나 경계·카메라 클램프(신규 인프라), 안전 원 처치 기반 수축, 밖 지속 피해, 최소 지대 보스.
8. **오염 확산**: 오염 지형 확산 sim(정수 상태), 노드 파괴 억제, 정화율 게이트, 임계 오염 실패, 오염원 보스.
9. **아이콘 티어대 재매핑** + 문서(GDD) 갱신.
10. **밸런스 패스**(출시 전 일괄): 스크롤 속도·압박 피해·수축 리듬·오염 확산 속도·단계 배율·구간 경계·모드별 상대 가치.

각 레인은 브랜치→PR→머지(전역 git 규칙). 결정론 골든은 레인 착수 전 녹화.

## 7. 오픈 퀘스천 (미결 — 구현 착수 전 결정 필요)

1. **신규 행성 콘텐츠 세부** (이름·컨셉·테마·모드 확정): **톡사르**(독성 늪지, 오염 확산, 부식·중독 테마)·**크라스**(소행성대, 블록격파, 파괴·관통 테마) 확정. 배정 전체: 카르곤=뱀서류·베르단=수축 지대·니플헤임=추격·탈출·아르케=레이싱·톡사르=오염 확산·크라스=블록격파. 남은 미결은 두 신규 행성의 **로스터(잡몹 4역할: 돌격·사수·특수·지원)·엘리트 2종·보스·특산 광물 2종의 구체 명칭**으로, 실제 데이터 작성(구현) 단계에서 채운다. 향후 행성 추가 시 "새 행성 = 새 모드 동반" 규칙 강제 여부도 미결.
2. **침공(PvP)과 행성 모드의 관계**: 침공은 `planet:0, tier:0` 고정에 3레이어 무대다. 블록격파 행성을 "침공"하면? 침공은 행성 모드와 무관(항상 3레이어)한지, 아니면 방어 대상 행성 모드가 침공 무대에 반영되는지. **잠정: 침공은 행성 모드 무관(3레이어 고정)** — 확인 필요.
3. **추격 모드 세부**: 시야 제한 방식(암흑 반경? 안개?), 포식자 이동 규칙(추적 속도·경로), 대피소 개수·간격, 반격 조건의 정체.
4. **레이싱 세부**: 트랙 분기(지름길 vs 우회) 유무, 부스트 패드 밀도, 앞지르기 보너스의 형태(자원? 파워업?).
5. **블록격파 세부**: 벽 내구/밀도, 압사 피해 곡선, 벽 뒤 적의 스폰 규칙.
6. **아이콘 티어대**: 3티어(저/중/고) → 침략 단계 구간 매핑 방식.
7. **기존 행성 콘텐츠 재사용**: 4행성의 로스터·보스·드랍 테마를 새 모드에 어떻게 얹나(몹은 유지, 모드만 덧입힘?).

### 7-R. 해소 기록 (2026-07-23 사용자 확정 — 구현 계승)

Lane 2·3 머지 후 사용자에게 일괄 확인해 아래를 확정했다. 계수(속도·피해·리듬 등)는 여전히 **밸런스 = 출시 전 일괄 튜닝**이라 여기서 정하지 않는다.

- **#2 침공×행성 모드 (확정)**: 침공은 **행성 모드 무관** — 항상 3레이어 무대(`planet:0`·`stage:1`·`planetMode` 미지정). Lane 2·3 이 그대로 구현됨(침공 두 경로 planet 0 → mode 0 → 스크롤/모드 폴드 미실행 → `verify-invasion` 무영향). 잠정 → **확정**.
- **#4 레이싱 트랙 (Lane 5)**: **분기 트랙(지름길 vs 우회)** 채택. 갈림길에서 지름길/안전 우회를 선택. 결정론·맵 데이터·검증 복잡도가 단일 트랙보다 크므로 리플레이 결정론(ADR-0005)에 트랙 분기 선택이 sim 정수 상태로 봉인되게 설계. 부스트 패드·앞지르기 보너스 형태는 밸런스/구현 단계.
- **#3 추격 반격 (Lane 6)**: 무적 포식자는 **맵의 반격 장치 파괴**로 취약화 → 보스전 전이. (대피소 전부 경유 후 자동 취약도, 생존 임계도 아님.) 반격 장치는 파괴 가능 오브젝트(정수 상태)로 sim 에 구현. 시야 제한 방식(암흑/안개)·포식자 이동 규칙·대피소 개수는 구현 단계에서(시야는 sim 정수 상태, 렌더 아님 — ADR-0005).
- **#6 아이콘 티어대 (Lane 10)**: 침략 단계를 **5구간 25/50/75/100/100+** 경계로 재매핑(기체 레벨 앵커 정렬 — 기체 Lv≈단계, Lv50≈단계50). 즉 저=1~24·중=25~49·상=50~74·최상=75~99·초월=100+. 현 3티어(저/중/고) → **5구간으로 확장**. STAGE_MILESTONES(1/11/21) 밴드와는 별개 축(밀도 마일스톤 ≠ 아이콘 티어대). 아이콘 자산·매핑 규칙(ADR-0015·0016 계열)을 5구간으로 갱신.
- **#1 신규 2행성 명칭 (Lane 9)**: **내가(구현측) 기존 컨벤션대로 생성 후 바로 진행**(사후 조정 가능). 톡사르(독성 늪지·오염)·크라스(소행성대·블록격파)의 로스터(4역할)·엘리트 2·보스·특산 광물 2 명칭을 카르곤(흑요석 파편·용암정)·베르단(경화 키틴·여왕 젤리) 식 한글 컨벤션으로 명명. "새 행성 = 새 모드 동반" 정책 강제 여부는 여전히 미결(당장 불필요).
- **#5 블록격파 세부 / #7 기존 콘텐츠 재사용**: 구조는 기획서대로(파괴가능 wall 서브타입·하이브리드 배치 / 몹·보스·특산 유지하고 모드만 덧입힘), 수치는 밸런스. 별도 사용자 결정 불요.
