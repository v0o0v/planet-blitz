# 침공 3레이어 대개편 + 기체 챔피언화 기획서

- 작성: 2026-07-20 그릴링 세션 (grill-with-docs)
- 근거 문서: ADR-0017(3레이어 단일 런), ADR-0018(방어체 경제·카드 폐지), ADR-0019(기체 완전 고유 트리), CONTEXT.md 용어집(같은 세션에서 갱신)
- 전제: **미출시 상태 — 기존 침공 자산(단일 아레나·포탑 6종·배치 포인트·카드 UI)의 유저 자산 보존은 고려하지 않는다.** 재활용 대상은 기술 인프라(sim 코어·결정론 리플레이 검증·엔티티/충돌·수호 기체 생애주기)다.

---

## 1. 목표

침공을 "3분 단일 아레나 코어 러시"에서 **3중 방어선을 뚫는 5분 원정**으로 재설계해 엔드게임 긴장 곡선을 만들고, 방어 준비를 **수집·강화 도파민이 있는 디펜스 게임**으로 만든다. 별도 마일스톤으로 **기체 챔피언화**(타입별 완전 고유 트리)를 얹어 "고르고 분석하는 재미"를 추가한다.

## 3. 침공 런 상세 흐름

### 레이어 1 — 외곽 돌파 (아래→위 종스크롤, ~90초)
- 연출: 행성 외곽 대기권/궤도에서 기지로 강하. 행성 표면이 아래로 흐른다.
- 웨이브 슬롯 6개(제안값). 각 슬롯에 방어자의 편대 1개. 빈 슬롯은 기본 수비대.
- 편대는 진형(V자·횡대·포위 등)과 공격 패턴을 내장 — 방어자는 순서 배치만.
- 전멸 가속: 현재 웨이브 전멸 시 다음 웨이브 등장 지점까지 스크롤 가속.
- 슬롯 순서의 전략: 약한 편대로 공격자 자원(체력·폭탄)을 빼놓고 강한 편대를 후반에.

### 레이어 2 — 내부 회랑 (좌→우 횡스크롤, ~90초)
- 연출: 격벽이 열리며 기지 내부 회랑 진입. 상·하 벽 사이를 전진(톱다운).
- 맵 템플릿 3종(제안): 직선형(소켓 많음·엄폐 없음) / 굴곡형(소켓 보통·사각 있음) / 병목형(소켓 적음·좁은 통로에 화력 집중).
- 설치 소켓 10개 내외(템플릿별 상이). 설비 3갈래를 소켓에 장착.
- 전멸 가속: 현재 화면 구간의 설비·드론 전멸 시 가속. 해저드는 파괴 불가물이면 전멸 판정에서 제외(통과가 답).

### 레이어 3 — 코어 방 (고정 화면, ≤120초)
- 연출: 회랑 끝 대형 격벽이 열리며 넓은 방. 우측 끝에 코어.
- 구성: 방어 보스 슬롯 1 + 수호 기체 슬롯 2 + 기물 소켓 6개 내외 + 코어.
- 코어: HP·자가 방어 패턴(강화로 성장) + 코어 모듈 슬롯(소모성, 구 카드).
- 승리 = 코어 파괴. 패배 = 총 상한 5분 소진 또는 격추.

### 공통 규칙
- 자원 승계: 체력·폭탄 등은 레이어를 관통. 레이어 클리어 시 소량 회복 보너스(수치 미정).
- 레이어 전환: 로딩 없이 연출로 연결(격벽 개방·강하 연출). sim 상으로는 단일 월드의 페이즈 전환.
- 검증: 리플레이 1개 = 침공 1건. verify-invasion 시간 예산 300초×60틱으로 확장.

## 4. 방어체 경제

- **획득**: ① PvE 런 드랍 — 행성별 드랍 테이블에 설계도 편입(엘리트·보스 드랍 중심). 행성마다 특산 방어체를 두면 "이 편대 얻으러 이 행성 파밍" 동기 발생. ② 제작 — 설계도+희귀 광물. 반복 파밍의 천장값. ③ 침공 약탈 복제 — 침공 성공 시 낮은 확률로 상대 배치 방어체 중 1종의 설계도 복제(방어자 무손실, ADR-0003). "저 방어 멋있다 → 뺏으러 간다"의 부러움→행동 전환.
- **강화 3축**: 방어체 레벨(크레딧+희귀 광물, 일일 루틴) / 승급(중복 설계도, 외형 변화 — 과시) / 방어체 어픽스 리롤(희귀 광물, 마감 콘텐츠).
- **정찰·과시**: 대상 선택 화면에서 레이어별 방어체 실루엣·등급 색·승급 별 노출. 유니크 방어 보스가 반짝이는 기지 = 걸어다니는 광고판. 정확 스펙·어픽스는 1회 침공 후 결과 화면에서 해금(재도전 설계 재미).
- **풍화**: 배치분만 정비도 감쇠(정비로 회복), 수호 기체만 회복 불가(바닥 50%). 보관함 수집품은 안전.
- **방어 성공 보상**: 방어체 획득 경로에서 제외(부익부 방지). 보조 재화(크레딧·정비 할인권 수준)만 검토 — 미결 #5.

## 5. 1차 방어체 카탈로그 제안 (밸런스 수치 미정, 컨셉 확정용)

### 편대 (L1) — 8종
| 이름(안) | 컨셉 | 재미 포인트 |
|---|---|---|
| 정찰 드론편대 | 최저가 물량, V자 직진 | 기본 수비대급, 초반 슬롯용 |
| 요격 편대 | 좌우 협공 진입 | 기본 화력 |
| 조류형 활공편대 | 사인 곡선 급강하 | 궤도 읽기 회피 |
| 기뢰 살포선 | 후퇴하며 기뢰 뿌림 | 지역 장악, 스크롤 압박 |
| 실드 호위편대 | 전면 실드기+후방 사수 | 실드부터 깰지 우회할지 |
| 저격 편대 | 화면 상단 고정, 조준선 예고 후 저격 | 긴장 리듬 |
| 강습 돌격편대 | 플레이어 위치로 가속 돌진 | 회피 강요 |
| 전자전 편대 | 격추 전까지 공격자 파워업 1종 봉인 | 우선 격파 판단 |

### 설비 (L2) — 9종
- 방어포 4종: 속사포(탄막 압박) / 관통 레일포(축선 차단, 예고선) / 곡사 박격포(착탄 지점 폭발) / 유도 미사일 포드(요격 가능 미사일)
- 해저드 3종: 레이저 격자(주기 온오프 리듬) / 압축 프레스(통로 협착 타이밍) / 화염 방사구(지속 장판)
- 스포너 2종: 드론 부화기(파괴 전까지 소형 드론 생산) / 수리 벌레 스포너(주변 설비 수리 — 처치 우선순위 뒤틀기)

### 기물 (L3) — 6종
실드 발생기(코어에 보호막 — 먼저 파괴 강제) / 중력 앵커(공격자 이동 감속 필드) / 회복 파일런(보스·수호 기체 회복) / 고정 주포(코어 방 최대 화력) / 기만 홀로그램(가짜 코어 — 첫 침공 정찰 카운터) / 자폭 지뢰군

### 방어 보스 — 3종 (1차)
| 이름(안) | 컨셉 | 유니크 계열 예시 |
|---|---|---|
| 강철 골리앗 | 장갑·근접 압박형 대형 로봇 | "파괴 시 코어 실드 재생" |
| 포자 여왕 | 소환·잠식형 외계 생체 | "체력 50% 이하 시 편대 1개 재소환" |
| 위상 감시자 | 순간이동·탄막형 기계 안구 | "공격자 폭탄 사용 시 카운터 탄막" |

방어 보스도 설계도 파밍(해당 행성 보스 드랍)+승급으로 성장 — "PvE 보스를 잡아 내 보스로 만든다"는 순환이 핵심 도파민.

## 6. 기체 챔피언화 (다음 마일스톤)

### 1차 로스터 컨셉안 — 5종
| 타입(안) | 실루엣 | 시그니처 패시브 | 트리 3계열(안) |
|---|---|---|---|
| 스트라이커(기본) | 표준 전투기 | 연속 처치 시 발사 속도 스택 | 화력 / 기동 / 방어 (현행 트리 재편) |
| 브루저 로보 | 인간형 로봇 | 피격 시 장갑 스택(상한) | 근접 블레이드 / 변형(모드 전환) / 요새화 |
| 비온 심비오트 | 외계 생체 | 처치 시 포자 자충전·소환 | 군체 소환 / 변이(자기 강화) / 잠식(적 약화) |
| 팬텀 코세어 | 스텔스 함 | 일정 시간 무피격 시 은신·기습 배율 | 암살(일점 화력) / 위상(회피·순간이동) / 교란 |
| 아크 캐스터 | 부유 포탑형 | 이동 정지 시 과충전 빔 | 전격 연쇄 / 포격(설치형) / 역장 |
- 고유: 트리+시그니처+스탯 보정+외형 / 공통: 장비 8슬롯·이동·판정점.
- 첫 기체=스트라이커 자동 지급, 퇴역 시 5종 전체에서 자유 선택.
- 수호 기체 AI가 타입 시그니처를 반영하면 방어 로스터 다양성이 저절로 늘어난다(확장 여지).

## 7. 방어 사령부 개편

- 레이어별 편집 탭 3개(L1 웨이브 슬롯 / L2 템플릿+소켓 / L3 보스·수호·기물·코어) + 방어체 보관함 + 모듈 경제(상점·합성) 탭.
- 배치 프리뷰(ADR-0013 정신 계승): 각 레이어를 실제 침공과 동일한 모습으로 미리보기, 가능하면 "시험 침공"(자기 기지 침공 시뮬레이션, 오염 런 규칙 준용) 제공.
- 편집 UI는 카툰나무풍 + Pixi(ADR-0014) 체제 유지.

## 8. 기술 과제

1. **강제 스크롤 sim**: 카메라 진행을 틱 결정 함수로(ADR-0005 규율 — `Math.random`/`Date.now` 금지). 스폰은 스크롤 오프셋 기준. 전멸 가속은 sim 상태(구간 전멸 플래그)로 계산.
2. **레이어 전환**: 단일 `stepWorld` 안의 페이즈 머신(L1→L2→L3). 리플레이 해시 스트림에 페이즈 전환 틱 포함.
3. **verify-invasion 확장**: 시간 예산 300초×60틱, 서버 권위 config에 3레이어 배치(웨이브 슬롯·소켓·보스/수호/기물·코어 모듈) 전체 포함. T0 스냅샷(begin_invasion) 스키마 확장.
4. **DB 스키마**: defenses를 3레이어 구조로 개편, 방어체 인벤토리 테이블(설계도·레벨·승급·어픽스), 드랍 테이블 확장, 기본 수비대 시드 데이터.
5. **NPC 시드 기지(배치전)**: 3레이어 세팅으로 재구성 — 난이도 단계별 기본 수비대+저등급 방어체 조합.
6. **렌더**: 종/횡 스크롤 배경 파이프라인(기존 무한 스크롤 배경 재활용 + 방향 파라미터화), 레이어 전환 연출.

## 9. 마일스톤 분할 (제안)

- **M7a — 침공 코어**: 강제 스크롤 sim + 3레이어 페이즈 머신 + 기본 수비대 + 임시 카탈로그(편대 3·설비 4·기물 3·보스 1) + verify 확장. 목표: 침공 1회가 끝까지 도는 것.
- **M7b — 방어체 경제**: 설계도 드랍·제작·복제 약탈, 강화 3축, 승급 외형, 방어 사령부 개편, 정찰 화면. 카드→코어 모듈 개명·재배선.
- **M7c — 콘텐츠 완충**: 카탈로그 풀 구성(§5), 유니크 방어체, 밸런스 패스, 배치전 재구성.
- **M8 — 기체 챔피언화**: 트리 데이터 타입별 일반화 → 신규 타입 2종 우선 출시 → 로스터 5종 완성. (아트 의존 큼 — pixellab 파이프라인 병행)

## 10. 미결 문제

1. 웨이브 슬롯 6·소켓 10·기물 소켓 6 등 **모든 수치는 제안값** — 밸런스 패스에서 확정.
2. 코어 모듈 슬롯 수(1~3) 미정.
3. 레이어 클리어 회복 보너스 수치·부활/폭탄 규칙 미정.
4. 침공 쿨다운·복수전·래더 스왑 규칙은 기존 유지 가정 — 5분 런 기준 재점검 필요.
5. 방어 성공 보조 보상(재화 수준)의 유무·수치.
6. 편대·설비 카탈로그의 행성별 분배(어느 행성이 뭘 드랍하나).
7. 전멸 가속의 상세(가속 배율 곡선, 해저드 제외 규칙의 예외).
8. L2 경로 분기(상하 갈림길)는 확장 예약 — 도입 시점 미정.
