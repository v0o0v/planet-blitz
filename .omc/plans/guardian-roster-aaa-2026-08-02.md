# 예비역 로스터 AAA 시네마틱 전환 — 레인 계약 (2026-08-02)

타이틀·인트로·기지·격납고·촉매 보관함(PR#236·#238·#240·#245·#246·#247)에 이어 격납고 하위
화면 셋 중 **예비역 수호기 로스터**(`src/ui/pixi/guardianRoster.ts`)를 전환한다.

**시각 정체성 = 시네마틱 전환**(사용자 확정). 나무 nine-slice(`ui_panel.png`)·나무 판때기 버튼
(`ui_btn_*.png`)·나무 배너(`ui_banner.png`)는 이 화면에서 **은퇴**한다. 붓: 페인터리 디지털
페인팅, 금빛 고대 석재, 청록·자홍 성운, 짙은 실루엣, 따뜻한 금색 램프광.

## 0. 절대 규칙 (격납고 §0 · 촉매 보관함 §0 을 그대로 승계)

1. **순수 render/UI 레이어(ADR-0005 · ADR-0014)** — sim 을 읽지도 쓰지도 않는다. 시간축은 벽시계.
2. **품질 티어를 런타임 수렴 상태로 판단하지 마라**(`getActiveTier()` 단독 사용 금지).
3. **띠를 겹쳐 그라디언트를 근사하지 마라.** 1px 겹침이 알파를 두 배로 만들어 가로줄이 생긴다.
   램프는 폭 1px 캔버스에 픽셀로 굽고 `linear` 로 늘린다. ⚠️ `titleScreen.ts` 광선 스윕
   (`slabs = 7`)에 이 결함이 아직 남아 있다 — 복사 금지.
4. **Pixi v8**: `Sprite` 에 자식 금지. `tint` 는 곱연산. 컬러 이모지 금지(`▶ ◀` 는 보존).
5. 자산은 **덧붙임이지 전제가 아니다** — 텍스처가 `undefined` 여도 화면이 서야 한다.
6. 캔버스 없는 환경(vitest)에서 `Text.width`·`document.createElement`·`ColorMatrixFilter`·
   `FillGradient` 가 던진다. 관용구는
   `typeof document === 'undefined' || typeof document.createElement !== 'function'`.
   ⚠️ **캔버스 굽기 함수에만** 붙인다 — `hudEl()` 같은 DOM 조회에 붙이면 HUD 숨김이 죽는다.
7. `npx tsc --noEmit` 0 · `npx eslint src --max-warnings 0`.

## 0-bis. 사용자가 **제거하기로 확정한 것** — 되살리지 마라

격납고에서 AAA 비평이 요구해 구현했다가 **사용자가 화면을 보고 삭제를 지시한 것**들이다.
지표 미달을 이유로 되살리지 마라 — **판정 기준은 스크린샷이고 수치는 대리 지표다.**

- **세로 석재 리브** — 표의 괘선으로 읽혔다.
- **가로 수평 이음선**(전폭 2~3줄)·짧은 코스 파편 — 그리드 사이를 가로지르는 선으로 읽혔다.
- **각인 번호판**(제목 띠 우측 눈금 표식).
- **헤더 각인 석재 인방** — 헤더는 배경이 그대로 보이는 띠로 둔다.
- **함선 도크 크래들**(받침).

남기는 것: 재질과 조명(석재 세로 램프 · 방향성 베벨 3단 · 패널별 조명 · 미세 그레인 · 2단 접지
그림자 · 리벳). 즉 **면 위에 "부품"처럼 얹히는 표식은 넣지 않는다.**

## 1. 이 화면 고유의 판단 셋

### ① 슬래브 패널 + 행인가, 시네마틱 타일(기지 카드)인가 → **슬래브 + 행**

칩이 물은 질문이다. 판단 근거:

- 로스터는 **길이가 무제한**이다(퇴역할 때마다 한 기씩 쌓인다). 카드 격자를 배경 위에 직접
  띄우면 스크롤 클리핑 경계가 배경 위에서 허공에 생겨 잘린 카드가 떠 있는 것처럼 읽힌다.
  목록에는 **담는 그릇**이 필요하다.
- 그릇을 두고 그 안에 `cinematicTile` 을 넣으면 정확히 칩이 경고한 **패널 안의 패널**이 된다.
- 바로 앞 형제 화면(촉매 보관함, PR#247)이 같은 문제를 이미 풀었다 — 슬래브 패널 + `rowPlate`
  (면 밝기 차 + 2단 접지 그림자 + 방향성 램프, **선 없음**). 형제끼리 언어가 갈리면 안 된다.

⇒ 슬래브 패널 안에 행 판을 깐다. 행 판 어휘는 촉매 보관함에서 **복제**하고 출처를 헤더에 남긴다
(계약 §2 "공용 모듈이 아닌 화면 파일의 값은 복제하고 출처를 밝혀라").

### ② 우측 열에 무엇을 두는가 → **선택 수호기 상세(기능 패널)**

촉매 보관함이 창을 뚫었다 뺀 교훈: **창은 "배경이 보이는 구멍"이 아니라 "무언가를 보여주는
자리"다.** 창 안에 초점 피사체가 없으면 뚫을 이유가 없다. 이 화면에도 함선 스프라이트를 놓을
수 있지만(`shipDock.ts`), 예비역은 **기체 타입만 같고 개체가 다른** 것들이라 도크에 세우면 행을
바꿔도 같은 그림이 나오는 자리가 된다. 뚫지 않는다(`windows: []`).

그 자리는 **소멸이 무엇을 되돌려주는지**가 차지한다 — 이 화면이 되돌릴 수 없는 조작 표면이기
때문에 가장 값어치 있는 정보다: 기체 타입 · 남은 성능 · 전투력 · **잠긴 장비 목록(등급색)** ·
회수 포인트 · 경고 문구.

### ③ 소멸 동작은 어디에 두는가 → **행 버튼 유지**(기능 불변)

행 [소멸] 버튼 → 확인 팝업의 흐름을 **그대로 둔다.** 상세 패널은 **읽기 전용**이다. 두 자리에
같은 파괴 버튼을 두면 어느 쪽이 지금 선택된 것인지 모호해진다. 상세 = 정보, 행 버튼 = 실행,
팝업 = 확인.

### 확인 팝업은 이 화면이 자기 것으로 만든다

`makeModal` 은 나무 nine-slice 에 묶여 있고 **다른 화면 5곳이 쓴다** — 고치면 그 화면들이 같이
갈린다. 그래서 시네마틱 팝업은 이 파일 안에 만든다(암막이 뒤 글자를 못 읽게 할 만큼 짙고
(`alpha 0.92` — 0.86 에서는 뒤 화면 제목이 읽혔다) · 암막이 이벤트를 먹음 · 패널 안쪽 탭은
암막까지 전파 차단 — `modal.ts` 헤더의 실측 규칙 3종을 그대로 승계).

**소멸은 되돌릴 수 없다 → 연출보다 가독성이 우선이다.** 팝업 본문·경고는 크림색 큰 글자,
[소멸]은 `red` 톤, [취소]는 `stone` 톤. 팝업 위에는 배경 연출을 얹지 않는다.

## 4. 재렌더 규율 — 촉매 보관함과 같다

`render()` 가 루트를 통째로 파괴·재생성하면 목록 재구성 때마다 1376×768 배경과 석재 패널이 다시
구워진다. 그래서:

- `buildChrome()` — 배경·패널 2장·헤더는 **한 번만**(자산 로드 시 1회 재건).
- `renderList()` — 행만 `listHost` 안에서 갈아끼운다.
- 선택 변경은 `rowSelect` 로 **두 행만** 토글하고 상세는 `.text` 만 갈아끼운다.
- 팝업은 `modalHost` 에서만 나고 진다.

`update(dt)`: 격납고가 **자기 가시성 가드보다 먼저** `roster.update(dt)` 를 부른다(이 화면이 떠
있는 동안 격납고 root 는 `suspend()` 로 숨겨져 있어 가드 뒤에 두면 연출이 통째로 멈춘다).

## 5. 기능 불변식 — 깨면 즉시 불합격

1. **소멸 계약**(ADR-0024·0025): 잠긴 장비 수를 **소멸 전에** 세고 `dismissGuardianRecord` →
   `saveProfile`. 장비 stash 반환·계보 포인트 회수는 그 함수가 한다. 이미 `retired` 면 no-op.
2. **확인 팝업 없이 소멸되지 않는다.** 되돌릴 수 없는 조작이다.
3. `activeGuardians` 만 나열한다(소멸분은 목록에서 사라진다).
4. `store` 가 null 이면 `?? undefined` 로 넘긴다 — 명시적 null 은 "저장하지 마라"다.
5. **휠 스크롤은 클립 Container 에**(`makeScrollArea`). 마스크 Graphics 는 히트 테스트 제외.
6. **행 클릭은 행 Container 에.** 버튼은 `stopRowPropagation`.
7. 하위 화면 규약: 격납고와는 `show()`/`onClose`, 격납고가 `suspend()`/`resume()`.
8. 진입 시 런 HUD 숨김 · 닫을 때 원복(`hudPrevVisibility`).
9. 등급 색(`RARITY_COLOR_NUM`)은 **파밍 시각 언어라 변경 불가**.
10. 구 수호기(`build` 부재)는 프리셋 라벨로 폴백하고 잠긴 장비 0 으로 읽는다.

## 7. 지표 운용 규율 (승계)

1. 대리 지표를 **"균일해야 할 것의 상한"** 으로 주면 그림이 지워진다. **하한(보존)으로만 안전.**
2. **평균은 결함을 가린다.** 게이트는 `타일 최소` + `임계 미만 픽셀 비율`로.
3. **가정한 상수를 잰 픽셀로 착각**하면 지표가 참인 채로 틀린다 → 대비는 **곱연산(AO)** 으로.
4. **절대 델타는 곱연산 편차의 지표가 아니다**(`Δ = bg × (1−ratio)`).
5. **표본 정의가 다르면 반대 결론이 나온다** → 정의 비의존 속성을 보고하게 하라.
6. **판정 기준은 스크린샷이고 수치는 대리 지표다.**
7. **처방을 내리기 전에 그 지표가 올바른 축을 재고 있는지 먼저 검토한다.**
