## 0. 전체 구조

각 마일스톤은 **플레이 가능한 상태로 종료**하고, 종료 시 PR 머지 + 게이트 검증을 거친다. 상대 규모는 S<M<L<XL.

| 마일스톤 | 산출물 | 규모 | 종료 게이트 |
|---|---|---|---|
| M1 전투 프로토타입 | 카르곤 1행성 1런 완주 | L | 재미 게이트 (4/5 "한 판 더" + 완주율 60%) |
| M2 파밍 루프 | 드랍→장비→강해짐 체감 | L | 파밍 게이트 (아래 §2) |
| M3 성장 완성 | 행성 5개 + 스킬트리 + 기지 | XL | 콘텐츠 완결 게이트 |
| M4 PvP | 침공·래더·검증 전체 | XL | PvP 무결성 게이트 |
| M5 출시 | CrazyGames 제출 | M | 출시 게이트 |

공통 원칙 (전 마일스톤):
- 시뮬 코어의 결정론 테스트는 CI 상시 게이트 — 새 엔티티·패턴 추가 시마다 해시 테스트 통과 필수
- 모든 작업은 브랜치 → PR → 머지 (전역 git 규칙), 마일스톤당 1~5개 PR로 분할
- 에셋은 "게임플레이 검증 후 생성" — 픽셀랩포지 캐시 조회 → miss 일괄 생성
- 세이브 데이터는 M2부터 버전 필드 포함 (M4 Supabase 이관 대비)

## 1. M1 — 전투 프로토타입

상세 태스크 21개는 [planet-blitz-m1-plan.md](planet-blitz-m1-plan.md) 참조. 요약: 리포 셋업 → 결정론 코어(시드 RNG·고정 타임스텝·리플레이 해시) → 기체·발칸·적 4종·웨이브 → 파워업·보스·보급선·젬 콤보 → 에셋·벤치(탄 2,000발 60fps)·재미 게이트.

## 2. M2 — 파밍 루프

목표: "런 → 드랍 → 장착 → 다음 런이 쉬워짐"의 디아2 도파민 사이클 완성.

1. **아이템 데이터 모델**: 등급 4단계, 어픽스 풀(접두 12+접미 12), 롤 규칙(매직 1~2, 레어 3~6), 아이템 직렬화 스키마(버전 필드 포함)
2. **로컬 세이브**: localStorage 기반 프로필(기체 레벨·인벤·창고·행성 진행), 마이그레이션 가능한 스키마
3. **드랍 시스템**: 엘리트·보스 바닥 드랍(등급색 빔, 접촉 자동 획득), 보스 처치 확정 고등급 드랍, 잡몹은 자원·젬만
4. **장비 시스템**: 8칸 장착 → 시뮬 스탯 파이프라인(주무기 타입 교체 포함 — 발칸 외 스프레드·레일건 추가로 3타입), 보조무기 2종
5. **인벤토리 UI**: DOM 그리드 인벤 48 + 창고 96(확장 2회), 일괄 분해(노말·매직→크레딧, 레어+→광물), 아이템 툴팁·비교
6. **유니크**: 15점 중 5점 구현 (고유 효과가 시뮬에 훅)
7. **행성 2개 체제**: 베르단 추가(잡몹 4종·엘리트 2종·여왕 무리개체 보스), 행성 선택 화면(성계 지도 초기판), 행성별 드랍 테이블·특산 광물 2종
8. **티어 시스템**: 정찰/교전 2티어 우선(섬멸은 M3), 패턴 진화(교전=서브탄 추가), **엘리트 어픽스** 8종 풀 중 4종 + 교전 1개 부여 규칙
9. **재미 요소**: 변칙 경보 3종(중력 폭풍·군체 대발생·암흑 성운), 유니크 세리머니(슬로모+플래시 — 렌더 계층 전용)
10. **기체 레벨**: 경험치 누적·레벨업(캡은 열어두되 M2 콘텐츠 기준 ~Lv40), 스킬 포인트는 적립만(트리는 M3)

**M2 게이트**: ①레어 드랍 시 장비 교체 고민이 실제로 발생(테스터 관찰) ②같은 행성 3연속 파밍 의욕 유지 ③결정론 테스트 통과(장비 스탯 반영 포함) ④변칙 수락 런과 거부 런의 정산 차이 재현.

## 3. M3 — 성장 완성

목표: 영구 성장 전 축 가동 + 콘텐츠 풀 볼륨 + 첫인상(FTUE) 완성.

1. **스킬트리 3계열**: 계열당 20노드(총 60) 데이터·시너지 규칙(하위 투자→상위 증폭)·리스펙(크레딧, 레벨 비례), 연구소 UI
2. **정제소**: 어픽스 리롤 + **잠금 리롤**(광물 3배, 슬롯머신 연출)
3. **행성 5개 완성**: 니플헤임·아르케 추가(잡몹 8종·엘리트 4종·보스 2종 — 유령 기함·수호자 오벨리스크), 섬멸 티어(패턴 변형+밀도↑, 엘리트 어픽스 2개, 어픽스 8종 완성), 레벨 캡 100 활성
4. **유니크·어픽스 완성**: 유니크 15점 전체, 어픽스 24종 전체
5. **기지 맵**: 픽셀아트 기지 화면 + 건물 5종(격납고·연구소·정제소·방어 사령부·관제탑) 클릭 진입, 미해금 잠금 연출 — 방어 사령부·관제탑은 "준비 중" 상태로 배치(기능은 M4)
6. **FTUE**: 타이틀 → 즉시 튜토리얼 런(3~4분 단축판, 홈월드 궤도·카르곤 몹 재사용) → 첫 드랍 → 기지 공개, 시스템 단계 해금(격납고→Lv3 연구소→정제소→…)
7. **파워업 풀 24종 완성**: 주무기 5타입 파생 전체(미사일·빔 무기 추가 포함)
8. **아트 통일 패스**: 전 행성 배경·적·탄막 스프라이트 완성, 탄막 가독성 규칙 전수 점검

**M3 게이트**: ①신규 유저가 안내 없이 60초 내 전투 진입·4분 내 첫 드랍 ②스킬 99포인트로 노드 40% 이하만 커버(수치 검증) ③빌드 2종(화력/생존)이 체감상 다른 플레이가 됨 ④전 행성×전 티어 완주 가능.

## 4. M4 — PvP

목표: 침공·래더·치트 방어 전체 가동. 기술 리스크 최대 구간.

1. **Supabase 셋업**: 프로젝트 생성(project scope `.mcp.json` — 전역 메모리 규칙 준수), 스키마: `profiles`, `ships`, `items`, `ladder`, `defenses`(배치 JSON+정비도), `invasions`(리플레이·결과), `guardians`
2. **시뮬 코어 Deno 포팅 검증**: Edge Function에서 시뮬 코어 실행 → 클라이언트와 해시 일치 e2e 테스트 (**최우선 착수 — 실패 시 아키텍처 재논의 필요한 최대 리스크**)
3. **계정·세이브 이관**: Supabase Auth(익명 시작), 로컬 세이브 → 서버 이관 마이그레이션, PvE 런 결과 서버 기록
4. **방어 배치 에디터**: 그리드 맵·포탑 6종·장애물·배치 포인트 예산제·코어 배치, 방어 사령부 UI
5. **침공 플로우**: 관제탑에서 상위 랭커 3명 제안(+30위 랜덤)·기지 정찰 뷰·침공 런(3분 제한·부활 불가)·코어 파괴 판정
6. **전수 검증**: 침공 리플레이 제출 → Edge Function 재실행 → 결과 확정·래더 스왑(Postgres 트랜잭션)
7. **래더**: 영구 순위표·스왑·**배치전**(NPC 시드 기지 대상 5회→삽입)·비활성 침하(pg_cron)·복제 약탈
8. **풍화·정비**: pg_cron 주간 정비도 -5%p, 정비 UI·예고 알림
9. **NPC 시드 기지**: 난이도 분포 20개 설계·배치
10. **PvE 샘플링 검증**: 상위 N%·통계 이상치·랜덤 재실행, 적발 시 런 무효+플래그
11. **재미 요소**: 복수전(24시간 창·쿨다운 무시)·도발 스티커(사전 세트 12종)
12. **리플레이 관전**: 내 기지 침공당한 리플레이 재생 뷰

**M4 게이트**: ①위조 결과 제출 시나리오 100% 거부(공격 테스트) ②침공→검증→스왑 전 과정 e2e 통과 ③배치전 삽입이 기존 순위 무변동 ④풍화 주기 실행 후 자원·장비·순위 무변동+정비도만 하락 ⑤두 계정 상호 침공·복수전 실플레이 검증.

## 5. M5 — 출시

1. **퇴역·수호 기체·계보**: 퇴역 플로우(수호 기체 생성·일괄 소멸 UI·새 기체 타입 해금), 수호 기체 AI(방어전 참전, 동시 2기), 수호 기체 풍화(주 5%p·바닥 50%)·소멸(전투력 점수×성능 비례), 계보 트리(기체 가지+수호 가지, 로그 점근 +50%)
2. **CrazyGames SDK**: 로그인 연동(Supabase 계정 링크), 리워드 광고 2지점(PvE 부활·정산 보너스), 진행도 클라우드 저장 병행, 포털 QA 가이드라인 점검(로딩 시간·볼륨)
3. **밸런싱 패스**: 티어 배율·드랍률·풍화 수치·계보 점근선 — 스펙 📝 시작값 기준 플레이테스트 튜닝
4. **폴리시**: 사운드·격추 유머 연출 다듬기·정산 화면 완성판·로컬라이즈(영어 우선, 한국어 병행)
5. **QA·성능 최종**: 60fps/2,000발 재검증, 크로스 브라우저(Chrome·Edge·Firefox), 장시간 세션 메모리 누수 점검
6. **제출**: CrazyGames 개발자 포털 제출 → 피드백 반영 → 출시

**M5 게이트(출시 판정)**: ①퇴역 1사이클 실플레이 완주 ②광고 2지점 동작·미시청 시 게임 진행 무결 ③CrazyGames QA 체크리스트 전 항목 통과.

## 6. 마일스톤 간 의존·순서 주의

- M4-2(Deno 포팅 검증)는 M4 최우선이지만, **M1 Phase 1에서 시뮬 코어의 플랫폼 독립성을 지키는 것이 전제** — M1 lint 규칙이 이 리스크의 실질 방어선
- 주무기 5타입은 M2(3타입)→M3(5타입 완성)로 분할 — 파워업 풀 24종이 M3에서야 완성되는 이유
- 방어 사령부·관제탑 건물은 M3에서 아트만, 기능은 M4 — 기지 맵을 두 번 만들지 않기 위함
- 리워드 광고는 M5 — 광고 SDK 없이도 부활·보너스를 개발 플래그로 M1~M4에서 테스트 가능하게 설계
