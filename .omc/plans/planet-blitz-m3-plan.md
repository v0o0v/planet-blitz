## 1. 요구사항 요약

목표(마스터 §3): **영구 성장 전 축 가동 + 콘텐츠 풀 볼륨 + 첫인상(FTUE) 완성.** 범위:

1. **스킬트리 3계열** — 계열당 20노드(총 60), 시너지 규칙(하위 투자→상위 증폭), 리스펙(크레딧, 레벨 비례), 연구소 UI.
2. **정제소** — 어픽스 리롤 + **잠금 리롤**(광물 3배, 슬롯머신 연출).
3. **행성 5개 완성** — 니플헤임·아르케 추가(잡몹 8종·엘리트 4종·보스 2종 = 유령 기함·수호자 오벨리스크), **섬멸 티어**(패턴 변형+밀도↑, 엘리트 어픽스 2개, 어픽스 8종 완성), 레벨 캡 100 활성.
4. **유니크·어픽스 완성** — 유니크 15점 전체, 어픽스 24종 전체.
5. **기지 맵** — 픽셀아트 기지 화면 + 건물 5종 클릭 진입, 미해금 잠금 연출. 방어 사령부·관제탑은 "준비 중"(기능은 M4).
6. **FTUE** — 타이틀 → 즉시 튜토리얼 런(3~4분, 홈월드 궤도·카르곤 재사용) → 첫 드랍 → 기지 공개, 시스템 단계 해금.
7. **파워업 풀 24종 완성** — 주무기 5타입 파생 전체(미사일·빔 추가).
8. **아트 통일 패스** — 전 행성 배경·적·탄막 스프라이트 완성, 탄막 가독성 전수 점검.

**비범위**: Supabase/PvP·방어 배치·침공(M4), 퇴역/수호/계보(M5), 사운드(M5).

## 2. 설계 원칙 + 핵심 결정 갈림길

### 설계 원칙
1. **결정론 승계(ADR-0005)**: 스킬트리·리롤·섬멸 티어·신규 보스 패턴의 시뮬 영향분은 시드 RNG·결정론 산술만. 리롤은 M2 `rollItem`과 동일 순수 규율(`src/items/roll.ts` 확장). 스킬 파생 스탯은 로드아웃과 함께 `Replay.config`에 포함(서버 재현).
2. **스킬트리 = 데이터, 시너지 = 순수 함수**: 60노드는 `data/skills.ts` 데이터. 투자 벡터 → 파생 스탯은 순수 `computeSkillStats(invest)`. 시뮬 훅은 M2 로드아웃 파이프라인(`src/items/loadout.ts`) 합류 지점 재사용.
3. **데이터 주도 콘텐츠(마스터 리스크 톱2)**: 니플헤임·아르케 로스터, 섬멸 티어, 어픽스 24종, 유니크 15점, 파워업 24종은 전부 `data/*.ts` 행 추가. 패턴 컴포넌트 엔진·웨이브 디렉터·`autoAttack` 분기 골격 유지.
4. **티어 = 패턴 진화 우선(GDD §6)**: 섬멸은 수치 배율 완만(HP ×4.5 수준) + 패턴 변형·밀도↑. "수치만 다른 티어" 금지.
5. **UI/시뮬 분리**: 연구소·정제소·기지 맵·FTUE 흐름은 DOM/렌더. 시뮬 무영향. 기지 맵은 M4 건물을 두 번 만들지 않도록 "준비 중" 상태로 자리만.

### 핵심 결정 갈림길

#### ① 스킬 투자가 런에 반영되는 지점
| 옵션 | Pros | Cons |
|---|---|---|
| **A. 스킬 파생 스탯을 M2 로드아웃 파이프라인에 합류 → `Replay.config` 포함 ★채택** | M2 인프라 재사용, 서버 재현 자동, 파워업 풀 진화(스킬 파생)와 정합, 해시 확장 최소 | config 스키마 재확장 |
| B. 스킬 전용 config 블록·별도 적용 경로 | 관심사 분리 | 파이프라인 이중화, 유지비↑, 파워업 풀 연동 복잡 |
| C. 스킬 효과를 런 중 실시간 판정 | 동적 | 불필요(런 중 스킬 불변), 결정론 표면↑ |

**채택 A 근거**: M2가 이미 `computeLoadoutStats`로 8칸 장비를 `WeaponStats`/`WorldConfig`에 주입(`src/items/loadout.ts`). 스킬 투자 파생 스탯을 **같은 합류 지점**에 더하면 "빌드가 깊을수록 파워업 풀도 진화"(GDD §3)가 자연 정합. `Replay.config`에 스킬 투자 스냅샷 포함. B는 이중화, C는 과설계로 기각.

#### ② 파워업 풀 24종의 "빌드 파생" 구조
| 옵션 | Pros | Cons |
|---|---|---|
| **A. 파워업 풀을 로드아웃(무기 타입·스킬 투자)로 필터·가중 → `powerupRng` 추첨 ★채택** | GDD "장비/스킬 파생 파워업" 충족, 기존 `drawPowerupChoices`(`powerups.ts:114`) 확장, 결정론 유지 | 풀 태깅·필터 규칙 필요 |
| B. 파워업 24종 전부 항상 후보 | 단순 | "내 빌드 파생" 정체성 상실(GDD §3 위배) |
| C. 무기 타입별 완전 분리 풀 | 명확 | 스킬 파생·범용 파워업 표현 곤란, 경직 |

**채택 A 근거**: GDD §3·§4 — 파워업은 장착 장비·투자 스킬에서 파생. 24종 풀에 태그(무기타입·스킬계열·범용)를 달고, `drawPowerupChoices`가 현재 로드아웃으로 후보 필터 후 시드 추첨. 추첨은 결정론(`powerupRng`) 유지. B는 정체성 상실, C는 경직으로 기각.

#### ③ 섬멸 티어 = 패턴 진화 표현 방식
| 옵션 | Pros | Cons |
|---|---|---|
| **A. 티어 파라미터를 패턴 데이터에 주입(서브탄·변형 플래그) + 엘리트 어픽스 2개 ★채택** | 패턴 엔진 재사용, "수치 아닌 진화"(GDD §6), 데이터 작업화 | 패턴 컴포넌트에 티어 분기 필요 |
| B. 섬멸용 별도 적 정의 복제 | 단순 | 콘텐츠 중복 폭발(적 20종×3티어), 유지 불가 |
| C. 수치 배율만 상향 | 최소 | "HP 스펀지"·"수치만 다른 티어" 금지 위배 |

**채택 A 근거**: GDD §6 — 교전=서브탄 추가, 섬멸=패턴 변형+밀도↑. 패턴 컴포넌트 엔진(`src/sim/patterns/`)에 티어 파라미터(서브탄 개수·변형 플래그·밀도)를 데이터로 주입. C는 명시 금지, B는 콘텐츠 중복으로 기각.

> **≥2 viable option 확보**: 세 갈림길 모두 대안 2개 이상. 채택안의 기각 근거 명시.

## 4. 구현 단계

> Phase A(스킬)·B(콘텐츠)·C(파워업)는 M2 위에서 병행 가능, D(UI)·E(FTUE)·F(아트)는 A~C 후, G 검증. **각 태스크 후 `npm test` + `tsc --noEmit`**.

### Phase A — 스킬트리 + 리롤 · 의존: M2
- **A1. 스킬 데이터** — 신규 `data/skills.ts`
  - 3계열(화력·생존·기동, GDD §4) × 20노드. 노드당 1~5포인트, 노드 비용 총합 ~250(계열 ~85)로 99포인트가 40% 커버(GDD §4). 각 노드 `statKey`·시너지 규칙.
- **A2. 스킬 파생 스탯(순수)** — 신규 `src/items/skills.ts` (또는 `loadout.ts` 확장)
  - `computeSkillStats(invest: number[])` → 파생 스탯, 시너지(하위 투자→상위 증폭) 반영. M2 `computeLoadoutStats`와 합산해 `WorldConfig`/`WeaponStats` 주입. `Replay.config`에 스킬 투자 스냅샷 포함.
- **A3. 리스펙·적립 소비** — `src/save/profile.ts` 확장
  - 크레딧 비용(레벨 비례). M2에서 적립만 하던 스킬 포인트를 여기서 소비. 세이브 스키마 확장(`saveVersion` 범프).
- **A4. 정제소 리롤(순수)** — `src/items/roll.ts` 확장
  - `rerollAffixes(item, rerollSeed, lockedIndex?)` 순수 함수: 잠금 어픽스 보존, 나머지 재롤(광물 3배 비용은 메타). 결정론 단위 테스트. Edge Function 공용.

### Phase B — 행성 5개 + 섬멸 티어 + 어픽스/유니크 완성 · 의존: M2
- **B1. 니플헤임 로스터** — 신규 `data/planets/niflheim.ts`
  - 잡몹 4종(빙설·유령 함대, 역할 4슬롯)·엘리트 2종. `ENEMY_BY_TYPE` typeIndex append. 유령 기함 보스(레이저 그물+감속 지대) 3페이즈 — `data/bosses/`.
- **B2. 아르케 로스터** — 신규 `data/planets/arke.ts`
  - 잡몹 4종(고대 기계, 역할 4슬롯)·엘리트 2종. 수호자 오벨리스크 보스(기하학 회전 탄막) 3페이즈.
- **B3. 섬멸 티어 파라미터** — `src/sim/patterns/` + `data/waves.ts`
  - 티어 파라미터(서브탄·변형 플래그·밀도) 패턴 데이터 주입(갈림길③A). 교전=서브탄(M2 완성분 승계), 섬멸=변형+밀도↑. 엘리트 어픽스 섬멸 2개 부여. 레벨 캡 100·Lv60 섬멸 진입 게이트(`data/`).
- **B4. 어픽스 24종 + 유니크 15점 완성** — `data/affixes.ts`·`data/uniques.ts` 확장
  - M2의 어픽스 12+12·엘리트 어픽스 4·유니크 5 → 전체 24 어픽스·엘리트 8·유니크 15. 각 시뮬/스탯 훅(`loadout.ts`).

### Phase C — 파워업 풀 24종 (빌드 파생) · 의존: M2 B2(무기타입)
- **C1. 무기 5타입 완성** — `autoAttack` 분기(`world.ts:642-671`)
  - M2의 발칸·스프레드·레일건(0~2)에 미사일(유도·분열)·빔(지속 라인) 추가(3~4). 미사일·빔의 결정론 발사 로직.
- **C2. 파워업 풀 24종 + 태그·필터** — `src/sim/powerups.ts` 확장
  - `POWERUPS` 8종 → 24종(주무기 5타입×2=10, 보조 5, 스킬 파생 계열당 3×3=9, GDD §3). 각 항목에 태그(무기타입/스킬계열/범용). `drawPowerupChoices`(`powerups.ts:114`)가 현 로드아웃으로 후보 필터·가중 후 `powerupRng` 추첨(결정론). **인덱스 안정성 유지**(기존 0~7 재정렬 금지, append — 리플레이 포맷).

### Phase D — 기지 맵 + 연구소·정제소 UI · 의존: A,B
- **D1. 기지 맵 허브** — 신규 `src/ui/baseMap.ts`
  - 픽셀아트 1화면 고정 뷰(GDD §7) + 건물 5종 클릭. 격납고(M2 인벤 재사용)·연구소·정제소 진입. 방어 사령부·관제탑 "준비 중" 잠금 연출(M4 자리 확보 — 두 번 안 만들기, 마스터 §6).
- **D2. 연구소 UI(스킬트리)** — 신규 `src/ui/researchLab.ts`
  - 3계열 트리 시각화·투자·리스펙·시너지 표시. 스킬 포인트 소비.
