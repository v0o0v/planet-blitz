## 불변 제약

- sim/save 무수정: `DefenseLayout` 구조·좌표 단위·`hashWorld` 불변. 결정론(ADR-0005) 무관 — 전부 렌더/UI 전용.
- 기존 레이아웃 저장·로드 왕복이 바이트 동일해야 한다(서버 defenseSync 계약 불변).
- 진입 지점(정중앙) 배치 금지·코어 1개·예산 검증은 기존 순수 함수 그대로.
- 프리뷰 정지 월드는 정산·리플레이·오염 경로에 연결 금지.

## AC (수용 기준)

1. 방어 사령부 진입 = 실월드 배치 프리뷰가 배치 영역 전체를 한 화면에 표시(카르곤 플랫 배경·실스프라이트·실축척).
2. 팔레트 도구 선택→칸 클릭으로 배치/제거, 수호 포함. 배치물 클릭 = 선택(사거리 원+제거 버튼).
3. 진입 지점 마커·그리드·호버 하이라이트·배치 불가 칸·코어 반경 표시. 사거리 원이 실축척(발칸 820 vs 저격 1500 차이가 눈으로 구분).
4. 예산·코어 1개·진입 지점 금지 규칙 기존과 동일 동작. 기존 저장 레이아웃 로드→무수정 저장 시 데이터 동일.
5. 카드 슬롯·정비도·카드 인벤/상점/합성이 우측 패널에서 기존 기능 그대로 동작.
6. 침공 런에서 포탑 6종·코어·수호가 각자 스프라이트로 렌더(player 폴백 0건).
7. vitest·lint·tsc green. 하네스 딥링크·치트 패널 경유 진입 정상.

## OQ (구현 시 판단)

1. 포탑 스프라이트의 포신 방향 — sim이 조준각을 유지하는지 확인 후, 정지 프리뷰에서는 기본 방향 고정 권장.
2. 우측 카드 패널 접이식 확장 시 프리뷰 가림 정도 — 반투명+접힘 기본, 디자인 재량.
3. 프리뷰 월드 재생성 시점 — 배치 확정 즉시 vs debounce, 구현 재량(체감 지연 없게).
4. 수호 스프라이트의 침공 런 이동 렌더 방향 처리(추적 AI 각도) — entityRenderer 기존 회전 규약 따름.
