## Goal

침공(PvP)당할 때 **자동 발동되는 소모성 방어 카드**를 도입한다. 카드는 등급(기존 Rarity 4단계)과 카드 어픽스(접두=정적 카운터, 접미=동적 트리거)를 가지며, 사용 횟수가 소진되면 사라진다. 목표는 두 겹의 퍼즐:
1. **방어자 퍼즐** — "요즘 나를 치는 공격자들의 성향에 맞춰 어떤 카드를 슬롯에 꽂을까" (단일 슬롯의 선택 긴장)
2. **공격자 역퍼즐** — "저 등급의 카드가 꽂힌 기지를 어떻게 뚫을까" (부분 공개 + 정찰)

부수 효과: 카드 소진·재장착·일일 상점이 만드는 주기적 접속 동기, 카드 합성·분해가 만드는 재화 순환.

## 확정 결정 (라운드순)

1. **단일 슬롯 + 수동 재장착 (R1)** — 방어 사령부에 카드 슬롯 1개. 침공 확정마다 발동 + 횟수 1 차감, 0이 되면 빈 슬롯. 자동 승계 없음 — 무방비 리스크가 곧 관리 동기.
2. **스냅샷 고정 + 확정 시 차감 (R2, ADR-0012)** — 카드 효력(효과+남은 횟수)은 `begin_invasion` 스냅샷에 고정. 차감은 `apply_invasion_result` 확정 시 서버만 수행. 공격자가 런을 버리면 카드는 닳지 않는다(카드 빼기 간보기 봉쇄). 기존 정비도·수호 기체 권위 주입 패턴과 동일.
3. **혼합 성향 판정 (R3)** — 접두사 = **정적 카운터**(스폰 시점에 공격자 기체/장비 스펙 — 원소 속성·무기 유형 등 — 을 보고 수치 보정), 접미사 = **동적 트리거**(런 중 공격자 행동 — 코어 직공·포탑 파괴·장기 대치 등 — 에 반응해 발동). 둘 다 결정론 시뮬 내부에서 판정.
4. **기존 Rarity 4단계 재사용 (R4)** — normal/magic/rare/unique 그대로. `rollItem` 패턴·색상 어휘 재활용. unique는 고유 이름 + 고정 특수효과(기존 uniques 패턴).
5. **강할수록 적은 횟수 (R5)** — 사용 횟수는 생성 시 시드로 확정. 📝 시작값: normal 6~10 / magic 5~8 / rare 3~6 / unique 2~4. 강카드는 "필살기", 약카드는 "보험" — 언제 강카드를 꺼낼지의 운영 퍼즐 + 희소 카드 영구화 방지.
6. **방어 사령부 탭 + 일일 로테이션 상점 (R6)** — 크레딧으로 구매, normal·magic 전용. 📝 재고: normal 3~4장 + magic 1~2장, 일일 시드 로테이션, 옵션 미리 공개. 새 건물 없음.
7. **희소 획득 4경로 (R7)** — ① 침공 방어 성공 보상(저확률, 강한 공격자를 막을수록 확률 상승) ② 일반 런 보스 드랍(극저확률, 기존 드랍 파이프라인) ③ 복수전 승리(낮은 확률 — 확정 아님) ④ 카드 합성. **unique는 모든 경로에서 매우 낮은 확률.**
8. **합성: 3장 → 확률 승급, 실패 시 동급 1장 (R8)** — 같은 등급 3장 소모 → 상위 등급 승급 확률 판정. 📝 시작값: normal→magic 50%, magic→rare 20%, rare→unique 3%. 실패해도 같은 등급 새 카드 1장 반환(새 옵션·새 횟수 롤) — 순소실 없음, 3→1 감소 자체가 싱크.
9. **부분 공개: 등급만 (R9)** — 타겟 목록에 카드 장착 여부 + 등급(색상)만 표시, 카드 어픽스는 비공개. 한 번 침공한 상대의 카드는 결과 화면에서 옵션 공개(정찰 가치) — 복수전·재침공 때 역퍼즐 가능.
10. **효과 3범주 + 전용 보관함 (R10)** — 허용: 방어 시설 버프 / 공격자 디버프 / 룰 변경형(unique 고유효과 전용). **제외: 경제·보상 개입** (EF 결과 단계는 횟수 차감 외 불변). 보관은 카드 전용 보관함(📝 상한 20장, 확장 없음, 창고와 분리) + 분해로 크레딧 회수.

## Constraints

- **서버 권위 (원칙2)**: 카드 효과가 침공 결과에 영향을 주므로, verify-invasion EF는 제출 config가 아니라 스냅샷의 서버 권위 카드 데이터로 재실행한다. 카드 소유·장착·횟수는 클라이언트가 직접 쓸 수 없다(가드 트리거 패턴).
- **결정론 (ADR-0005)**: 정적 카운터·동적 트리거 판정은 전부 순수 함수로 sim 안에 산다. 클라·EF(Deno)가 같은 모듈을 공유해야 하며, `verifyInvasionCore.ts`는 플랫폼 전역 무참조 원칙 유지.
- **스냅샷 정합 (M5)**: `begin_invasion` 스냅샷에 카드가 포함된다. 잔여 횟수 0 이후 확정되는 동시 침공도 스냅샷에 실린 효력은 유지, 차감은 바닥 0에서 멈춘다.
- **무손실 철학 (ADR-0003)**: 카드 발동·소진은 방어자의 능동 소비이며, 침공당해 카드 외의 것을 잃는 경로는 추가하지 않는다.
- 접두·접미 표기는 반드시 **카드 어픽스** 전체 표기 (장비 어픽스·엘리트 어픽스와 3중 구분, CONTEXT.md).
- 📝 수치 시작값은 전부 밸런스 조정 대상(횟수 범위, 합성 확률, 상점 재고, 보관 상한, 개별 옵션 계수).

## Non-Goals

- 카드 여러 장 동시 장착 / 덱 구성 (단일 슬롯 확정)
- 카드 거래·선물 (경제 격리)
- 경제/보상 개입형 카드 옵션 (약탈량 감소·보상 증가 등 — 1차 범위 외로 명시 제외)
- 공격 카드 (침공자 측 카드 — 방어 전용 시스템)
- 카드 어픽스 리롤 (합성 실패 반환이 사실상 리롤 역할 — 별도 리롤 크래프팅 없음)
- 카드 보관함 확장 (상한 고정)

## 카드 해부 (Anatomy)

```
[등급] [접두사: 정적 카운터] 기본 카드명 [접미사: 동적 트리거]  (사용 횟수 N)
```

- **기본 옵션**: 등급별 기저 방어 수치 (예: 포탑 화력·코어 HP 소폭 상승) — normal도 무옵션이 아니라 기저 효과는 있음 📝
- **접두사 (정적 카운터)** 예: 소화의(화염 공격자 피해 감소), 절연의(전격 보조무기 쿨다운 증가), 중장갑 파쇄의(전투력 우위 공격자에 화력 보너스), 복수자의(복수전 공격자 상대 2배), 연전 차단의(동일 공격자 재침공 보정)
- **접미사 (동적 트리거)** 예: ~의 역장(코어 반경 진입 시 일시 실드), ~의 격노(포탑 3기 파괴 시 연사 증가), ~의 지연전(90초 경과 시 공격자 이속 감소), ~의 응징(수호 기체 격추 시 일제사격)
- **unique 고유효과 (룰 변경형)** 예: 신기루 코어(가짜 코어), 블랙아웃(첫 30초 레이더 무력화), 최후의 재기동(코어 파괴 직전 1회 부활), 거울 관문(피해 일부 반사)
- affix 수는 장비와 동일 규칙 재사용: normal 0(기저만) / magic 1~2 / rare 3~6 / unique 고정

## 구현 접점 (Touchpoints)

| 레이어 | 위치 | 작업 |
|--------|------|------|
| 데이터 | `data/` 신규 (예: `data/defenseCards.ts`) | 카드 어픽스 카탈로그(정적 카운터·동적 트리거), unique 카드 정의, 횟수 범위, 합성 확률 — 순수 데이터 |
| 롤링 | `src/items/` 패턴 준용 | `rollCard(seed, rarity)` 결정론 생성 (rollItem 준용, 횟수 롤 포함) |
| 시뮬 | `src/sim/defense.ts` 연계 | `InvasionConfig`에 카드 효력 탑재, 정적 카운터는 스폰 시 수치 보정, 동적 트리거는 스텝 함수에서 판정 |
| 스키마 | `supabase/migrations/` 신규 | 카드 소유 테이블 + `defenses` 장착 참조 + 스냅샷 포함 + RLS/가드 트리거(횟수 서버 전용) |
| EF | `verifyInvasionCore.ts` + `index.ts` | 카드 권위 주입(정비도·수호 패턴 동일), `apply_invasion_result`에 차감 추가 |
| UI | `src/ui/defenseCommand.ts` | 카드 슬롯·보관함·상점 탭·합성·분해. 타겟 목록에 등급 배지, 결과 화면에 옵션 공개 |

## Acceptance Criteria

- [ ] 카드 장착 후 침공당하면 스냅샷에 카드 효력이 실리고, EF 재실행 결과가 클라 hashStream과 일치
- [ ] 침공 시작만 하고 미제출 시 사용 횟수 불변, `apply_invasion_result` 확정 시 정확히 1 감소, 0에서 카드 소멸·슬롯 비움
- [ ] 클라이언트가 횟수·장착을 직접 UPDATE 시도하면 가드 트리거가 거부
- [ ] 정적 카운터: 조건 일치 공격자와 불일치 공격자의 방어 수치 차이를 결정론 테스트로 검증
- [ ] 동적 트리거: 트리거 조건 충족 리플레이와 미충족 리플레이의 발동 여부를 결정론 테스트로 검증
- [ ] 상점 일일 로테이션이 같은 날 같은 유저에게 동일 재고(시드 검증), normal·magic만 등장
- [ ] 합성 3장 소모 → 성공 시 상위 등급 1장 / 실패 시 동급 1장, rare→unique 확률이 설정값과 통계적으로 일치
- [ ] unique 획득 확률이 전 경로(방어 보상·보스 드랍·복수전·합성)에서 설정된 극저확률 상한 이하
- [ ] 타겟 목록에 등급만 노출되고 옵션은 침공 이력 있는 상대만 공개
- [ ] 보관함 상한 도달 시 신규 획득 처리(📝 획득 불가 vs 우편 대기 — OQ#1)가 명세대로 동작
- [ ] 잔여 1회 카드에 UI 경고 표시

## Open Questions (구현 전 결정 필요)

- **OQ#1**: 보관함 만석 시 신규 카드 처리 — 획득 차단 vs 임시 우편함 vs 자동 분해. 📝 권장: 획득 차단 + 상점/합성 버튼 비활성화 안내(단순).
- **OQ#2**: 방어 성공 보상 카드의 "강한 공격자일수록 확률 상승" 산식 — 전투력 점수 차 기반 계수 정의 필요.
- **OQ#3**: 동적 트리거 발동을 방어자 리플레이 관전에서 어떻게 연출할지(발동 순간 배너 등) — 렌더 전용이라 결정론 무관, UI 패스에서 결정.
- **OQ#4**: 배치전(NPC 시드 기지) 침공 시 NPC 기지에도 카드를 심을지 — 📝 권장: 1차에서는 없음(신규 유저 학습 부담 회피).

## Assumptions Exposed & Resolved

| 가정 | 도전 방식 | 해소 |
|------|-----------|------|
| "한 번에 1장 = 덱에서 자동으로 나온다" | R1 슬롯 vs 큐 구분 질문 | 단일 슬롯 + 수동 재장착 — 퍼즐 긴장과 접속 동기 확보 |
| "침공당하면 즉시 횟수가 닳는다" | R2 카드 빼기 간보기 악용 지적 | 확정 시 차감 (ADR-0012) |
| "성향 반응은 한 축이면 된다" | R3 정적/동적 분리 제시 | 접두=정적, 접미=동적 — 어휘 축 자체를 이원화 |
| "카드 등급은 새로 만든다" | R4 기존 Rarity 재사용 제안 | 4단계 재사용 — 학습 비용·코드 재활용 |
| "희소할수록 오래 쓴다" | R5 CONTRARIAN: 강카드 영구화 | 강할수록 적은 횟수 — 필살기/보험 구도 |
| "상점은 새 건물" | R6 기지 UI 비용 지적 | 방어 사령부 탭 통합 |
| "합성 실패는 소멸" | R8 이탈 리스크 지적 | 동급 1장 반환 — 리롤 가치로 손맛 완화 |
| "카드는 숨겨야 기습이 된다" | R9 운빨 패배감 지적 | 등급만 공개 + 침공 후 정찰 공개 |
