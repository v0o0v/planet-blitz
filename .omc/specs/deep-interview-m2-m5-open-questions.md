## 결정 사항

### 1. M2 유니크 5점 (OQ-M2-6 닫힘)
배분 원칙: **주무기 3타입 대표 각 1 + 보조무기 1 + 범용 1**. 이름은 구현 시 조정 가능, 효과 골자는 고정.

| # | 슬롯/타입 | 이름(안) | 고유 효과 |
|---|---|---|---|
| 1 | 주무기·발칸 | 과열 드럼 | 연속 명중마다 발사속도 스택↑, 피격 시 리셋 (램프업) |
| 2 | 주무기·스프레드 | 분열 코어 | 스프레드 탄이 적 명중 시 파편 2발 분열 |
| 3 | 주무기·레일건 | 관통 자이로 | 관통 무제한 + 관통당 피해 증폭 |
| 4 | 보조무기 | 자율 드론 베이 | 발동 시 임시 포탑 소환 (scroll-map `turretPickup` 로직 재사용) |
| 5 | 범용·장갑 | 위상 장갑 | 대시 직후 짧은 무적 + 대시 쿨다운 감소 |

### 2. M3 유니크 15점·어픽스 24종 (OQ-M3-5 닫힘)
유니크 15점 = M2 5점 + M3 10점 (슬롯 7종 전체 커버):

| # | 슬롯 | 이름(안) | 효과 |
|---|---|---|---|
| 6 | 주무기·미사일 | 군집 벌통 | 미사일 격추 시 마이크로 미사일 3발 분열 |
| 7 | 주무기·빔 | 수렴 프리즘 | 관통 적 수만큼 빔 폭·피해 증가 |
| 8 | 주무기·스프레드 | 쌍둥이 항성 (GDD 예시) | 발사체 2배, 피해 -30%, 피격 시 실드 대신 주변 탄 소멸 |
| 9 | 보조무기 | 특이점 발생기 | 소형 중력장 — 적 흡인 (자석 로직 역방향) |
| 10 | 장갑 | 반응 장갑 | 피격 시 반격 펄스 (생존 트리 시너지) |
| 11 | 실드 | 위상 전환막 | 실드 0 시 광역 폭발 + 절반 회복 (내부 쿨다운) |
| 12 | 엔진 | 잔상 추진기 | 대시 잔상이 적탄 소거 (기동 트리 최상위와 중첩 규약 필요 — M3 구현 시 명세) |
| 13 | 코어 | 탐욕의 심장 | 젬 획득마다 콤보 지속·자석 반경 스택 |
| 14 | 모듈 | 도박사의 칩 | 파워업 선택지 +1, 저주 선택지 혼입 확률 |
| 15 | 모듈 | 유물 증폭기 | 광물 발견율·경험치·유니크 드랍률 소폭↑ |

어픽스 24종:
- **접두 12 (공격)**: 피해+% / 발사속도+% / 발사체+1 / 관통+1 / 폭발 부여 / 화염(지속피해) / 냉기(감속) / 전격(연쇄) / 치명타 확률 / 치명타 피해 / 탄속+% / 보스 피해+%
- **접미 12 (유틸·생존)**: 이동속도 / 대시 쿨다운↓ / 최대 HP / 실드 재생 / 자석 반경 / 경험치+% / 광물 발견율 / 크레딧+% / 파워업 재선택+1 / 젬 가치+% / 피격 무적시간+% / 드랍률+%
- **원소 3종(화염·냉기·전격)은 M2 제외, M3에서 상태이상 시스템과 함께 투입** — M2 어픽스 풀은 21종으로 시작. (Contrarian 라운드 결정: 상태이상 타이머·감속 배율·연쇄 판정의 sim 비용을 M2에 앞당기지 않음)

### 3. M4 (OQ-M4-1 및 목록)
- **Deno import 경로 정합**: 논의로 닫지 않음 — M4 Phase A 착수 시 기술 게이트로 검증, 실패 시 M4 중단·재논의 (계획 유지).
- **포탑 6종 확정**: ①발칸(단일 연사, 기본) ②저격(장거리 고피해 저속) ③산탄(근거리 부채꼴) ④감속(냉기장, 지원) ⑤미사일(제한 선회 유도) ⑥전격(연쇄 다수 약공). ④⑤⑥은 M3 산출물(상태이상·미사일) 재사용.
- **도발 스티커 12종**: 톤만 확정 — "가벼운 유머·도발, 조롱·모욕 아님". 개별 목록은 M4 착수 시 디자인 패스.

### 4. M5 기체 2종
- 1차 출시 기체 2종 = 스타터(밸런스형) + **퇴역 해금 기체(선택제)**.
- 선택제 범위: **스탯 프리셋 선택 + 3계열 트리 공유** — 퇴역 시 타이탄형(고HP·고화력·저속·대시 쿨다운↑) / 인터셉터형(고속·대시 특화·저내구) 중 선택. 전용 트리 분화는 출시 후 확장.
