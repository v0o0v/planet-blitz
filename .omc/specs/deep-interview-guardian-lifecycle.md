## Goal

수호 기체를 "보존물"에서 **순환 자원**으로 재설계한다: 생성(퇴역) → 풍화(수명형 감쇠) → 소멸(계보 포인트 회수) → 계보 강화(다음 세대가 더 강함)의 생애주기 순환. 이로써 수호 기체 무한 축적 문제를 해소하고, "언제 회수할까"라는 주기적 결정과 "세대를 거듭할수록 강해지는 계보"라는 장기 성장 서사를 만든다.

## 확정 결정 (라운드순)

1. **수명형 풍화 (R1)** — 수호 기체는 정비 불가. 주기마다 성능이 서서히 감쇠(노후화). 세대교체 서사와 순환을 강제.
2. **계보 전역 강화 (R2)** — 포인트는 개체가 아닌 계정 단위 **계보** 트리에 투자 → 현재·미래 모든 수호 기체에 적용. 개체 소멸에도 투자 영구 보존 → 수명형과 무모순.
3. **언제든 소멸 + 풍화 반영 산식 (R3)** — 소멸은 방어 사령부에서 상시 가능(퇴역 시 일괄 소멸 UI 별도 제공). 포인트 = 기본값 × 남은 성능 비율 → "신선할 때 회수 vs 말년까지 방어 활용"의 상시 딜레마. 방치 유저는 회수량도 자연 손해 → 순환 가속.
4. **계보 무한 + 로그 스케일 (R4, 비권장 선택 존중)** — 계보 트리는 상한 없이 투자 가능하되 효과는 로그 스케일. 📝 완화 제안: 점근형 설계(계보 보너스 총합 +50%에 수렴)로 무한 성장감과 실질 격차 상한을 양립. PvP 고착화 재생산 리스크는 이 점근선 수치로 통제.
5. **바닥 50% 유지 (R5)** — 성능은 100%→50%까지만 감쇠하고 멈춤. 자동 소멸 없음(무손실 철학 유지). 회수 포인트도 같은 비율로 바닥까지만 감소.
6. **계보로 통합 (R6)** — 기존 계승 특전을 폐지하고 **계보** 단일 시스템으로: [기체 가지](구 계승 특전 — 내 기체 소폭 강화) + [수호 가지](수호 기체 강화). 포인트 원천: 퇴역 시 기본 지급 + 수호 기체 소멸(성능 비례). UI는 연구소 한 화면.
7. **수호 가지 = 스탯 + 소수 질적 노드 (R7)** — 대부분은 반복 투자형 수치 노드(피해↑·내구↑·풍화 속도↓)로 무한+로그 구조 담당, 마일스톤 노드 3~4개만 질적 해금(예: 격추 시 1회 재기동, 코어 근접 시 수비 모드, 동료 수호기와 실드 공유).
8. **복사 스냅샷 + 전투력 점수 (R8)** — 퇴역 시 장비 원본은 자동 창고 반환(기존 "창고 공유 재사용"과 정합), 수호 기체는 능력치 복사본. 퇴역 순간의 **전투력 점수**(장비 등급·어픽스 가치 + 스킬 빌드 종합)를 스냅샷에 기록, 소멸 포인트 = 전투력 점수 비례 × 남은 성능. 잠재 모순(장비 복제 vs 창고 재사용)이 이 라운드에서 해소됨.

## Constraints

- 풍화는 이제 두 대상: 방어 시설 정비도(회복 가능, 주 5%p) + 수호 기체 성능(회복 불가, 수명형) — ADR-0006 개정 필요
- 자동 소멸 금지 — 수호 기체가 유저 행동 없이 사라지는 이벤트는 없다
- 계보 투자는 되돌리지 않는다 (리스펙 없음 — 포인트가 순환 재화이므로)
- 동시 배치 2기 제한은 유지 — 계보는 질적 성장 경로
- 📝 수치 시작값: 수호 기체 성능 감쇠 주 5%p (100→50%까지 10주), 소멸 기본 포인트 = 100 × (성능/100), 퇴역 기본 지급 50pt

## Non-Goals

- 개별 수호 기체 강화·장비 교체 (계보 전역 강화로 대체)
- 수호 기체 정비/수리 (수명형 원칙)
- 계보 리스펙
- 공격측 계보(침공 전적 기반 보정) — 1차 범위 외

## Acceptance Criteria

- [ ] 풍화 주기 실행 후 수호 기체 성능이 5%p 하락하고, 50%에서 더 내려가지 않음
- [ ] 성능 x%인 수호 기체 소멸 시 계보 포인트 = 기본값 × x% 지급 확인
- [ ] 소멸이 방어 사령부에서 상시 가능하고, 퇴역 플로우에 일괄 소멸 선택이 표시됨
- [ ] 계보 노드 투자 후 신규 생성 수호 기체에 보너스가 즉시 적용됨
- [ ] 계보 보너스 총합이 점근선(📝 +50%)을 초과하지 않음을 수치 검증
- [ ] 구 계승 특전 참조가 문서·UI에 남아 있지 않음 (계보 기체 가지로 통일)
- [ ] 수호 기체가 유저 행동 없이 소멸하는 경로가 없음을 확인
