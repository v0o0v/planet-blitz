## Goal

기존 GDD의 뼈대(아레나 서바이벌+탄막 × 디아2 파밍 × 비동기 PvP) 위에, 구현 착수에 필요한 디테일을 확정한다: 런 내 파워업의 정체(장비 증폭식), 성장 상한과 엔드게임 순환(캡 100 → 퇴역 → 수호 기체), 아이템·인벤토리 규칙, 콘텐츠 볼륨(표준판), 치트 방어 아키텍처(결정론 리플레이), 영구 래더의 순환 장치(배치전·비활성 침하·풍화), 첫 실행 경험과 화면 구조.

## 확정 결정 (라운드순)

1. **런 내 파워업 = 장비 증폭식** — 임시 무기 추가 없음. 3택 선택지는 장착 장비·투자 스킬에서 파생된 강화·변형(연사속도↑, 미사일 분열, 대시 쿨다운↓, 실드 반격 등). 빌드가 깊을수록 파워업 풀도 진화 → 파밍↔런 상호 강화.
2. **FTUE = 즉시 튜토리얼 런** — 타이틀 클릭 즉시 홈월드 궤도 튜토리얼 런(3~4분 단축판). 이동·회피·레벨업 3택을 전투 안에서 학습, 보스 처치 → 첫 장비 드랍 → 기지 공개. 시스템 단계 해금.
3. **인벤토리 = 제한 인벤 + 기지 창고** — 런 중 수거 무제한(자동 수거), 기지 인벤 48칸(6×8) + 창고 96칸(크레딧으로 2회 확장). 아이템 1×1 고정. 가득 차면 **분해** 유도: 노말·매직→크레딧, 레어 이상→희귀 광물 소량.
4. **침공 검증 = 결정론 리플레이 검증** — 전투 로직은 고정 타임스텝 결정론(렌더 분리). 침공 클라이언트는 [시드+입력로그] 제출 → Edge Function이 동일 시뮬 재실행으로 결과 재현 확인. 부산물: 침공 리플레이 관전 기능 무료 획득 (GDD 미결 ❓ 해소).
5. **성장 상한 = 캡 100 / 완만한 무한 성장감** (비권장 선택 존중) — 스킬 포인트 총 99. 노드 비용 총합 ~250포인트로 설계해 최대 40%만 커버 → 빌드 선택 강제 유지. 티어 진입: 2티어 Lv30, 3티어 Lv60. Lv70+ 구간은 경험치 요구 급증(3티어 반복 파밍 구간).
6. **화면 구조 = 기지 맵 공간 연출 + 개별 화면** (비권장 선택 존중) — 픽셀아트 기지 맵에서 건물 클릭으로 격납고/연구소/정제소/방어 사령부/관제탑 진입. 미해금 건물은 잠금 연출. 대가: 기지 맵 아트+건물 5종 에셋을 M3에 추가.
7. **콘텐츠 볼륨 = 표준판** — 잡몹 20종(행성당 4종×5) / 엘리트 10종 / 보스 5종(각 3페이즈) / 주무기 5타입 / 보조무기 5종 / 어픽스 접두 12+접미 12 / 유니크 15점 / 파워업 풀 24종 / 포탑 6종 / 기체 2종(스타터+퇴역 해금 1종).
8. **엔드게임 = 퇴역→수호 기체 순환** — 만렙(100) 기체를 퇴역시키면: ①그 기체가 빌드·장비 그대로 기지 방어의 AI **수호 기체**로 참전 ②새 기체 타입 해금(새 3계열 트리 = 새 클래스) ③**계승 특전**(계정 영구 소폭 보너스). 파밍 장비는 창고 공유로 재사용.
9. **PvE 검증 = 샘플링 리플레이** — 모든 런이 침공과 동일 포맷 [시드+입력로그] 제출. 서버 재실행은 래더 상위 N%·통계 이상치·랜덤 소수만. 적발 시 런 무효+계정 플래그.
10. **래더 진입 완화 = 배치전 + 비활성 침하** — PvP 해금 시 첫 5회는 NPC 시드 기지 배치전 → 성적으로 초기 순위 삽입(기존 유저 순위 무변동). 30일 미접속 계정은 주기적 순위 하락.
11. **풍화 (신규 시스템)** — 방어 시설 정비도의 주기적 자연 감쇠 (주 1회 -5%p, 0%면 포탑 성능 50%까지 저하). 크레딧 **정비**로 회복. 방치된 상위 기지에 하위 랭커의 도전 창이 자연히 열림 — 시즌제 없는 영구 래더의 순환 장치. **⚠️ R14 수정: 자원 감쇠(초안 주 8%)는 철회** — 풍화는 자원·장비·레벨·순위에 작용하지 않음 (ADR-0003 무손실 철학과 정합).
12. **타이틀 = Planet Blitz** (R13) — "Planet + 탄막 슈팅 어휘" 요구에서 확정.
13. **수호 기체 동시 배치 상한 = 2기** (R14) — 보유 무제한, 방어전 동시 투입만 제한 (배치 포인트 예산과 별도 슬롯).

## Constraints

- 결정론 요구: 전투 로직은 렌더와 분리된 고정 타임스텝 시뮬로 M1부터 구현 (Math.random 금지, 시드 RNG 전용)
- 리워드 광고 부활은 PvE 전용, 침공에서는 불가 (래더 공정성)
- 풍화는 자원·방어 시설에만 적용 — 장비·레벨·래더 순위는 감쇠하지 않음
- 배치전은 기존 유저 순위를 변동시키지 않는 삽입 방식
- 성능 기준: 1920×1080, 탄 2,000발+적 200기 60fps (기존 GDD 유지)

## Non-Goals

- 장비 내구도/수리비 (풍화 범위에서 명시 제외)
