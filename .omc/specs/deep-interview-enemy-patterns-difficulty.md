## 확정 결정 (라운드순)

1. **적 20종 전부 고유 패턴 (R1, 비권장 선택 존중)** — 실행 방식: 구현은 **공용 패턴 컴포넌트 엔진**(발사체 타입 × 궤적 × 발사 타이밍의 조합 엔진, 시드 RNG), 20종의 고유함은 그 위의 디자인 데이터. 탄막 가독성 규칙(아웃라인·화이트 코어·예고선)은 전역 공통.
2. **보스 = 3페이즈 + 과열 창 + 탄 소거 (R2)** — HP 100→70% P1(시그니처), 70→35% P2(변형+지형 개입), 35→0% P3(발악). 전환 시 2초 연출+화면 탄 전체 소거. 패턴 시전 직후 5초 **과열 창**(받는 피해 2배) — 접근 타이밍이라는 공격적 축 부여.
3. **랜덤 웨이브 조합 (R3, 비권장 선택 존중)** — 웨이브를 풀에서 시드 랜덤 추첨. 편차 통제: ①구간별 강도 예산표(화면 내 적 수·탄 수 상한 — 탄 2,000발 성능 제약 겸용) ②웨이브 풀 티어 게이팅. 변칙 경보와 결합해 로그라이트식 런 다양성.
4. **티어 스케일링 = 패턴 진화 + 엘리트 어픽스 (R4)** — 수치 배율은 완만(HP 스펀지 방지), 티어업의 본질은 질적 변화: 교전 티어 = 기존 패턴에 서브탄 추가, 섬멸 티어 = 패턴 변형+밀도 상향. 상위 티어 엘리트에 디아2 챔피언식 랜덤 수식어(**엘리트 어픽스**) 부여.
5. **행성 완전 병렬 (R5, 비권장 선택 존중)** — 4개 파밍 행성은 동일 출발선, 차별화는 특산 광물·패턴 스타일만. 진행감은 티어(세로축)가 전담.
6. **잡몹 역할 4슬롯 템플릿 (R6)** — 행성당 4종 = 돌격형·사수형·특수형·지원형 고정 슬롯. 슬롯 안에서 행성별 고유 패턴은 완전 자유. 역할별 위협 기준선 공유로 밸런싱 예측 가능.

## 📝 수치 초안

- 티어 배율: HP ×1 / ×2.2 / ×4.5, 접촉 피해 ×1 / ×1.5 / ×2, 탄속 +0% / +15% / +30% (배율은 완만, 질적 진화가 주축)
- 구간 예산표(정찰 기준): 화면 내 적 12→20→28→36→44→보스전, 동시 탄 상한 300→600→900→1,200→1,600→2,000
- 웨이브 카드 풀 📝: 포위 스폰, 일렬 돌격 러시, 사수 진형+돌격 혼성, 특수형 필드 구축, 지원형 호위 편대 등 구간별 카드 8~12장에서 시드 추첨
- 보스 과열 창: 5초, 받는 피해 2배, 시각 표시(과열 증기+색 변화) 필수
